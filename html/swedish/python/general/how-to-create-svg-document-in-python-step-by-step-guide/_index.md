# Hur man skapar SVG-dokument i Python – steg‑för‑steg‑guide

Om du behöver **create SVG document** programatiskt visar den här handledningen exakt hur du gör. Du får ett komplett, körbart exempel som skapar en enkel vektorgrafik, exporterar SVG‑bilden och sparar SVG‑filen på disk.

Att arbeta med SVG‑filer är vanligt när du vill ha upplösningsoberoende grafik för webbsidor, rapporter eller UI‑ikoner. I avsnitten som följer kommer du att lära dig hur du sätter upp miljön, bygger SVG‑elementen och hanterar kantfall som anpassade namnrymder eller dynamiska attributvärden.

## Förutsättningar

* Python 3.8 eller nyare installerat.
* `svgwrite`‑paketet (eller ett bibliotek som tillhandahåller ett `SVGDocument`‑liknande API). Installera det med:

```bash
pip install svgwrite
```

* Skrivrättighet till den katalog där du planerar att **save SVG file**.

Inga ytterligare systemberoenden krävs.

## Steg 1: Initiera SVG-dokumentet

Det första steget är att skapa ett nytt **SVG document**‑objekt. Detta objekt representerar rot‑elementet `<svg>` och tillhandahåller metoder för att lägga till former, grupper och andra SVG‑konstruktioner.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Varför detta är viktigt*: Att initiera dokumentet definierar automatiskt canvas‑storleken och XML‑namnrymden, vilket är avgörande för alla **create vector graphic**‑arbetsflöden.

## Steg 2: Definiera ett rött cirkelelement

Därefter lägger du till det faktiska grafikinnehållet. I det här exemplet ritar vi en röd cirkel centrerad vid (50, 50) med en radie på 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Varför detta är viktigt*: Att använda en dictionary för attribut håller koden ren och gör det enkelt att ändra egenskaper senare—användbart när du **export SVG image** med olika färger eller storlekar.

## Steg 3: Lägg till ytterligare element (valfritt)

Du kan utöka grafiken genom att lägga till fler former, text eller grupper. Nedan är ett valfritt steg som lägger till en svart kontur runt cirkeln.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Proffstips*: Att återanvända `svg_doc.circle` med olika parametrar låter dig **create vector graphic**‑lager utan att manuellt hantera XML‑strängar.

## Steg 4: Spara SVG-filen

Slutligen skriver du den in‑memory‑SVG:n till disk. Detta är ögonblicket då **save SVG file**‑operationen sker.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

När skriptet är klart hittar du `circle.svg` i mappen `output`. Att öppna filen i en webbläsare eller en SVG‑redigerare visar en röd cirkel med en tunn svart kontur.

### Förväntad output (rå SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Om du visar filen i en webbläsare ser du den röda cirkeln centrerad i en 100 × 100 pixel‑canvas.

## Hur man skapar SVG med dynamisk data

Ofta behöver du generera SVG‑filer baserat på data vid körning (t.ex. diagrampunkter, användaravatarer). Samma mönster gäller:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Varför detta fungerar*: Funktionen abstraherar logiken för **how to create SVG**, vilket låter dig anropa den med vilken radie eller fyllningsfärg som helst. Detta tillvägagångssätt skalar bra för batch‑behandling eller API‑endpoints som returnerar SVG‑bilder.

## Exportera SVG‑bild för webbbruk

Om du behöver bädda in SVG:n direkt i HTML eller skicka den via HTTP kan du **export SVG image** som en sträng:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Att koda strängen som Base64 låter dig använda en data‑URI, vilket eliminerar behovet av en separat **save SVG file**‑begäran i många webbsituationer.

## Vanliga fallgropar och hur man undviker dem

| Problem | Varför det händer | Lösning |
|---------|-------------------|--------|
| Saknad namnrymd | Vissa bibliotek lägger inte till `xmlns` automatiskt. | Se till att `svgwrite.Drawing` används eller sätt manuellt `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Ogiltiga attributnamn | SVG är skiftlägeskänsligt; `"strokeWidth"` känns inte igen. | Använd SVG‑specifika attributnamn (`stroke-width`). |
| Skriva över filen | Att köra skriptet igen kan skriva över en befintlig fil utan varning. | Kontrollera `os.path.exists(output_path)` innan du anropar `saveas`. |
| Stora utskriftssträngar | Export av mycket stora SVG‑filer kan förbruka minne. | Strömma utdata till en fil med `svg_doc.write(output_path)` istället för `tostring()`. |

Att hantera dessa kantfall säkerställer att din **create SVG document**‑rutin är robust i produktionsmiljöer.

## Fullt fungerande exempel

När vi sätter ihop allt, här är ett självständigt skript som skapar en röd cirkel, lägger till en valfri kontur och sparar SVG‑filen:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Att köra detta skript skapar `output/circle.svg`, som du kan öppna i vilken modern webbläsare som helst. Filen demonstrerar en grundläggande **create vector graphic** som du kan utöka med fler former, text eller animationer.
