# Hogyan hozzunk létre SVG dokumentumot Pythonban – lépésről‑lépésre útmutató

Ha programozott módon **create SVG document**-ot kell létrehoznod, ez a tutorial pontosan megmutatja, hogyan. Egy teljes, futtatható példát kapsz, amely egyszerű vektorgrafikát hoz létre, exportálja az SVG képet, és elmenti az SVG fájlt a lemezre.

Az SVG fájlokkal való munka gyakori, ha felbontás‑független grafikára van szükség weboldalakhoz, jelentésekhez vagy UI ikonokhoz. A következő szakaszokban megtanulod, hogyan állítsd be a környezetet, építsd fel az SVG elemeket, és kezeld az olyan széljegyeket, mint az egyedi névtér vagy a dinamikus attribútumértékek.

## Előfeltételek

Mielőtt elkezdenéd, győződj meg róla, hogy a következők telepítve vannak:

* Python 3.8 vagy újabb telepítve.
* A `svgwrite` csomag (vagy bármely könyvtár, amely `SVGDocument`‑szerű API-t biztosít). Telepítsd a következővel:

```bash
pip install svgwrite
```

* Írási jogosultság a könyvtárban, ahová **save SVG file**-t tervezed menteni.

Nem szükségesek további rendszerfüggőségek.

## 1. lépés: Az SVG dokumentum inicializálása

Az első lépés egy friss **SVG document** objektum létrehozása. Ez az objektum képviseli a gyökér `<svg>` elemet, és módszereket biztosít alakzatok, csoportok és egyéb SVG szerkezetek hozzáadásához.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: Az dokumentum inicializálása automatikusan meghatározza a vászon méretét és az XML névteret, ami elengedhetetlen bármely **create vector graphic** munkafolyamat számára.

## 2. lépés: Piros kör elem definiálása

Ezután hozzáadjuk a tényleges grafikus tartalmat. Ebben a példában egy piros kört rajzolunk, amely középpontja (50, 50) és sugara 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: Az attribútumok szótárként való használata tisztán tartja a kódot, és könnyűvé teszi a tulajdonságok későbbi módosítását – hasznos, ha **export SVG image**-t különböző színekkel vagy méretekkel szeretnél exportálni.

## 3. lépés: További elemek hozzáadása (opcionális)

A grafikát kiegészítheted további alakzatokkal, szöveggel vagy csoportokkal. Az alábbi opcionális lépés egy fekete körvonalat ad a kör köré.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: A `svg_doc.circle` újrahasználata különböző paraméterekkel lehetővé teszi **create vector graphic** rétegek létrehozását XML karakterláncok manuális kezelése nélkül.

## 4. lépés: SVG mentése fájlba

Végül írjuk a memóriában lévő SVG-t a lemezre. Ez az a pillanat, amikor a **save SVG file** művelet végbemegy.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Amikor a szkript befejeződik, a `circle.svg` fájlt a `output` mappában találod. A fájl böngészőben vagy SVG szerkesztőben megnyitva egy piros kör látható vékony fekete körvonallal.

### Várt kimenet (nyers SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Ha a fájlt böngészőben nézed, a piros kör a 100 × 100 pixel vásznon középen jelenik meg.

## Hogyan hozzunk létre SVG-t dinamikus adatokkal

Gyakran szükség van SVG-k generálására futásidőben kapott adatok alapján (pl. diagrampontok, felhasználói avatarok). Ugyanez a minta alkalmazható:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: A függvény absztrahálja a **how to create SVG** logikát, lehetővé téve, hogy bármilyen sugárral vagy kitöltőszínnel meghívd. Ez a megközelítés jól skálázódik kötegelt feldolgozáshoz vagy API végpontokhoz, amelyek SVG képeket adnak vissza.

## SVG kép exportálása webes használatra

Ha közvetlenül szeretnéd beágyazni az SVG-t HTML-be vagy HTTP-n keresztül küldeni, **export SVG image**-t karakterláncként exportálhatod:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

A karakterlánc Base64‑re kódolása lehetővé teszi a data URI használatát, ami sok webes szituációban megszünteti a külön **save SVG file** kérés szükségességét.

## Gyakori buktatók és elkerülésük módjai

| Probléma | Miért fordul elő | Megoldás |
|----------|------------------|----------|
| Hiányzó névtér | Egyes könyvtárak nem adnak hozzá `xmlns`-t automatikusan. | Győződj meg róla, hogy `svgwrite.Drawing`-et használsz, vagy állítsd be manuálisan: `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Érvénytelen attribútumnevek | Az SVG kis‑ és nagybetű érzékeny; a `"strokeWidth"` nem kerül felismerésre. | Használd az SVG‑specifikus attribútumneveket (`stroke-width`). |
| Fájl felülírása | A szkript újrafuttatása figyelmeztetés nélkül felülírhat egy meglévő fájlt. | Ellenőrizd a `os.path.exists(output_path)`-t a `saveas` hívása előtt. |
| Nagy kimeneti karakterláncok | Nagyon nagy SVG-k exportálása sok memóriát fogyaszthat. | Írd a kimenetet közvetlenül fájlba a `svg_doc.write(output_path)` használatával a `tostring()` helyett. |

Ezeknek a széljegyeknek a kezelése biztosítja, hogy a **create SVG document** rutinod robusztus legyen a termelési környezetben.

## Teljes működő példa

Mindent egy helyen, itt egy önálló szkript, amely piros kört hoz létre, opcionális körvonalat ad hozzá, és elmenti az SVG fájlt:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

A szkript futtatása létrehozza a `output/circle.svg` fájlt, amelyet bármely modern böngészőben megnyithatsz. A fájl egy alap **create vector graphic** példát mutat, amelyet további alakzatokkal, szöveggel vagy animációkkal bővíthetsz.
