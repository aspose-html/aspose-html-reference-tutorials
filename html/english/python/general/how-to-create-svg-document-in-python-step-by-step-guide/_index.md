# How to create SVG document in Python – step‑by‑step guide

If you need to **create SVG document** programmatically, this tutorial shows you exactly how. You’ll get a complete, runnable example that creates a simple vector graphic, exports the SVG image, and saves the SVG file to disk.

Working with SVG files is common when you want resolution‑independent graphics for web pages, reports, or UI icons. In the sections that follow you’ll learn how to set up the environment, build the SVG elements, and handle edge cases such as custom namespaces or dynamic attribute values.

## Prerequisites

Before you start, make sure you have:

* Python 3.8 or newer installed.
* The `svgwrite` package (or any library that provides an `SVGDocument`‑like API). Install it with:

```bash
pip install svgwrite
```

* Write permission to the directory where you plan to **save SVG file**.

No additional system dependencies are required.

## Step 1: Initialize the SVG document

The first step is to create a fresh **SVG document** object. This object represents the root `<svg>` element and provides methods for adding shapes, groups, and other SVG constructs.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: Initializing the document defines the canvas size and the XML namespace automatically, which is essential for any **create vector graphic** workflow.

## Step 2: Define a red circle element

Next, you add the actual graphic content. In this example we draw a red circle centered at (50, 50) with a radius of 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: Using a dictionary for attributes keeps the code clean and makes it easy to modify properties later—useful when you **export SVG image** with different colors or sizes.

## Step 3: Append additional elements (optional)

You can extend the graphic by adding more shapes, text, or groups. Below is an optional step that adds a black stroke around the circle.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: Re‑using `svg_doc.circle` with different parameters lets you **create vector graphic** layers without manually handling XML strings.

## Step 4: Save the SVG to a file

Finally, write the in‑memory SVG to disk. This is the moment where the **save SVG file** operation occurs.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

When the script finishes, you’ll find `circle.svg` inside the `output` folder. Opening the file in a browser or an SVG editor shows a red circle with a thin black outline.

### Expected output (raw SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

If you view the file in a browser, you’ll see the red circle centered in a 100 × 100 pixel canvas.

## How to create SVG with dynamic data

Often you need to generate SVGs based on runtime data (e.g., chart points, user avatars). The same pattern applies:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: The function abstracts the **how to create SVG** logic, allowing you to call it with any radius or fill color. This approach scales well for batch processing or API endpoints that return SVG images.

## Export SVG image for web use

If you need to embed the SVG directly into HTML or send it over HTTP, you can **export SVG image** as a string:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Encoding the string as Base64 lets you use a data URI, which eliminates the need for a separate **save SVG file** request in many web scenarios.

## Common pitfalls and how to avoid them

| Issue | Why it happens | Fix |
|-------|----------------|-----|
| Missing namespace | Some libraries don’t add `xmlns` automatically. | Ensure `svgwrite.Drawing` is used or manually set `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Invalid attribute names | SVG is case‑sensitive; `"strokeWidth"` is not recognized. | Use the SVG‑spec attribute names (`stroke-width`). |
| Overwriting the file | Re‑running the script may overwrite an existing file without warning. | Check `os.path.exists(output_path)` before calling `saveas`. |
| Large output strings | Exporting very large SVGs can consume memory. | Stream the output to a file using `svg_doc.write(output_path)` instead of `tostring()`. |

Addressing these edge cases ensures your **create SVG document** routine is robust in production environments.

## Full working example

Putting everything together, here’s a self‑contained script that creates a red circle, adds an optional stroke, and saves the SVG file:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Running this script creates `output/circle.svg`, which you can open in any modern browser. The file demonstrates a basic **create vector graphic** that you can extend with more shapes, text, or animations.
