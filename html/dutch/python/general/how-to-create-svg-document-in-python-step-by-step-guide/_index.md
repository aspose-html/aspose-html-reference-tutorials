# Hoe maak je een SVG-document in Python – stapsgewijze handleiding

Als je **create SVG document** programmatisch moet maken, laat deze tutorial je precies zien hoe. Je krijgt een compleet, uitvoerbaar voorbeeld dat een eenvoudige vectorafbeelding maakt, de SVG-afbeelding exporteert en het SVG‑bestand opslaat op schijf.

Werken met SVG‑bestanden is gebruikelijk wanneer je resolutie‑onafhankelijke graphics wilt voor webpagina's, rapporten of UI‑iconen. In de volgende secties leer je hoe je de omgeving instelt, de SVG‑elementen bouwt en omgaat met randgevallen zoals aangepaste namespaces of dynamische attribuutwaarden.

## Vereisten

* Python 3.8 of nieuwer geïnstalleerd.
* Het `svgwrite`‑pakket (of een andere bibliotheek die een `SVGDocument`‑achtige API biedt). Installeer het met:

```bash
pip install svgwrite
```

* Schrijfrechten voor de map waarin je van plan bent **save SVG file** op te slaan.

Er zijn geen extra systeemafhankelijkheden vereist.

## Stap 1: Initialiseer het SVG‑document

De eerste stap is het aanmaken van een nieuw **SVG document** object. Dit object vertegenwoordigt het root‑element `<svg>` en biedt methoden om vormen, groepen en andere SVG‑constructies toe te voegen.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Waarom dit belangrijk is*: Het initialiseren van het document definieert automatisch de canvasgrootte en de XML‑namespace, wat essentieel is voor elke **create vector graphic** workflow.

## Stap 2: Definieer een rood cirkelelement

Vervolgens voeg je de daadwerkelijke grafische inhoud toe. In dit voorbeeld tekenen we een rode cirkel gecentreerd op (50, 50) met een radius van 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Waarom dit belangrijk is*: Het gebruik van een dictionary voor attributen houdt de code overzichtelijk en maakt het later eenvoudig om eigenschappen aan te passen — handig wanneer je **export SVG image** met verschillende kleuren of groottes.

## Stap 3: Voeg extra elementen toe (optioneel)

Je kunt de grafiek uitbreiden door meer vormen, tekst of groepen toe te voegen. Hieronder staat een optionele stap die een zwarte lijn rond de cirkel toevoegt.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: Het hergebruiken van `svg_doc.circle` met verschillende parameters stelt je in staat **create vector graphic** lagen te maken zonder handmatig XML‑strings te behandelen.

## Stap 4: Sla de SVG op in een bestand

Tot slot schrijf je de in‑memory SVG naar schijf. Dit is het moment waarop de **save SVG file** operatie plaatsvindt.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Wanneer het script is voltooid, vind je `circle.svg` in de map `output`. Het openen van het bestand in een browser of een SVG‑editor toont een rode cirkel met een dunne zwarte omtrek.

### Verwachte output (raw SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Als je het bestand in een browser bekijkt, zie je de rode cirkel gecentreerd op een canvas van 100 × 100 pixel.

## Hoe maak je SVG met dynamische data

Vaak moet je SVG's genereren op basis van runtime‑data (bijv. grafiekpunten, gebruikersavatars). Hetzelfde patroon is van toepassing:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Waarom dit werkt*: De functie abstraheert de **how to create SVG** logica, waardoor je deze kunt aanroepen met elke radius of vulkleur. Deze aanpak schaalt goed voor batchverwerking of API‑endpoints die SVG‑afbeeldingen retourneren.

## Exporteer SVG‑afbeelding voor webgebruik

Als je de SVG direct in HTML wilt insluiten of via HTTP wilt verzenden, kun je **export SVG image** als een string:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Het coderen van de string als Base64 stelt je in staat een data‑URI te gebruiken, waardoor in veel webscenario's een aparte **save SVG file** aanvraag overbodig wordt.

## Veelvoorkomende valkuilen en hoe ze te vermijden

| Probleem | Waarom het gebeurt | Oplossing |
|----------|--------------------|-----------|
| Ontbrekende namespace | Sommige bibliotheken voegen `xmlns` niet automatisch toe. | Zorg ervoor dat `svgwrite.Drawing` wordt gebruikt of stel handmatig `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"` in. |
| Ongeldige attribuutnamen | SVG is hoofdlettergevoelig; "strokeWidth" wordt niet herkend. | Gebruik de SVG‑specifieke attribuutnamen (`stroke-width`). |
| Bestand overschrijven | Het opnieuw uitvoeren van het script kan een bestaand bestand zonder waarschuwing overschrijven. | Controleer `os.path.exists(output_path)` voordat `saveas` wordt aangeroepen. |
| Grote output‑strings | Het exporteren van zeer grote SVG's kan veel geheugen verbruiken. | Stream de output naar een bestand met `svg_doc.write(output_path)` in plaats van `tostring()`. |

Het aanpakken van deze randgevallen zorgt ervoor dat je **create SVG document** routine robuust is in productieomgevingen.

## Volledig werkend voorbeeld

Door alles samen te voegen, hier is een zelfstandige script die een rode cirkel maakt, een optionele lijn toevoegt, en het SVG‑bestand opslaat:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Het uitvoeren van dit script maakt `output/circle.svg`, die je in elke moderne browser kunt openen. Het bestand toont een basis **create vector graphic** die je kunt uitbreiden met meer vormen, tekst of animaties.
