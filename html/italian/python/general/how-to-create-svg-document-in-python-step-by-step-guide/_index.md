# Come creare un documento SVG in Python – guida passo‑passo

Se hai bisogno di **creare un documento SVG** programmaticamente, questo tutorial ti mostra esattamente come fare. Otterrai un esempio completo e eseguibile che crea una semplice grafica vettoriale, esporta l'immagine SVG e salva il file SVG su disco.

Lavorare con file SVG è comune quando si desiderano grafiche indipendenti dalla risoluzione per pagine web, report o icone UI. Nelle sezioni successive imparerai come configurare l'ambiente, costruire gli elementi SVG e gestire casi particolari come namespace personalizzati o valori di attributi dinamici.

## Prerequisiti

* Python 3.8 o versioni successive installato.
* Il pacchetto `svgwrite` (o qualsiasi libreria che fornisca un'API simile a `SVGDocument`). Installalo con:

```bash
pip install svgwrite
```

* Permessi di scrittura nella directory in cui prevedi di **salvare il file SVG**.

Non sono richieste dipendenze di sistema aggiuntive.

## Passo 1: Inizializzare il documento SVG

Il primo passo è creare un nuovo oggetto **documento SVG**. Questo oggetto rappresenta l'elemento radice `<svg>` e fornisce metodi per aggiungere forme, gruppi e altri costrutti SVG.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Perché è importante*: Inizializzare il documento definisce automaticamente le dimensioni della tela e lo spazio dei nomi XML, il che è essenziale per qualsiasi flusso di lavoro di **creazione di grafica vettoriale**.

## Passo 2: Definire un elemento cerchio rosso

Successivamente, aggiungi il contenuto grafico reale. In questo esempio disegniamo un cerchio rosso centrato in (50, 50) con un raggio di 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Perché è importante*: Usare un dizionario per gli attributi mantiene il codice pulito e facilita la modifica delle proprietà in seguito—utile quando **esporti l'immagine SVG** con colori o dimensioni diversi.

## Passo 3: Aggiungere elementi aggiuntivi (opzionale)

Puoi estendere la grafica aggiungendo altre forme, testo o gruppi. Di seguito un passo opzionale che aggiunge un contorno nero attorno al cerchio.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Consiglio professionale*: Riutilizzare `svg_doc.circle` con parametri diversi ti consente di creare livelli di **grafica vettoriale** senza gestire manualmente stringhe XML.

## Passo 4: Salvare l'SVG su file

Infine, scrivi l'SVG in memoria su disco. Questo è il momento in cui avviene l'operazione di **salvataggio del file SVG**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Quando lo script termina, troverai `circle.svg` nella cartella `output`. Aprire il file in un browser o in un editor SVG mostra un cerchio rosso con un sottile contorno nero.

### Output previsto (SVG grezzo)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Se visualizzi il file in un browser, vedrai il cerchio rosso centrato in una tela di 100 × 100 pixel.

## Come creare SVG con dati dinamici

Spesso è necessario generare SVG basati su dati di runtime (ad es., punti di un grafico, avatar utente). Si applica lo stesso schema:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Perché funziona*: La funzione astrae la logica di **come creare SVG**, permettendoti di chiamarla con qualsiasi raggio o colore di riempimento. Questo approccio scala bene per l'elaborazione batch o per endpoint API che restituiscono immagini SVG.

## Esportare l'immagine SVG per uso web

Se hai bisogno di incorporare l'SVG direttamente in HTML o inviarlo via HTTP, puoi **esportare l'immagine SVG** come stringa:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Codificare la stringa in Base64 ti consente di utilizzare un data URI, eliminando la necessità di una richiesta separata di **salvataggio del file SVG** in molti scenari web.

## Problemi comuni e come evitarli

| Problema | Perché accade | Soluzione |
|----------|----------------|-----------|
| Namespace mancante | Alcune librerie non aggiungono `xmlns` automaticamente. | Assicurati di usare `svgwrite.Drawing` o imposta manualmente `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Nomi attributi non validi | SVG è case‑sensitive; `"strokeWidth"` non è riconosciuto. | Usa i nomi di attributi secondo le specifiche SVG (`stroke-width`). |
| Sovrascrittura del file | Rieseguire lo script può sovrascrivere un file esistente senza avviso. | Verifica `os.path.exists(output_path)` prima di chiamare `saveas`. |
| Stringhe di output grandi | Esportare SVG molto grandi può consumare memoria. | Trasmetti l'output su file usando `svg_doc.write(output_path)` invece di `tostring()`. |

Affrontare questi casi limite garantisce che la tua routine di **creazione di documenti SVG** sia robusta negli ambienti di produzione.

## Esempio completo funzionante

Mettendo tutto insieme, ecco uno script autonomo che crea un cerchio rosso, aggiunge un contorno opzionale e salva il file SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Eseguendo questo script si crea `output/circle.svg`, che puoi aprire in qualsiasi browser moderno. Il file dimostra una **creazione di grafica vettoriale** di base che puoi estendere con più forme, testo o animazioni.
