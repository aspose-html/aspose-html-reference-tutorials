# 如何在 Python 中创建 SVG 文档 – 逐步指南

如果您需要以编程方式 **create SVG document**，本教程将向您展示具体步骤。您将获得一个完整、可运行的示例，创建一个简单的矢量图形，导出 SVG 图像，并将 SVG 文件保存到磁盘。

在需要为网页、报告或 UI 图标提供分辨率无关的图形时，使用 SVG 文件是很常见的。在接下来的章节中，您将学习如何设置环境、构建 SVG 元素，以及处理诸如自定义命名空间或动态属性值等边缘情况。

## 前置条件

* 已安装 Python 3.8 或更高版本。
* `svgwrite` 包（或任何提供 `SVGDocument`‑like API 的库）。使用以下方式安装：

```bash
pip install svgwrite
```

* 对计划 **save SVG file** 的目录具有写入权限。

无需额外的系统依赖。

## 步骤 1：初始化 SVG 文档

第一步是创建一个全新的 **SVG document** 对象。该对象代表根 `<svg>` 元素，并提供用于添加形状、组和其他 SVG 构造的方法。

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*：初始化文档会自动定义画布大小和 XML 命名空间，这对于任何 **create vector graphic** 工作流都是必不可少的。

## 步骤 2：定义红色圆形元素

接下来，您添加实际的图形内容。在本例中，我们绘制一个以 (50, 50) 为中心、半径为 40 px 的红色圆形。

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*：使用字典来存放属性可以保持代码整洁，并且便于以后修改属性——在 **export SVG image** 时更改颜色或尺寸时非常有用。

## 步骤 3：追加其他元素（可选）

您可以通过添加更多形状、文本或组来扩展图形。下面是一个可选步骤，为圆形添加黑色描边。

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*：重复使用 `svg_doc.circle` 并传入不同参数，可让您在不手动处理 XML 字符串的情况下 **create vector graphic** 图层。

## 步骤 4：将 SVG 保存到文件

最后，将内存中的 SVG 写入磁盘。这就是执行 **save SVG file** 操作的时刻。

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

脚本执行完毕后，您会在 `output` 文件夹中找到 `circle.svg`。在浏览器或 SVG 编辑器中打开该文件，可看到一个带有细黑色轮廓的红色圆形。

### 预期输出（原始 SVG）

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

如果在浏览器中查看该文件，您会看到红色圆形位于 100 × 100 像素画布的中心。

## 如何使用动态数据创建 SVG

通常，您需要根据运行时数据（例如图表点、用户头像）生成 SVG。相同的模式适用：

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*：该函数抽象了 **how to create SVG** 的逻辑，允许您使用任意半径或填充颜色调用它。这种方法在批处理或返回 SVG 图像的 API 端点中具有良好的可扩展性。

## 为网页使用导出 SVG 图像

如果您需要将 SVG 直接嵌入 HTML 或通过 HTTP 发送，可以将 **export SVG image** 为字符串：

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

将字符串编码为 Base64 可让您使用 data URI，这在许多网页场景中消除了单独的 **save SVG file** 请求的需求。

## 常见陷阱及其避免方法

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 缺少命名空间 | 某些库不会自动添加 `xmlns`。 | 确保使用 `svgwrite.Drawing`，或手动设置 `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`。 |
| 属性名称无效 | SVG 区分大小写，`"strokeWidth"` 不被识别。 | 使用 SVG 规范的属性名称（`stroke-width`）。 |
| 文件被覆盖 | 重新运行脚本可能在没有警告的情况下覆盖已有文件。 | 在调用 `saveas` 前检查 `os.path.exists(output_path)`。 |
| 输出字符串过大 | 导出非常大的 SVG 可能会消耗大量内存。 | 使用 `svg_doc.write(output_path)` 将输出流式写入文件，而不是使用 `tostring()`。 |

处理这些边缘情况可确保您的 **create SVG document** 例程在生产环境中具有鲁棒性。

## 完整工作示例

将所有内容组合在一起，以下是一个完整的脚本，创建红色圆形，添加可选描边，并保存 SVG 文件：

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

运行此脚本会生成 `output/circle.svg`，您可以在任何现代浏览器中打开。该文件展示了一个基本的 **create vector graphic**，您可以在此基础上添加更多形状、文本或动画。
