# 如何使用 Aspose.HTML for Java 将 HTML 转换为 MHTML

将 HTML 转换为 MHTML 是一种常见需求，当您需要一个包含 HTML 页面及其所有资源（图像、CSS、脚本）的单一可移植文件时。本教程将教您使用 Aspose.HTML for Java **如何将 HTML 转换为 MHTML**，了解如何 **将 HTML 保存为 MHTML**，并发现最佳的 **以 Java 风格加载 HTML 文档** 的方法。无论是归档网页、生成可用于电子邮件的内容，还是构建报告流水线，下面的步骤都能帮助您快速实现。

## 快速答案
- **主要库是什么？** Aspose.HTML for Java  
- **实现需要多长时间？** 基本转换大约需要 10‑15 分钟  
- **我需要许可证吗？** 测试时临时许可证即可；生产环境需要正式许可证  
- **可以批量处理文件吗？** 可以 – 将代码放入循环并复用相同的选项  
- **支持的输出？** MHTML (`.mht`)，以及其他格式如 PDF、PNG 等

## 什么是 HTML 转换为 MHTML？
HTML 转换为 MHTML 将标准网页转换为单个 MIME 编码文件，该文件将 HTML 标记与所有链接资源（如图像、样式表和脚本）打包在一起。生成的 .mht 文件是自包含的，支持离线查看、轻松共享，并可嵌入电子邮件中而无需外部依赖。

## 为什么使用 Aspose.HTML for Java？
Aspose.HTML for Java 提供纯 Java 引擎，可在不依赖外部浏览器的情况下转换 HTML 内容，为开发者提供对渲染、资源处理和输出保真度的完整控制。它支持批量处理，高效处理大文件，并提供多种输出格式，是企业级文档生成和归档任务的理想选择。

- **完整控制** 资源处理（您决定转换器应跟随链接的深度）  
- **无需外部浏览器** – 转换完全在 JVM 上运行  
- **高保真度** – 生成的 MHTML 在浏览器中看起来与原始页面完全一致  
- **可扩展** – 适用于单页或大批量作业  
- **支持 12 种以上输出格式**（包括 MHTML、PDF、PNG、JPEG、SVG、EPUB），且可处理高达 500 MB 的文件而无需将整个文档加载到内存中。

3. **HTML 文档** – 您想要 **将 HTML 保存为 MHTML** 的文件。它可以是任何本地 `.html` 文件，或是运行时生成的页面。

现在基础已经介绍完毕，让我们深入代码。

## 导入包

在您的 Java 类中添加所需的导入：

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## 步骤指南

### 步骤 1：加载 HTML 文档

`HTMLDocument` 类表示已加载到内存中以供进一步处理的 HTML 文件。  
这里我们通过提供文件路径 **以 Java 风格加载 HTML 文档**。`HTMLDocument` 类会解析标记并为转换做好准备。

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### 步骤 2：初始化 MHTML 保存选项

`MHTMLSaveOptions` 对象定义了将转换为 MHTML 的方式，包括编码和资源处理。  
`MHTMLSaveOptions` 对象允许您微调转换行为（例如资源处理、编码）。

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### 步骤 3：设置资源处理规则

`ResourceHandlingOptions` 类控制嵌入哪些外部资源以及爬虫的深度。  
您可以控制转换器跟随链接资源的深度。将深度设置为 `1` 表示仅嵌入直接引用的资源（图像、CSS），从而保持输出文件大小在合理范围内。

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### 步骤 4：指定输出路径

`outputPath` 字符串指示库将生成的 MHTML 文件写入何处。  
选择要保存生成的 **MHTML** 文件的位置。

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### 步骤 5：执行转换

`Converter.convertHTML` 静态方法读取源 `HTMLDocument`，应用 `MHTMLSaveOptions`，并写入输出文件。  
静态的 `convertHTML` 方法负责核心工作：读取 `HTMLDocument`，应用 `options`，并将 MHTML 文件写入 `outputMHTML`。

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **专业提示：** 如果需要转换多个文件，请实例化一次 `MHTMLSaveOptions` 并在循环中复用，以提升性能。

## 资源处理深度如何影响 MHTML 大小？

较低的深度（例如 `1`）仅嵌入直接引用的资源，生成更小的 MHTML 文件；而较高的深度（例如 `3`）会包含更深层次的链接资产，导致文件体积增大但提升完整性。请根据存储限制和对完全自包含输出的需求来选择深度。

## 如何将 HTML 转换为 PDF（java html to pdf）——快速说明

Aspose.HTML for Java 并不限于 MHTML。如果您还需要生成 PDF，只需将 `MHTMLSaveOptions` 替换为 `PdfSaveOptions` 并调用相同的 `Converter.convertHTML` 方法。此灵活性使您能够在不添加额外库的情况下处理 **java html to pdf** 转换。

## 常见问题及解决方案

| 问题 | 解决方案 |
|-------|----------|
| **MHTML 文件中缺少图像** | 确保 `setMaxHandlingDepth` 足够高以包含嵌套资源，或通过 `resourceHandlingOptions.getAdditionalResources()` 手动添加它们 |
| **不支持的 CSS 功能** | Aspose.HTML 遵循 HTML5/CSS3 标准；较旧或专有的 CSS 可能被忽略。简化样式表或将样式直接嵌入 HTML 中 |
| **运行时 LicenseException** | 在开发期间应用临时许可证：`License license = new License(); license.setLicense("Aspose.HTML.Java.lic");` |
