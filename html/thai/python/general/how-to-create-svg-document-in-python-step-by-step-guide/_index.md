# วิธีสร้างเอกสาร SVG ใน Python – คู่มือขั้นตอนโดยละเอียด

หากคุณต้องการ **create SVG document** อย่างอัตโนมัติ, บทแนะนำนี้จะแสดงให้คุณเห็นอย่างชัดเจน คุณจะได้ตัวอย่างที่ทำงานได้เต็มรูปแบบซึ่งสร้างกราฟิกเวกเตอร์แบบง่าย, ส่งออกภาพ SVG, และบันทึกไฟล์ SVG ลงดิสก์.

การทำงานกับไฟล์ SVG เป็นเรื่องทั่วไปเมื่อคุณต้องการกราฟิกที่ไม่ขึ้นกับความละเอียดสำหรับหน้าเว็บ, รายงาน, หรือไอคอน UI. ในส่วนต่อไปนี้คุณจะได้เรียนรู้วิธีตั้งค่าสภาพแวดล้อม, สร้างองค์ประกอบ SVG, และจัดการกรณีขอบเช่นเนมสเปซที่กำหนดเองหรือค่าแอตทริบิวต์แบบไดนามิก.

## ข้อกำหนดเบื้องต้น

* Python 3.8 หรือใหม่กว่า ติดตั้งแล้ว.
* แพคเกจ `svgwrite` (หรือไลบรารีใด ๆ ที่ให้ API แบบ `SVGDocument`). ติดตั้งด้วย:

```bash
pip install svgwrite
```

* สิทธิ์การเขียนในไดเรกทอรีที่คุณวางแผนจะ **save SVG file**.

ไม่ต้องการการพึ่งพาระบบเพิ่มเติม.

## ขั้นตอนที่ 1: เริ่มต้นเอกสาร SVG

ขั้นตอนแรกคือการสร้างอ็อบเจ็กต์ **SVG document** ใหม่. อ็อบเจ็กต์นี้แทนองค์ประกอบราก `<svg>` และให้เมธอดสำหรับเพิ่มรูปทรง, กลุ่ม, และโครงสร้าง SVG อื่น ๆ.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*ทำไมเรื่องนี้ถึงสำคัญ*: การเริ่มต้นเอกสารกำหนดขนาดแคนวาสและเนมสเปซ XML โดยอัตโนมัติ ซึ่งจำเป็นสำหรับกระบวนการ **create vector graphic** ใด ๆ.

## ขั้นตอนที่ 2: กำหนดองค์ประกอบวงกลมสีแดง

ต่อไปคุณจะเพิ่มเนื้อหากราฟิกจริง ในตัวอย่างนี้เราวาดวงกลมสีแดงที่ศูนย์กลาง (50, 50) ด้วยรัศมี 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*ทำไมเรื่องนี้ถึงสำคัญ*: การใช้ดิกชันนารีสำหรับแอตทริบิวต์ทำให้โค้ดสะอาดและง่ายต่อการแก้ไขคุณสมบัติในภายหลัง—มีประโยชน์เมื่อคุณ **export SVG image** ด้วยสีหรือขนาดที่ต่างกัน.

## ขั้นตอนที่ 3: เพิ่มองค์ประกอบเพิ่มเติม (ไม่บังคับ)

คุณสามารถขยายกราฟิกโดยเพิ่มรูปทรง, ข้อความ, หรือกลุ่มเพิ่มเติม ด้านล่างเป็นขั้นตอนเสริมที่เพิ่มเส้นขอบสีดำรอบวงกลม.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*เคล็ดลับ*: การใช้ `svg_doc.circle` ซ้ำกับพารามิเตอร์ต่าง ๆ ทำให้คุณสามารถ **create vector graphic** ชั้นต่าง ๆ ได้โดยไม่ต้องจัดการสตริง XML ด้วยตนเอง.

## ขั้นตอนที่ 4: บันทึก SVG ลงไฟล์

สุดท้ายให้เขียน SVG ที่อยู่ในหน่วยความจำลงดิสก์ นี่คือช่วงที่ดำเนินการ **save SVG file**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

เมื่อสคริปต์ทำงานเสร็จ คุณจะพบ `circle.svg` ภายในโฟลเดอร์ `output` การเปิดไฟล์ในเบราว์เซอร์หรือโปรแกรมแก้ไข SVG จะแสดงวงกลมสีแดงพร้อมเส้นขอบสีดำบาง.

### ผลลัพธ์ที่คาดหวัง (SVG ดิบ)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

หากคุณเปิดไฟล์ในเบราว์เซอร์ คุณจะเห็นวงกลมสีแดงอยู่ตรงกลางแคนวาสขนาด 100 × 100 พิกเซล.

## วิธีสร้าง SVG ด้วยข้อมูลแบบไดนามิก

บ่อยครั้งคุณต้องสร้าง SVG ตามข้อมูลที่รันไทม์ (เช่น จุดกราฟ, รูปประจำตัวผู้ใช้) รูปแบบเดียวกันนี้ใช้ได้:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*ทำไมวิธีนี้ถึงได้ผล*: ฟังก์ชันแยกตรรกะ **how to create SVG** ทำให้คุณเรียกใช้ได้ด้วยรัศมีหรือสีเติมใด ๆ วิธีนี้ขยายได้ดีสำหรับการประมวลผลเป็นชุดหรือ API endpoint ที่ส่งคืนภาพ SVG.

## ส่งออกภาพ SVG เพื่อใช้บนเว็บ

หากคุณต้องการฝัง SVG ลงใน HTML โดยตรงหรือส่งผ่าน HTTP คุณสามารถ **export SVG image** เป็นสตริงได้:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

การเข้ารหัสสตริงเป็น Base64 ทำให้คุณใช้ data URI ซึ่งลบความจำเป็นของการร้องขอ **save SVG file** แยกต่างหากในหลายสถานการณ์บนเว็บ.

## ความผิดพลาดทั่วไปและวิธีหลีกเลี่ยง

| ปัญหา | ทำไมจึงเกิดขึ้น | วิธีแก้ |
|-------|----------------|-----|
| ไม่มี namespace | บางไลบรารีไม่เพิ่ม `xmlns` โดยอัตโนมัติ. | ตรวจสอบว่าใช้ `svgwrite.Drawing` หรือกำหนดค่า `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"` ด้วยตนเอง. |
| ชื่อแอตทริบิวต์ไม่ถูกต้อง | SVG แยกแยะตัวพิมพ์ใหญ่‑เล็ก; `"strokeWidth"` ไม่ได้รับการรับรู้. | ใช้ชื่อแอตทริบิวต์ตามสเปค SVG (`stroke-width`). |
| เขียนทับไฟล์ | การรันสคริปต์ซ้ำอาจเขียนทับไฟล์ที่มีอยู่โดยไม่มีการเตือน. | ตรวจสอบ `os.path.exists(output_path)` ก่อนเรียก `saveas`. |
| สตริงผลลัพธ์ขนาดใหญ่ | การส่งออก SVG ขนาดใหญ่มากอาจใช้หน่วยความจำมาก. | สตรีมผลลัพธ์ไปยังไฟล์โดยใช้ `svg_doc.write(output_path)` แทน `tostring()`. |

การจัดการกรณีขอบเหล่านี้ทำให้ขั้นตอน **create SVG document** ของคุณมีความทนทานในสภาพแวดล้อมการผลิต.

## ตัวอย่างทำงานเต็มรูปแบบ

เมื่อนำทุกอย่างมารวมกัน นี่คือสคริปต์อิสระที่สร้างวงกลมสีแดง, เพิ่มเส้นขอบเสริม, และบันทึกไฟล์ SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

การรันสคริปต์นี้จะสร้าง `output/circle.svg` ซึ่งคุณสามารถเปิดในเบราว์เซอร์สมัยใหม่ใดก็ได้ ไฟล์นี้แสดง **create vector graphic** พื้นฐานที่คุณสามารถขยายด้วยรูปทรง, ข้อความ, หรือแอนิเมชันเพิ่มเติม.
