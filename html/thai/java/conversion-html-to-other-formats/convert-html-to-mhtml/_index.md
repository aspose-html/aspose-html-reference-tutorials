# วิธีแปลง HTML เป็น MHTML ด้วย Aspose.HTML for Java

การแปลง HTML เป็น MHTML เป็นความต้องการทั่วไปเมื่อคุณต้องการไฟล์เดียวที่พกพาได้ซึ่งประกอบด้วยหน้า HTML พร้อมทรัพยากรทั้งหมด (รูปภาพ, CSS, สคริปต์) ในบทเรียนนี้คุณจะได้เรียนรู้ **วิธีแปลง HTML เป็น MHTML** ด้วย Aspose.HTML for Java, ดูวิธี **บันทึก HTML เป็น MHTML**, และค้นพบวิธีที่ดีที่สุดในการ **โหลดเอกสาร HTML แบบ Java**‑style ไม่ว่าคุณจะกำลังเก็บสำรองหน้าเว็บ, สร้างเนื้อหาที่พร้อมส่งอีเมล, หรือสร้างไพป์ไลน์การรายงาน, ขั้นตอนต่อไปนี้จะช่วยให้คุณทำได้อย่างรวดเร็ว

- **ต้องมีลิขสิทธิ์หรือไม่?** ลิขสิทธิ์ชั่วคราวเพียงพอสำหรับการทดสอบ; ต้องมีลิขสิทธิ์เต็มสำหรับการใช้งานจริง  
- **สามารถประมวลผลไฟล์เป็นชุดได้หรือไม่?** ได้ – เพียงใส่โค้ดในลูปและใช้ตัวเลือกเดียวกันซ้ำ  
- **รูปแบบผลลัพธ์ที่รองรับ?** MHTML (`.mht`), รวมถึงรูปแบบอื่น ๆ เช่น PDF, PNG, เป็นต้น  

## การแปลง HTML เป็น MHTML คืออะไร?
การแปลง HTML เป็น MHTML ทำให้หน้าเว็บมาตรฐานกลายเป็นไฟล์ MIME‑encoded เดียวที่บรรจุโค้ด HTML พร้อมทรัพยากรที่เชื่อมโยงทั้งหมด เช่น รูปภาพ, สไตล์ชีต, และสคริปต์ ไฟล์ .mht ที่ได้เป็นไฟล์อิสระที่สามารถดูแบบออฟไลน์, แชร์ได้ง่าย, และฝังในอีเมลโดยไม่ต้องพึ่งพาแหล่งภายนอก

## นำเข้าแพ็กเกจ

เพิ่มการนำเข้าที่จำเป็นในคลาส Java ของคุณ:

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## คู่มือขั้นตอนโดยละเอียด

### ขั้นตอนที่ 1: โหลดเอกสาร HTML

คลาส `HTMLDocument` แสดงถึงไฟล์ HTML ที่โหลดเข้าสู่หน่วยความจำเพื่อการประมวลผลต่อไป  
ที่นี่เราจะ **โหลดเอกสาร HTML แบบ Java**‑style โดยระบุเส้นทางไฟล์ `HTMLDocument` จะทำการพาร์สโค้ดและเตรียมพร้อมสำหรับการแปลง

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### ขั้นตอนที่ 2: เริ่มต้น MHTML Save Options

อ็อบเจ็กต์ `MHTMLSaveOptions` กำหนดวิธีการแปลงเป็น MHTML รวมถึงการเข้ารหัสและการจัดการทรัพยากร  
คุณสามารถปรับแต่งพฤติกรรมการแปลงได้ (เช่น การจัดการทรัพยากร, การเข้ารหัส)

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### ขั้นตอนที่ 3: ตั้งค่ากฎการจัดการทรัพยากร

คลาส `ResourceHandlingOptions` ควบคุมว่าทรัพยากรภายนอกใดบ้างจะถูกฝังและความลึกของการสำรวจ  
การตั้งค่าความลึกเป็น `1` หมายถึงฝังเฉพาะทรัพยากรที่อ้างอิงโดยตรง (รูปภาพ, CSS) ทำให้ขนาดไฟล์ผลลัพธ์อยู่ในระดับที่เหมาะสม

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### ขั้นตอนที่ 4: ระบุเส้นทางการบันทึกผลลัพธ์

สตริง `outputPath` บอกไลบรารีว่าจะเขียนไฟล์ MHTML ที่ใด  
เลือกตำแหน่งที่ต้องการบันทึกไฟล์ **MHTML** ของคุณ

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### ขั้นตอนที่ 5: ดำเนินการแปลง

เมธอดสแตติก `Converter.convertHTML` จะอ่าน `HTMLDocument` ต้นฉบับ, ใช้ `MHTMLSaveOptions`, และเขียนไฟล์ผลลัพธ์  
เมธอด `convertHTML` ทำหน้าที่หลัก: อ่าน `HTMLDocument`, ประยุกต์ `options`, และเขียนไฟล์ MHTML ไปยัง `outputMHTML`

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **Pro tip:** หากต้องแปลงหลายไฟล์, สร้างอ็อบเจ็กต์ `MHTMLSaveOptions` ครั้งเดียวและใช้ซ้ำภายในลูปเพื่อเพิ่มประสิทธิภาพ

## ความลึกของการจัดการทรัพยากรมีผลต่อขนาดของ MHTML อย่างไร?
ความลึกที่ต่ำกว่า (เช่น `1`) จะฝังเฉพาะทรัพยากรที่อ้างอิงโดยตรง, ทำให้ไฟล์ MHTML เล็กลง, ในขณะที่ความลึกที่สูงกว่า (เช่น `3`) จะรวมทรัพยากรที่ลิงก์ลึกลงไป, ทำให้ไฟล์ใหญ่ขึ้นแต่ความสมบูรณ์ของข้อมูลดียิ่งขึ้น เลือกความลึกตามข้อจำกัดของพื้นที่จัดเก็บและความต้องการให้ไฟล์เป็นอิสระเต็มรูปแบบ
