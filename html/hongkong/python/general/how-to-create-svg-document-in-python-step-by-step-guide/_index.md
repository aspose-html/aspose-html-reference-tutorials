# 如何在 Python 中建立 SVG 文件 – 步驟指南

如果你需要以程式方式 **create SVG document**，本教學會完整說明如何操作。你將獲得一個完整、可執行的範例，能建立簡單的向量圖形、**export SVG image**，並將 **save SVG file** 儲存至磁碟。

在需要為網頁、報告或 UI 圖示提供解析度無關的圖形時，使用 SVG 檔案相當常見。接下來的章節將教你如何設定環境、建構 SVG 元素，並處理自訂命名空間或動態屬性值等邊緣案例。

## 前置條件

在開始之前，請確保你已具備：

* 已安裝 Python 3.8 或更新版本。
* `svgwrite` 套件（或任何提供 `SVGDocument`‑like API 的函式庫）。使用以下指令安裝：

```bash
pip install svgwrite
```

* 具有寫入目錄的權限，以便 **save SVG file**。

不需要額外的系統相依性。

## 步驟 1：初始化 SVG document

第一步是建立一個全新的 **SVG document** 物件。此物件代表根 `<svg>` 元素，並提供加入形狀、群組及其他 SVG 結構的方法。

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*為何重要*：初始化文件會自動定義畫布大小與 XML 命名空間，這對任何 **create vector graphic** 工作流程都是必須的。

## 步驟 2：定義紅色圓形元素

接著，加入實際的圖形內容。本例在 (50, 50) 位置繪製半徑為 40 px 的紅色圓形。

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*為何重要*：使用字典來設定屬性可讓程式碼保持簡潔，且日後修改屬性時更為方便——在 **export SVG image** 時更換顏色或尺寸時特別有用。

## 步驟 3：附加其他元素（可選）

你可以透過加入更多形狀、文字或群組來擴充圖形。以下示範一個可選步驟，為圓形加上黑色描邊。

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*小技巧*：重新使用 `svg_doc.circle` 並傳入不同參數，即可在不手動處理 XML 字串的情況下建立 **create vector graphic** 層。

## 步驟 4：將 SVG 儲存至檔案

最後，將記憶體中的 SVG 寫入磁碟。此時會執行 **save SVG file** 的動作。

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

腳本執行完畢後，你會在 `output` 資料夾內找到 `circle.svg`。在瀏覽器或 SVG 編輯器中開啟該檔案，即可看到帶有細黑色輪廓的紅色圓形。

### 預期輸出（原始 SVG）

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

若在瀏覽器中檢視此檔案，會看到位於 100 × 100 像素畫布中心的紅色圓形。

## 如何使用動態資料建立 SVG

有時需要根據執行時資料（例如圖表點位、使用者頭像）產生 SVG。相同的模式同樣適用：

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*為何可行*：此函式將 **how to create SVG** 的邏輯抽象化，讓你可以傳入任意半徑或填色。此做法在批次處理或回傳 SVG 圖片的 API 端點上具備良好擴充性。

## 匯出 SVG image 供網頁使用

若需直接將 SVG 嵌入 HTML 或透過 HTTP 傳送，可將 **export SVG image** 為字串：

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

將字串以 Base64 編碼後即可使用 data URI，這在許多網頁情境下可省去額外的 **save SVG file** 請求。

## 常見陷阱與避免方法

| 問題 | 發生原因 | 解決方法 |
|-------|----------------|-----|
| 缺少命名空間 | 某些函式庫不會自動加入 `xmlns`。 | Ensure `svgwrite.Drawing` is used or manually set `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| 屬性名稱無效 | SVG 區分大小寫；`"strokeWidth"` 無法辨識。 | Use the SVG‑spec attribute names (`stroke-width`). |
| 覆寫檔案 | 重新執行腳本可能在未提示的情況下覆寫已存在的檔案。 | Check `os.path.exists(output_path)` before calling `saveas`. |
| 輸出字串過大 | 匯出非常大的 SVG 可能會佔用大量記憶體。 | Stream the output to a file using `svg_doc.write(output_path)` instead of `tostring()`. |

處理這些邊緣案例可確保你的 **create SVG document** 程式在正式環境中具備韌性。

## 完整範例

將所有步驟整合在一起，以下是一個自包含的腳本，會建立紅色圓形、加入可選描邊，並 **save SVG file**：

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

執行此腳本會產生 `output/circle.svg`，可在任何現代瀏覽器開啟。此檔案展示了基本的 **create vector graphic**，你可以在此基礎上加入更多形狀、文字或動畫。
