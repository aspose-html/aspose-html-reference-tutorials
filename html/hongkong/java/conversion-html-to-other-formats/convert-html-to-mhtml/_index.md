# 如何使用 Aspose.HTML for Java 將 HTML 轉換為 MHTML

將 HTML 轉換為 MHTML 是一項常見需求，當您需要一個包含 HTML 頁面及其所有資源（圖片、CSS、腳本）的單一可攜檔案時。於本教學中，您將學習 **如何將 HTML 轉換為 MHTML**，了解如何 **將 HTML 儲存為 MHTML**，以及發現最佳的 **以 Java 方式載入 HTML 文件** 方法。無論是歸檔網頁、產生可直接寄送的電子郵件內容，或是建立報告流程，以下步驟都能快速協助您完成。

## 快速答案
- **主要的函式庫是什麼？** Aspose.HTML for Java  
- **實作需要多長時間？** 基本轉換大約需要 10‑15 分鐘  
- **需要授權嗎？** 測試時臨時授權即可；正式環境需購買正式授權  
- **可以批次處理檔案嗎？** 可以 – 在迴圈中包裝程式碼並重複使用相同的選項  
- **支援的輸出格式？** MHTML (`.mht`)，以及其他如 PDF、PNG 等格式  

## 什麼是 HTML 轉換為 MHTML？
HTML 轉換為 MHTML 會將標準網頁轉換為單一的 MIME 編碼檔案，將 HTML 標記與所有連結的資源（如圖片、樣式表與腳本）打包在一起。產生的 .mht 檔案是自包含的，可離線檢視、輕鬆分享，且能嵌入電子郵件中而不需外部依賴。

## 為什麼使用 Aspose.HTML for Java？
Aspose.HTML for Java 提供純 Java 引擎，能在不依賴外部瀏覽器的情況下轉換 HTML 內容，讓開發人員能完整掌控渲染、資源處理與輸出精確度。它支援批次處理、有效處理大型檔案，且提供多種輸出格式，是企業級文件產生與歸檔任務的理想選擇。

- **完整控制** 資源處理（您決定轉換器應追蹤連結的深度）  
- **無需外部瀏覽器** – 轉換完全在 JVM 上執行  
- **高保真度** – 產生的 MHTML 與瀏覽器中原始頁面完全相同  
- **可擴展** – 適用於單頁或大型批次工作  
- **支援 12 種以上輸出格式**（包括 MHTML、PDF、PNG、JPEG、SVG、EPUB），且可處理高達 500 MB 的檔案而無需將整個文件載入記憶體

3. **HTML 文件** – 您想要 **將 HTML 儲存為 MHTML** 的檔案。可以是任何本機的 `.html` 檔，或是執行時產生的頁面。

現在基礎已說明完畢，讓我們深入程式碼。

## 匯入套件

在您的 Java 類別中加入必要的匯入：

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## 步驟說明

### 步驟 1：載入 HTML 文件

`HTMLDocument` 類別代表已載入記憶體中以供後續處理的 HTML 檔案。  
此處我們透過提供檔案路徑 **以 Java 方式載入 HTML 文件**。`HTMLDocument` 會解析標記並為轉換做準備。

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### 步驟 2：初始化 MHTML 儲存選項

`MHTMLSaveOptions` 物件定義了轉換為 MHTML 的執行方式，包括編碼與資源處理。  
`MHTMLSaveOptions` 讓您調整轉換行為（例如資源處理、編碼）。

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### 步驟 3：設定資源處理規則

`ResourceHandlingOptions` 類別控制哪些外部資源會被嵌入以及爬蟲的深度。  
您可以決定轉換器追蹤連結資源的深度。將深度設定為 `1` 表示僅嵌入直接引用的資源（圖片、CSS），以保持輸出檔案大小在合理範圍。

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### 步驟 4：指定輸出路徑

`outputPath` 字串告訴函式庫將產生的 MHTML 檔案寫入何處。  
選擇 **MHTML** 檔案的儲存位置。

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### 步驟 5：執行轉換

`Converter.convertHTML` 靜態方法會讀取來源 `HTMLDocument`、套用 `MHTMLSaveOptions`，並寫出輸出檔案。  
此靜態 `convertHTML` 方法負責主要工作：讀取 `HTMLDocument`、套用 `options`，並將 MHTML 檔案寫入 `outputMHTML`。

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **專業提示：** 若需轉換大量檔案，請僅實例化一次 `MHTMLSaveOptions`，並在迴圈中重複使用，以提升效能。

## 資源處理深度如何影響 MHTML 大小？

較低的深度（例如 `1`）僅嵌入直接引用的資源，產生較小的 MHTML 檔案；較高的深度（例如 `3`）則會包含更深層的連結資產，雖會增大檔案大小，但可提升完整性。請依據您的儲存限制與對完整自包含輸出的需求來選擇深度。

## 如何將 HTML 轉換為 PDF（java html to pdf）– 快速說明

Aspose.HTML for Java 不僅限於 MHTML。如果您也需要產生 PDF，只需將 `MHTMLSaveOptions` 換成 `PdfSaveOptions`，並呼叫相同的 `Converter.convertHTML` 方法。此彈性讓您在不額外加入其他函式庫的情況下處理 **java html to pdf** 轉換。

## 常見問題與解決方案

| 問題 | 解決方案 |
|-------|----------|
| **MHTML 檔案缺少圖片** | 確保 `setMaxHandlingDepth` 設定足夠高以包含巢狀資源，或透過 `resourceHandlingOptions.getAdditionalResources()` 手動加入 |
| **不支援的 CSS 功能** | Aspose.HTML 遵循 HTML5/CSS3 標準；較舊或專有的 CSS 可能會被忽略。請簡化樣式表或直接在 HTML 中嵌入樣式 |
| **執行時 LicenseException** | 在開發期間套用臨時授權：`License license = new License(); license.setLicense("Aspose.HTML.Java.lic");` |
