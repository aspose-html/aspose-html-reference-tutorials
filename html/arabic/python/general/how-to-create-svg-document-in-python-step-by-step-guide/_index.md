# كيفية إنشاء مستند SVG في بايثون – دليل خطوة بخطوة

إذا كنت بحاجة إلى **إنشاء مستند SVG** برمجيًا، فإن هذا الدليل يوضح لك بالضبط كيفية ذلك. ستحصل على مثال كامل قابل للتنفيذ ينشئ رسمًا متجهيًا بسيطًا، يصدر صورة SVG، ويحفظ ملف SVG على القرص.

العمل مع ملفات SVG شائع عندما تريد رسومات مستقلة عن الدقة للصفحات الويب أو التقارير أو أيقونات واجهة المستخدم. في الأقسام التالية ستتعلم كيفية إعداد البيئة، بناء عناصر SVG، ومعالجة الحالات الخاصة مثل مساحات الأسماء المخصصة أو قيم السمات الديناميكية.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من أن لديك:

* تثبيت Python 3.8 أو أحدث.
* حزمة `svgwrite` (أو أي مكتبة توفر واجهة شبيهة بـ `SVGDocument`). قم بتثبيتها باستخدام:

```bash
pip install svgwrite
```

* صلاحية كتابة في الدليل الذي تخطط **لحفظ ملف SVG** فيه.

لا توجد تبعيات نظام إضافية مطلوبة.

## الخطوة 1: تهيئة مستند SVG

الخطوة الأولى هي إنشاء كائن **مستند SVG** جديد. هذا الكائن يمثل عنصر `<svg>` الجذري ويوفر طرقًا لإضافة أشكال، مجموعات، وبنات SVG أخرى.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*لماذا هذا مهم*: تهيئة المستند تحدد حجم اللوحة ومساحة الاسم XML تلقائيًا، وهو أمر أساسي لأي سير عمل **إنشاء رسم متجهي**.

## الخطوة 2: تعريف عنصر دائرة حمراء

بعد ذلك، تضيف المحتوى الرسومي الفعلي. في هذا المثال نرسم دائرة حمراء متمركزة عند (50, 50) بنصف قطر 40 بكسل.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*لماذا هذا مهم*: استخدام قاموس للسمات يبقي الشيفرة نظيفة ويسهل تعديل الخصائص لاحقًا—مفيد عندما **تصدّر صورة SVG** بألوان أو أحجام مختلفة.

## الخطوة 3: إلحاق عناصر إضافية (اختياري)

يمكنك توسيع الرسم بإضافة المزيد من الأشكال أو النص أو المجموعات. أدناه خطوة اختيارية تضيف حدًا أسود حول الدائرة.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*نصيحة احترافية*: إعادة استخدام `svg_doc.circle` بمعلمات مختلفة يتيح لك **إنشاء رسم متجهي** بطبقات دون التعامل يدويًا مع سلاسل XML.

## الخطوة 4: حفظ SVG إلى ملف

أخيرًا، اكتب الـ SVG الموجود في الذاكرة إلى القرص. هذه هي اللحظة التي يحدث فيها عملية **حفظ ملف SVG**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

عند انتهاء السكريبت، ستجد `circle.svg` داخل مجلد `output`. فتح الملف في متصفح أو محرر SVG يظهر دائرة حمراء ذات حدود سوداء رقيقة.

### النتيجة المتوقعة (SVG خام)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

إذا عرفت الملف في متصفح، سترى الدائرة الحمراء متمركزة على لوحة بحجم 100 × 100 بكسل.

## كيفية إنشاء SVG ببيانات ديناميكية

غالبًا ما تحتاج إلى توليد SVG بناءً على بيانات وقت التشغيل (مثل نقاط المخطط أو صور المستخدمين). النمط نفسه ينطبق:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*لماذا هذا يعمل*: الدالة تجريد منطق **كيفية إنشاء SVG**، مما يسمح لك باستدعائها بأي نصف قطر أو لون تعبئة. هذا النهج يتوسع جيدًا للمعالجة الدفعية أو نقاط النهاية API التي تُعيد صور SVG.

## تصدير صورة SVG للاستخدام على الويب

إذا كنت بحاجة إلى تضمين SVG مباشرة في HTML أو إرساله عبر HTTP، يمكنك **تصدير صورة SVG** كسلسلة نصية:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

ترميز السلسلة كـ Base64 يتيح لك استخدام URI بيانات، مما يلغي الحاجة إلى طلب **حفظ ملف SVG** منفصل في العديد من سيناريوهات الويب.

## المشكلات الشائعة وكيفية تجنبها

| المشكلة | لماذا يحدث | الحل |
|---------|------------|------|
| فقدان مساحة الاسم | بعض المكتبات لا تضيف `xmlns` تلقائيًا. | تأكد من استخدام `svgwrite.Drawing` أو اضبط يدويًا `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| أسماء السمات غير صالحة | SVG حساس لحالة الأحرف؛ `"strokeWidth"` غير معترف به. | استخدم أسماء السمات وفق مواصفات SVG (`stroke-width`). |
| الكتابة فوق الملف | إعادة تشغيل السكريبت قد يكتب فوق ملف موجود دون تحذير. | تحقق من `os.path.exists(output_path)` قبل استدعاء `saveas`. |
| سلاسل الإخراج الكبيرة | تصدير SVG كبير جدًا قد يستهلك الذاكرة. | قم ببث الإخراج إلى ملف باستخدام `svg_doc.write(output_path)` بدلاً من `tostring()`. |

معالجة هذه الحالات الخاصة تضمن أن روتين **إنشاء مستند SVG** يكون قويًا في بيئات الإنتاج.

## مثال كامل يعمل

بجمع كل شيء معًا، إليك سكريبت مستقل ينشئ دائرة حمراء، يضيف حدًا اختياريًا، ويحفظ ملف SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

تشغيل هذا السكريبت ينشئ `output/circle.svg`، والذي يمكنك فتحه في أي متصفح حديث. الملف يوضح **إنشاء رسم متجهي** أساسي يمكنك توسيعه بمزيد من الأشكال أو النص أو الرسوم المتحركة.

## الخلاصة

أنت الآن تعرف كيف **تنشئ مستند SVG** في بايثون، **كيف تنشئ عناصر SVG** برمجيًا، وأفضل الممارسات لـ **حفظ ملف SVG**، **تصدير صورة SVG**، و**إنشاء رسم متجهي**. يغطي المثال التهيئة، إنشاء العناصر، التنسيق الاختياري، وحفظ الملف، مما يمنحك أساسًا قويًا لتصميم رسومات أكثر تعقيدًا مثل المخططات، الأيقونات، أو الرسوم التوضيحية الديناميكية.
