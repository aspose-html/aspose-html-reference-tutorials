# كيفية تحويل HTML إلى MHTML باستخدام Aspose.HTML for Java

تحويل HTML إلى MHTML هو طلب شائع عندما تحتاج إلى ملف واحد محمول يحتوي على صفحة HTML مع جميع مواردها (الصور، CSS، السكريبتات). في هذا الدرس ستتعلم **كيفية تحويل HTML إلى MHTML** باستخدام Aspose.HTML for Java، وتعرف كيف **تحفظ HTML كـ MHTML**، وتكتشف أفضل طريقة **لتحميل مستند HTML بأسلوب Java**. سواءً كنت تقوم بأرشفة صفحات الويب، أو توليد محتوى جاهز للبريد الإلكتروني، أو بناء خط أنابيب تقارير، فإن الخطوات أدناه ستوصلك إلى الهدف بسرعة.

## إجابات سريعة
- **ما هي المكتبة الأساسية؟** Aspose.HTML for Java  
- **كم من الوقت تستغرق عملية التنفيذ؟** حوالي 10‑15 دقيقة للتحويل الأساسي  
- **هل أحتاج إلى ترخيص؟** ترخيص مؤقت يكفي للاختبار؛ الترخيص الكامل مطلوب للإنتاج  
- **هل يمكنني معالجة الملفات على دفعات؟** نعم – ضع الكود داخل حلقة وأعد استخدام نفس الخيارات  
- **المخرجات المدعومة؟** MHTML (`.mht`)، بالإضافة إلى صيغ أخرى مثل PDF، PNG، إلخ.

## ما هو تحويل HTML إلى MHTML؟
تحويل HTML إلى MHTML يحول صفحة ويب قياسية إلى ملف MIME مشفر واحد يجمع بين شفرة HTML وجميع الموارد المرتبطة مثل الصور، أوراق الأنماط، والسكريبتات. الملف الناتج بامتداد .mht يكون مستقلاً، مما يسمح بالعرض دون اتصال، مشاركة سهلة، وتضمينه في رسائل البريد الإلكتروني دون الاعتماد على موارد خارجية.

## لماذا نستخدم Aspose.HTML for Java؟
توفر Aspose.HTML for Java محركًا نقيًا بلغة Java يحول محتوى HTML دون الاعتماد على متصفحات خارجية، مما يمنح المطورين تحكمًا كاملاً في العرض، معالجة الموارد، ودقة المخرجات. يدعم المعالجة على دفعات، يتعامل بفعالية مع الملفات الكبيرة، ويقدم مجموعة واسعة من صيغ الإخراج، مما يجعله مثاليًا لتوليد المستندات على مستوى المؤسسات ومهام الأرشفة.

- **تحكم كامل** في معالجة الموارد (أنت تقرر إلى أي عمق يجب أن يتبع المحول الروابط)  
- **بدون متصفحات خارجية** – يتم التحويل بالكامل على JVM  
- **دقة عالية** – ملف MHTML الناتج يبدو تمامًا كما في المتصفح الأصلي  
- **قابلية التوسع** – مناسب للصفحات الفردية أو وظائف الدفعات الكبيرة  
- **يدعم أكثر من 12 صيغة إخراج** (بما في ذلك MHTML، PDF، PNG، JPEG، SVG، EPUB) ويمكنه معالجة ملفات تصل إلى 500 ميغابايت دون تحميل المستند بالكامل في الذاكرة.

## استيراد الحزم

أضف الاستيرادات المطلوبة إلى فئة Java الخاصة بك:

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## دليل خطوة بخطوة

### الخطوة 1: تحميل مستند HTML

تمثل فئة `HTMLDocument` ملف HTML تم تحميله إلى الذاكرة للمعالجة اللاحقة.  
هنا نقوم **بتحميل مستند HTML بأسلوب Java** عن طريق توفير مسار الملف. تقوم فئة `HTMLDocument` بتحليل الشفرة وتحضيرها للتحويل.

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### الخطوة 2: تهيئة خيارات حفظ MHTML

كائن `MHTMLSaveOptions` يحدد كيفية تنفيذ التحويل إلى MHTML، بما في ذلك الترميز ومعالجة الموارد.  
يتيح لك كائن `MHTMLSaveOptions` تعديل سلوك التحويل (مثل معالجة الموارد، الترميز).

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### الخطوة 3: ضبط قواعد معالجة الموارد

تتحكم فئة `ResourceHandlingOptions` في الموارد الخارجية التي يتم تضمينها وإلى أي عمق يتجول الزاحف.  
يمكنك التحكم في عمق متابعة المحول للموارد المرتبطة. ضبط العمق إلى `1` يعني تضمين الموارد الفورية فقط (الصور، CSS)، مما يحافظ على حجم المخرجات معقولًا.

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### الخطوة 4: تحديد مسار الإخراج

سلسلة `outputPath` تخبر المكتبة أين تكتب ملف MHTML الناتج.  
اختر المكان الذي تريد حفظ ملف **MHTML** فيه.

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### الخطوة 5: تنفيذ التحويل

طريقة `Converter.convertHTML` الثابتة تقرأ `HTMLDocument` المصدر، تطبق `MHTMLSaveOptions`، وتكتب ملف الإخراج.  
طريقة `convertHTML` الثابتة تقوم بالعمل الرئيسي: تقرأ `HTMLDocument`، تطبق `options`، وتكتب ملف MHTML إلى `outputMHTML`.

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **نصيحة احترافية:** إذا كنت تحتاج إلى تحويل العديد من الملفات، أنشئ كائن `MHTMLSaveOptions` مرة واحدة وأعد استخدامه داخل حلقة لتحسين الأداء.

## كيف يؤثر عمق معالجة الموارد على حجم MHTML؟

عمق أقل (مثل `1`) يضم فقط الموارد المشار إليها مباشرة، مما ينتج ملف MHTML أصغر، بينما عمق أعلى (مثل `3`) يضيف موارد مرتبطة بعمق أكبر، مما يزيد حجم الملف لكنه يحسن الاكتمال. اختر العمق بناءً على قيود التخزين وأهمية الحصول على ملف مكتمل ذاتيًا.

## ملاحظة سريعة حول تحويل HTML إلى PDF (java html to pdf)

Aspose.HTML for Java لا يقتصر على MHTML فقط. إذا كنت تحتاج أيضًا إلى توليد ملفات PDF، ما عليك سوى استبدال `MHTMLSaveOptions` بـ `PdfSaveOptions` واستدعاء نفس طريقة `Converter.convertHTML`. هذه المرونة تسمح لك بمعالجة تحويلات **java html to pdf** دون إضافة مكتبات إضافية.
