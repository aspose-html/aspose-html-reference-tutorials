# تحويل canvas إلى PDF باستخدام Aspose.HTML for Java

غالبًا ما تعتمد تجارب الويب التفاعلية على عنصر **Canvas** في HTML5. من خلال رسم الرسومات باستخدام JavaScript يمكنك إنشاء مخططات، توقيعات، أو توضيحات مخصصة مباشرة في المتصفح. في العديد من السيناريوهات ستحتاج إلى **تحويل canvas إلى PDF** حتى يمكن طباعة الرسومات أو أرشفتها أو مشاركتها. يوضح هذا البرنامج التعليمي بالضبط كيفية إجراء هذا التحويل باستخدام JavaScript مع Aspose.HTML for Java، مع تغطية إنشاء canvas، رسم النص، حفظ ملف HTML، وتصديره إلى مستند PDF.

## إجابات سريعة
- **ما معنى “convert canvas to PDF”؟** يعني أخذ المحتوى المرئي المُعرض على عنصر HTML5 Canvas وإنشاء مستند PDF يحافظ على هذا الشكل.  
- **أي مكتبة تتولى التحويل؟** توفر Aspose.HTML for Java واجهة برمجة تطبيقات موثوقة من جانب الخادم لتحويل HTML (بما في ذلك Canvas) إلى PDF.  
- **هل أحتاج إلى متصفح لإجراء التحويل؟** لا. يتم تشغيل التحويل على بيئة تشغيل Java، لذا يمكنك أتمتة إنشاء PDF على الخادم أو في خدمة الخلفية.  
- **هل يمكنني رسم نص على الـ canvas قبل التحويل؟** بالطبع – سنعرض مثالًا بسيطًا بـ JavaScript يكتب “Hello World” على الـ canvas.  
- **ما هي المتطلبات الأساسية؟** Java JDK، مكتبة Aspose.HTML for Java، وبيئة تطوير Java (Eclipse، IntelliJ، إلخ).  

## كيفية تحويل canvas إلى PDF باستخدام Aspose.HTML for Java؟
حمّل ملف HTML الخاص بك الذي يحتوي على عنصر `<canvas>` واستدعِ `Converter.convert` – هذه الدعوة الوحيدة تقوم برسم الـ canvas وجميع ميزات HTML5 المرتبطة به إلى صفحة PDF. تتعامل الواجهة البرمجية تلقائيًا مع تضمين الخطوط، دقة الألوان، والحفاظ على التخطيط، لذا تحصل على PDF جاهز للطباعة في سطرين فقط من كود Java.

## ما هو “convert canvas to PDF”؟
يعني تحويل canvas إلى PDF تحويل الرسم القائم على البكسل من عنصر `<canvas>` إلى صفحة PDF صديقة للمتجهات. يتيح لك ذلك الحفاظ على المظهر الدقيق للـ canvas مع الاستفادة من ميزات PDF مثل الترقيم، النص القابل للبحث، والمشاركة السهلة.

## استيراد الحزم
فئة `HTMLDocument` هي الكائن الأساسي الذي يمثل ملف HTML في الذاكرة، بينما تقوم فئة `Converter` بتنفيذ عملية الرسم الفعلية إلى PDF.

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.PdfSaveOptions;
import java.io.FileWriter;
```

## لماذا حفظ الـ canvas كملف PDF؟
يعد حفظ الـ canvas كملف PDF خيارًا مثاليًا عندما تحتاج إلى تمثيل ثابت وقابل للطباعة للرسومات الديناميكية على الويب. يمكن عرض ملفات PDF عالميًا، وتدعم عرضًا عالي الدقة، ويمكن أرشفتها أو إرسالها بالبريد الإلكتروني دون فقدان الجودة. بالإضافة إلى ذلك، تحتفظ ملفات PDF بالمعلومات المتجهية عندما يكون ذلك ممكنًا، وتسمح لك بتضمين بيانات التعريف، ويمكن دمجها مع صفحات أخرى لإنشاء تقارير متعددة الصفحات، مما يجعلها مناسبة للمتطلبات الأرشيفية والامتثال.

## الخطوة 1: إنشاء عنصر canvas ورسم النص

### 1.1 إعداد HTML و JavaScript (رسم النص على الـ canvas)
فيما يلي سلسلة Java تحتوي على صفحة HTML بسيطة مع عنصر `<canvas>`. يحصل JavaScript المضمّن على سياق الـ canvas، يحدد خطًا، ويرسم العبارة **“Hello World”**.

```java
String code = "<canvas id='myCanvas' width='200' height='100' style='border:1px solid #d3d3d3;'></canvas>\n" +
              "<script>\n" +
              "    var c = document.getElementById('myCanvas');\n" +
              "    var context = c.getContext('2d');\n" +
              "    context.font = '20px Arial';\n" +
              "    context.fillStyle = 'red';\n" +
              "    context.fillText('Hello World', 40, 50);\n" +
              "</script>\n";
```

### 1.2 حفظ كود HTML إلى ملف (تحويل java html إلى pdf)
نكتب سلسلة HTML إلى `document.html`. سيتم تحميل هذا الملف لاحقًا بواسطة Aspose.HTML.

```java
try (FileWriter fileWriter = new FileWriter("document.html")) {
    fileWriter.write(code);
}
```

## تهيئة مستند HTML
حمّل ملف HTML إلى كائن `HTMLDocument` حتى يتمكن Aspose.HTML من معالجته.

```java
HTMLDocument document = new HTMLDocument("document.html");
```

## تحويل HTML (مع Canvas) إلى PDF
أخيرًا، استخدم فئة `Converter` لتحويل مستند HTML إلى ملف PDF. هذه الخطوة **تحفظ الـ canvas كملف PDF** وتكمل سير عمل “convert canvas to PDF”.

```java
try {
    Converter.convertHTML(
        document,
        new PdfSaveOptions(),
        "output.pdf"
    );
} finally {
    if (document != null) {
        document.dispose();
    }
}
```

### النتيجة المتوقعة
تشغيل البرنامج ينشئ `output.pdf`. عند فتح ملف PDF يظهر النص الأحمر “Hello World” بالضبط كما ظهر على الـ canvas في صفحة HTML الأصلية.

## كيفية إنشاء PDF من الـ canvas باستخدام Java
