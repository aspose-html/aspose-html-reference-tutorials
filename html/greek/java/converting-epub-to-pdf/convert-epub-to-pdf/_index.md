## Προαπαιτούμενα

1. **Java Development Kit** – JDK 8 ή νεότερο εγκατεστημένο στο μηχάνημά σας.  
2. **Aspose.HTML for Java** – Κατεβάστε το πιο πρόσφατο JAR από την επίσημη σελίδα **[here](https://releases.aspose.com/html/java/)**.  
3. **EPUB source file** – Έχετε ένα αρχείο EPUB έτοιμο (π.χ., `input.epub`). Οποιοδήποτε συμβατό με πρότυπα EPUB θα λειτουργήσει.

Με αυτά τα στοιχεία, είστε έτοιμοι να ξεκινήσετε τη μετατροπή.

## Εισαγωγή πακέτων

Το πακέτο `com.aspose.html` παρέχει την κλάση `Converter` που χρησιμοποιείται για τη μετατροπή EPUB‑σε‑PDF.  

```java
import com.aspose.html.saving.PdfSaveOptions;
import com.aspose.html.converters.Converter;
import java.io.FileInputStream;
```

## Φόρτωση του αρχείου EPUB

`FileInputStream` ανοίγει ένα αρχείο ως ροή byte, την οποία ο μετατροπέας διαβάζει για να επεξεργαστεί το περιεχόμενο του EPUB.  

```java
try (FileInputStream fileInputStream = new FileInputStream("input.epub")) {
```

## Ορισμός επιλογών μετατροπής PDF

`PdfSaveOptions` ρυθμίζει πώς αποδίδεται το PDF, επιτρέποντάς σας να ορίσετε μέγεθος σελίδας, περιθώρια, ενσωμάτωση γραμματοσειρών και άλλες ιδιότητες.  

```java
PdfSaveOptions options = new PdfSaveOptions();
```

## Μετατροπή EPUB σε PDF

`Converter.convertEPUB` εκτελεί την πραγματική μετατροπή από ροή εισόδου EPUB σε ροή εξόδου PDF χρησιμοποιώντας τις επιλογές που δώσατε.  

```java
Converter.convertEPUB(fileInputStream, options, "output.pdf");
```

Μετά την εκτέλεση αυτής της γραμμής, το `output.pdf` εμφανίζεται στον φάκελο του έργου σας, έτοιμο για διανομή ή περαιτέρω επεξεργασία.

## Συχνά προβλήματα και λύσεις

| Πρόβλημα | Αιτία | Διόρθωση |
|----------|-------|----------|
| **Κενές σελίδες στο PDF** | Λείπουν CSS ή γραμματοσειρές στο EPUB | Βεβαιωθείτε ότι το EPUB περιλαμβάνει όλους τους πόρους ή ενσωματώστε γραμματοσειρές μέσω `PdfSaveOptions` |
| **Λανθασμένο μέγεθος σελίδας** | Οι προεπιλεγμένες επιλογές δεν ταιριάζουν με τις απαιτήσεις σας | Καλέστε `options.setPageSize()` ή `options.setMargins()` πριν από τη μετατροπή |
| **OutOfMemoryError σε μεγάλα EPUB** | Τα μεγάλα αρχεία καταναλώνουν πολύ μνήμη | Αυξήστε το μέγεθος heap της JVM (`-Xmx2g`) ή επεξεργαστείτε το EPUB σε τμήματα |
