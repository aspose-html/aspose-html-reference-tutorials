# Πώς να δημιουργήσετε έγγραφο SVG σε Python – οδηγός βήμα‑βήμα

Αν χρειάζεστε να **create SVG document** προγραμματιστικά, αυτό το tutorial σας δείχνει ακριβώς πώς. Θα λάβετε ένα πλήρες, εκτελέσιμο παράδειγμα που δημιουργεί ένα απλό vector graphic, εξάγει το SVG image και αποθηκεύει το SVG file στο δίσκο.

Η εργασία με αρχεία SVG είναι συνηθισμένη όταν θέλετε γραφικά ανεξάρτητα από την ανάλυση για ιστοσελίδες, αναφορές ή εικονίδια UI. Στις επόμενες ενότητες θα μάθετε πώς να ρυθμίσετε το περιβάλλον, να δημιουργήσετε τα SVG elements και να αντιμετωπίσετε edge cases όπως προσαρμοσμένα namespaces ή δυναμικές τιμές χαρακτηριστικών.

## Προαπαιτούμενα

* Εγκατεστημένο Python 3.8 ή νεότερο.
* Το πακέτο `svgwrite` (ή οποιαδήποτε βιβλιοθήκη που παρέχει ένα API παρόμοιο με `SVGDocument`). Εγκαταστήστε το με:

```bash
pip install svgwrite
```

* Δικαιώματα εγγραφής στον φάκελο όπου σκοπεύετε να **save SVG file**.

Δεν απαιτούνται πρόσθετες εξαρτήσεις συστήματος.

## Βήμα 1: Αρχικοποίηση του εγγράφου SVG

Το πρώτο βήμα είναι να δημιουργήσετε ένα νέο αντικείμενο **SVG document**. Αυτό το αντικείμενο αντιπροσωπεύει το ριζικό στοιχείο `<svg>` και παρέχει μεθόδους για την προσθήκη σχημάτων, ομάδων και άλλων SVG constructs.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Γιατί είναι σημαντικό*: Η αρχικοποίηση του εγγράφου ορίζει αυτόματα το μέγεθος του καμβά και το XML namespace, κάτι που είναι απαραίτητο για οποιοδήποτε workflow **create vector graphic**.

## Βήμα 2: Ορισμός στοιχείου κόκκινου κύκλου

Στη συνέχεια, προσθέτετε το πραγματικό περιεχόμενο γραφικών. Σε αυτό το παράδειγμα σχεδιάζουμε έναν κόκκινο κύκλο κεντραρισμένο στο (50, 50) με ακτίνα 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Γιατί είναι σημαντικό*: Η χρήση ενός dictionary για τα attributes διατηρεί τον κώδικα καθαρό και διευκολύνει την τροποποίηση των ιδιοτήτων αργότερα—χρήσιμο όταν **export SVG image** με διαφορετικά χρώματα ή μεγέθη.

## Βήμα 3: Προσθήκη επιπλέον στοιχείων (προαιρετικό)

Μπορείτε να επεκτείνετε το γραφικό προσθέτοντας περισσότερα σχήματα, κείμενο ή ομάδες. Παρακάτω υπάρχει ένα προαιρετικό βήμα που προσθέτει μια μαύρη γραμμή περιγράμματος γύρω από τον κύκλο.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Συμβουλή*: Η επαναχρησιμοποίηση του `svg_doc.circle` με διαφορετικές παραμέτρους σας επιτρέπει να **create vector graphic** στρώσεις χωρίς να χειρίζεστε χειροκίνητα XML strings.

## Βήμα 4: Αποθήκευση του SVG σε αρχείο

Τέλος, γράψτε το SVG στη μνήμη στο δίσκο. Αυτή είναι η στιγμή που εκτελείται η ενέργεια **save SVG file**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Όταν το script ολοκληρωθεί, θα βρείτε το `circle.svg` μέσα στο φάκελο `output`. Το άνοιγμα του αρχείου σε πρόγραμμα περιήγησης ή επεξεργαστή SVG εμφανίζει έναν κόκκινο κύκλο με λεπτό μαύρο περίγραμμα.

### Αναμενόμενη έξοδος (ακατέργαστο SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Αν προβάλετε το αρχείο σε πρόγραμμα περιήγησης, θα δείτε τον κόκκινο κύκλο κεντραρισμένο σε καμβά 100 × 100 pixel.

## Πώς να δημιουργήσετε SVG με δυναμικά δεδομένα

Συχνά χρειάζεται να δημιουργήσετε SVGs βάσει δεδομένων χρόνου εκτέλεσης (π.χ., σημεία διαγράμματος, avatar χρηστών). Ισχύει το ίδιο πρότυπο:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Γιατί λειτουργεί*: Η συνάρτηση αφαιρεί τη λογική **how to create SVG**, επιτρέποντάς σας να την καλέσετε με οποιαδήποτε ακτίνα ή χρώμα γεμίσματος. Αυτή η προσέγγιση κλιμακώνεται καλά για επεξεργασία παρτίδων ή API endpoints που επιστρέφουν SVG images.

## Εξαγωγή SVG image για χρήση στο web

Αν χρειάζεστε να ενσωματώσετε το SVG απευθείας σε HTML ή να το στείλετε μέσω HTTP, μπορείτε να **export SVG image** ως συμβολοσειρά:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Η κωδικοποίηση της συμβολοσειράς ως Base64 σας επιτρέπει να χρησιμοποιήσετε ένα data URI, το οποίο εξαλείφει την ανάγκη για ξεχωριστό αίτημα **save SVG file** σε πολλές διαδικτυακές περιπτώσεις.

## Συνηθισμένα προβλήματα και πώς να τα αποφύγετε

| Πρόβλημα | Γιατί συμβαίνει | Διόρθωση |
|-------|----------------|-----|
| Missing namespace | Some libraries don’t add `xmlns` automatically. | Ensure `svgwrite.Drawing` is used or manually set `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Invalid attribute names | SVG is case‑sensitive; `"strokeWidth"` is not recognized. | Use the SVG‑spec attribute names (`stroke-width`). |
| Overwriting the file | Re‑running the script may overwrite an existing file without warning. | Check `os.path.exists(output_path)` before calling `saveas`. |
| Large output strings | Exporting very large SVGs can consume memory. | Stream the output to a file using `svg_doc.write(output_path)` instead of `tostring()`. |

Η αντιμετώπιση αυτών των edge cases εξασφαλίζει ότι η ρουτίνα **create SVG document** είναι ανθεκτική σε περιβάλλοντα παραγωγής.

## Πλήρες λειτουργικό παράδειγμα

Συνδυάζοντας όλα, εδώ είναι ένα αυτόνομο script που δημιουργεί έναν κόκκινο κύκλο, προσθέτει ένα προαιρετικό περίγραμμα και αποθηκεύει το SVG file:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Η εκτέλεση αυτού του script δημιουργεί το `output/circle.svg`, το οποίο μπορείτε να ανοίξετε σε οποιοδήποτε σύγχρονο πρόγραμμα περιήγησης. Το αρχείο δείχνει ένα βασικό **create vector graphic** που μπορείτε να επεκτείνετε με περισσότερα σχήματα, κείμενο ή animations.
