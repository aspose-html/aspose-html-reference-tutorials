# Aspose.HTML for Java के साथ HTML को MHTML में कैसे बदलें

HTML को MHTML में बदलना एक सामान्य आवश्यकता है जब आपको एकल, पोर्टेबल फ़ाइल चाहिए जिसमें HTML पेज और उसकी सभी संसाधन (छवियां, CSS, स्क्रिप्ट) शामिल हों। इस ट्यूटोरियल में आप **HTML को MHTML में कैसे बदलें** सीखेंगे, **HTML को MHTML के रूप में सहेजें**, और **HTML दस्तावेज़ Java‑स्टाइल** लोड करने का सबसे अच्छा तरीका जानेंगे। चाहे आप वेब पेजों को आर्काइव कर रहे हों, ई‑मेल‑तैयार कंटेंट जेनरेट कर रहे हों, या रिपोर्टिंग पाइपलाइन बना रहे हों, नीचे दिए गए चरण आपको जल्दी से लक्ष्य तक पहुंचाएंगे।

## त्वरित उत्तर
- **मुख्य लाइब्रेरी कौन सी है?** Aspose.HTML for Java  
- **इम्प्लीमेंटेशन में कितना समय लगेगा?** बेसिक कन्वर्ज़न के लिए लगभग 10‑15 मिनट  
- **क्या लाइसेंस चाहिए?** परीक्षण के लिए एक टेम्पररी लाइसेंस पर्याप्त है; प्रोडक्शन के लिए पूर्ण लाइसेंस आवश्यक है  
- **क्या मैं फाइलों को बैच‑प्रोसेस कर सकता हूँ?** हाँ – कोड को लूप में रखें और वही विकल्प पुन: उपयोग करें  
- **समर्थित आउटपुट?** MHTML (`.mht`), साथ ही PDF, PNG आदि जैसे अन्य फॉर्मेट

## HTML से MHTML रूपांतरण क्या है?
HTML से MHTML रूपांतरण एक मानक वेब पेज को एकल MIME‑एन्कोडेड फ़ाइल में बदलता है जो HTML मार्कअप को सभी जुड़े संसाधनों (छवियां, स्टाइलशीट, स्क्रिप्ट) के साथ बंडल करता है। परिणामी .mht फ़ाइल स्व-समाहित होती है, जिससे ऑफ़लाइन व्यूइंग, आसान शेयरिंग, और ई‑मेल में बाहरी निर्भरताओं के बिना एम्बेड करना संभव हो जाता है।

## चरण‑दर‑चरण गाइड

### चरण 1: HTML दस्तावेज़ लोड करें

`HTMLDocument` क्लास एक HTML फ़ाइल को मेमोरी में लोड करके आगे प्रोसेसिंग के लिए तैयार करती है।  
यहाँ हम **HTML दस्तावेज़ Java‑स्टाइल** में फ़ाइल पाथ प्रदान करके लोड करते हैं। `HTMLDocument` क्लास मार्कअप को पार्स करती है और रूपांतरण के लिए तैयार करती है।

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### चरण 2: MHTML सेव ऑप्शन्स इनिशियलाइज़ करें

`MHTMLSaveOptions` ऑब्जेक्ट यह निर्धारित करता है कि MHTML में रूपांतरण कैसे किया जाएगा, जिसमें एन्कोडिंग और रिसोर्स हैंडलिंग शामिल है।  
`MHTMLSaveOptions` ऑब्जेक्ट आपको रूपांतरण के व्यवहार को ट्यून करने की अनुमति देता है (जैसे, रिसोर्स हैंडलिंग, एन्कोडिंग)।

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### चरण 3: रिसोर्स हैंडलिंग नियम सेट करें

`ResourceHandlingOptions` क्लास यह नियंत्रित करती है कि कौन से बाहरी संसाधन एम्बेड किए जाएंगे और क्रॉलर कितनी गहराई तक जाएगा।  
आप तय कर सकते हैं कि कन्वर्टर लिंक किए गए संसाधनों को कितनी गहराई तक फॉलो करे। `1` की गहराई सेट करने का मतलब है केवल तत्काल संसाधन (छवियां, CSS) एम्बेड हों, जिससे आउटपुट साइज उचित रहता है।

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### चरण 4: आउटपुट पाथ निर्दिष्ट करें

`outputPath` स्ट्रिंग लाइब्रेरी को बताती है कि परिणामी MHTML फ़ाइल कहाँ लिखी जानी चाहिए।  
निर्धारित करें कि परिणामी **MHTML** फ़ाइल कहाँ सहेजी जानी चाहिए।

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### चरण 5: रूपांतरण निष्पादित करें

`Converter.convertHTML` स्टैटिक मेथड स्रोत `HTMLDocument` पढ़ता है, `MHTMLSaveOptions` लागू करता है, और आउटपुट फ़ाइल लिखता है।  
स्टैटिक `convertHTML` मेथड मुख्य कार्य करता है: यह `HTMLDocument` पढ़ता है, `options` लागू करता है, और MHTML फ़ाइल को `outputMHTML` में लिखता है।

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **प्रो टिप:** यदि आपको कई फ़ाइलें बदलनी हैं, तो `MHTMLSaveOptions` को एक बार इंस्टैंशिएट करके लूप में पुन: उपयोग करें, इससे प्रदर्शन बेहतर होगा।

## रिसोर्स हैंडलिंग डिप्थ MHTML साइज को कैसे प्रभावित करती है?

कम डिप्थ (जैसे `1`) केवल सीधे रेफ़रेंस किए गए संसाधनों को एम्बेड करती है, जिससे MHTML फ़ाइल छोटा रहता है, जबकि अधिक डिप्थ (जैसे `3`) गहरे लिंक्ड एसेट्स को शामिल करती है, जिससे फ़ाइल साइज बढ़ता है लेकिन पूर्णता बेहतर होती है। अपने स्टोरेज प्रतिबंध और पूर्ण‑स्व-समाहित आउटपुट की महत्त्वता के आधार पर डिप्थ चुनें।

## HTML को PDF (java html to pdf) में कैसे बदलें – एक त्वरित नोट

Aspose.HTML for Java केवल MHTML तक सीमित नहीं है। यदि आपको PDF भी जनरेट करना है, तो बस `MHTMLSaveOptions` को `PdfSaveOptions` से बदलें और वही `Converter.convertHTML` मेथड कॉल करें। यह लचीलापन आपको **java html to pdf** रूपांतरण बिना अतिरिक्त लाइब्रेरी के करने देता है।

**प्रश्न 4: अन्य रूपांतरण टूल्स की तुलना में Aspose.HTML for Java के क्या फायदे हैं?**

उत्तर: नहीं। रूपांतरण स्थैतिक मार्कअप और संसाधनों को कैप्चर करता है; रन‑टाइम पर JavaScript द्वारा जेनरेट किया गया डायनामिक कंटेंट निष्पादित नहीं होता।
