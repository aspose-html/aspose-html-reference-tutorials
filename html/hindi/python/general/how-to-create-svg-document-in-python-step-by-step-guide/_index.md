# Python में SVG दस्तावेज़ कैसे बनाएं – चरण‑दर‑चरण गाइड

यदि आपको प्रोग्रामेटिक रूप से **create SVG document** बनाना है, तो यह ट्यूटोरियल आपको ठीक-ठीक दिखाता है। आपको एक पूर्ण, चलाने योग्य उदाहरण मिलेगा जो एक सरल वेक्टर ग्राफिक बनाता है, SVG image को एक्सपोर्ट करता है, और SVG फ़ाइल को डिस्क पर सहेजता है।

वेब पेज, रिपोर्ट या UI आइकॉन के लिए रिज़ॉल्यूशन‑इंडिपेंडेंट ग्राफिक्स चाहिए हों तो SVG फ़ाइलों के साथ काम करना आम है। अगले सेक्शन में आप सीखेंगे कि पर्यावरण कैसे सेट‑अप करें, SVG तत्व कैसे बनाएं, और कस्टम नेमस्पेस या डायनामिक एट्रिब्यूट वैल्यू जैसे एज केस को कैसे हैंडल करें।

## Prerequisites

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* Python 3.8 या उससे नया स्थापित हो।
* `svgwrite` पैकेज (या कोई भी लाइब्रेरी जो `SVGDocument`‑like API प्रदान करती हो)। इसे इस कमांड से इंस्टॉल करें:

```bash
pip install svgwrite
```

* उस डायरेक्टरी में लिखने की अनुमति जहाँ आप **save SVG file** सहेजने की योजना बना रहे हैं।

कोई अतिरिक्त सिस्टम निर्भरताएँ आवश्यक नहीं हैं।

## Step 1: SVG दस्तावेज़ को इनिशियलाइज़ करें

पहला कदम एक नया **SVG document** ऑब्जेक्ट बनाना है। यह ऑब्जेक्ट रूट `<svg>` एलिमेंट का प्रतिनिधित्व करता है और शैप्स, ग्रुप्स, तथा अन्य SVG कॉन्स्ट्रक्ट्स जोड़ने के मेथड्स प्रदान करता है।

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: डॉक्यूमेंट को इनिशियलाइज़ करने से कैनवास साइज और XML नेमस्पेस ऑटोमैटिकली सेट हो जाता है, जो किसी भी **create vector graphic** वर्कफ़्लो के लिए आवश्यक है।

## Step 2: लाल सर्कल एलिमेंट परिभाषित करें

अब आप वास्तविक ग्राफिक कंटेंट जोड़ते हैं। इस उदाहरण में हम (50, 50) के केंद्र पर 40 px रेडियस वाला लाल सर्कल ड्रॉ करते हैं।

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: एट्रिब्यूट्स को डिक्शनरी में रखकर कोड साफ़ रहता है और बाद में प्रॉपर्टीज़ बदलना आसान हो जाता है—विशेषकर जब आप **export SVG image** विभिन्न रंगों या साइजों के साथ करना चाहते हों।

## Step 3: अतिरिक्त एलिमेंट्स जोड़ें (वैकल्पिक)

आप ग्राफिक को और शैप्स, टेक्स्ट या ग्रुप्स जोड़कर विस्तारित कर सकते हैं। नीचे एक वैकल्पिक कदम है जो सर्कल के चारों ओर काली स्ट्रोक जोड़ता है।

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: विभिन्न पैरामीटर्स के साथ `svg_doc.circle` को दोबारा उपयोग करने से आप **create vector graphic** लेयर्स बना सकते हैं बिना XML स्ट्रिंग्स को मैन्युअली हैंडल किए।

## Step 4: SVG को फ़ाइल में सहेजें

अंत में, इन‑मेमोरी SVG को डिस्क पर लिखें। यही वह क्षण है जब **save SVG file** ऑपरेशन होता है।

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

जब स्क्रिप्ट समाप्त होगी, तो आप `circle.svg` को `output` फ़ोल्डर के अंदर पाएंगे। ब्राउज़र या किसी SVG एडिटर में फ़ाइल खोलने पर आपको एक पतली काली आउटलाइन वाला लाल सर्कल दिखेगा।

### अपेक्षित आउटपुट (कच्चा SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

यदि आप फ़ाइल को ब्राउज़र में देखते हैं, तो आपको 100 × 100 पिक्सेल कैनवास में केंद्रित लाल सर्कल दिखाई देगा।

## डायनामिक डेटा के साथ SVG कैसे बनाएं

अक्सर आपको रन‑टाइम डेटा (जैसे चार्ट पॉइंट्स, यूज़र अवतार) के आधार पर SVG जनरेट करने की जरूरत पड़ती है। वही पैटर्न लागू होता है:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: यह फ़ंक्शन **how to create SVG** लॉजिक को एब्स्ट्रैक्ट करता है, जिससे आप इसे किसी भी रेडियस या फ़िल कलर के साथ कॉल कर सकते हैं। यह एप्रोच बैच प्रोसेसिंग या API एंडपॉइंट्स के लिए स्केलेबल है जो SVG इमेजेज रिटर्न करते हैं।

## वेब उपयोग के लिए SVG image को एक्सपोर्ट करें

यदि आपको SVG को सीधे HTML में एम्बेड करना है या HTTP पर भेजना है, तो आप **export SVG image** को स्ट्रिंग के रूप में प्राप्त कर सकते हैं:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

स्ट्रिंग को Base64 में एन्कोड करने से आप डेटा URI का उपयोग कर सकते हैं, जिससे कई वेब परिदृश्यों में अलग **save SVG file** रिक्वेस्ट की आवश्यकता नहीं रहती।

## सामान्य pitfalls और उन्हें कैसे टालें

| Issue | Why it happens | Fix |
|-------|----------------|-----|
| Namespace गायब | कुछ लाइब्रेरीज़ `xmlns` को स्वचालित रूप से नहीं जोड़तीं। | सुनिश्चित करें कि `svgwrite.Drawing` का उपयोग किया गया है या मैन्युअली `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"` सेट करें। |
| अमान्य attribute नाम | SVG केस‑सेंसिटिव है; `"strokeWidth"` पहचाना नहीं जाता। | SVG‑स्पेसिफिक attribute नामों (`stroke-width`) का उपयोग करें। |
| फ़ाइल का ओवरराइट होना | स्क्रिप्ट को फिर से चलाने से मौजूदा फ़ाइल बिना चेतावनी के ओवरराइट हो सकती है। | `saveas` कॉल करने से पहले `os.path.exists(output_path)` जांचें। |
| बड़ी आउटपुट स्ट्रिंग्स | बहुत बड़े SVG को एक्सपोर्ट करने से मेमोरी का उपयोग बढ़ सकता है। | `tostring()` के बजाय `svg_doc.write(output_path)` का उपयोग करके आउटपुट को फ़ाइल में स्ट्रीम करें। |

इन एज केसों को संभालने से आपका **create SVG document** रूटीन प्रोडक्शन वातावरण में मजबूत बनता है।

## पूर्ण कार्यशील उदाहरण

सब कुछ एक साथ लाते हुए, यहाँ एक स्व-निहित स्क्रिप्ट है जो लाल सर्कल बनाता है, वैकल्पिक स्ट्रोक जोड़ता है, और SVG फ़ाइल सहेजता है:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

इस स्क्रिप्ट को चलाने पर `output/circle.svg` बनता है, जिसे आप किसी भी आधुनिक ब्राउज़र में खोल सकते हैं। फ़ाइल एक बुनियादी **create vector graphic** दर्शाती है जिसे आप और शैप्स, टेक्स्ट या एनीमेशन जोड़कर विस्तारित कर सकते हैं।
