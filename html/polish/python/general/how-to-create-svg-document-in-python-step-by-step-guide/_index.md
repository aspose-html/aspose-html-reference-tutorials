# Jak utworzyć dokument SVG w Pythonie – przewodnik krok po kroku

Jeśli potrzebujesz **create SVG document** programowo, ten tutorial pokaże Ci dokładnie, jak to zrobić. Otrzymasz kompletny, działający przykład, który tworzy prostą grafikę wektorową, eksportuje obraz SVG i zapisuje plik SVG na dysku.

Praca z plikami SVG jest powszechna, gdy potrzebujesz grafik niezależnych od rozdzielczości dla stron internetowych, raportów lub ikon UI. W kolejnych sekcjach nauczysz się, jak skonfigurować środowisko, budować elementy SVG oraz obsługiwać przypadki brzegowe, takie jak niestandardowe przestrzenie nazw czy dynamiczne wartości atrybutów.

## Wymagania wstępne

* Zainstalowany Python 3.8 lub nowszy.
* Pakiet `svgwrite` (lub dowolna biblioteka udostępniająca API podobne do `SVGDocument`). Zainstaluj go za pomocą:

```bash
pip install svgwrite
```

* Uprawnienia do zapisu w katalogu, w którym planujesz **save SVG file**.

Nie są wymagane dodatkowe zależności systemowe.

## Krok 1: Inicjalizacja dokumentu SVG

Pierwszym krokiem jest utworzenie nowego obiektu **SVG document**. Obiekt ten reprezentuje element root `<svg>` i udostępnia metody do dodawania kształtów, grup oraz innych konstrukcji SVG.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Dlaczego to ważne*: Inicjalizacja dokumentu automatycznie definiuje rozmiar płótna i przestrzeń nazw XML, co jest niezbędne w każdym procesie **create vector graphic**.

## Krok 2: Definiowanie czerwonego elementu koła

Następnie dodajesz rzeczywistą zawartość graficzną. W tym przykładzie rysujemy czerwone koło o środku w (50, 50) i promieniu 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Dlaczego to ważne*: Użycie słownika dla atrybutów utrzymuje kod przejrzystym i ułatwia późniejszą modyfikację właściwości — przydatne, gdy **export SVG image** z różnymi kolorami lub rozmiarami.

## Krok 3: Dodawanie dodatkowych elementów (opcjonalnie)

Możesz rozbudować grafikę, dodając więcej kształtów, tekst lub grupy. Poniżej znajduje się opcjonalny krok, który dodaje czarny obrys wokół koła.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Wskazówka*: Ponowne użycie `svg_doc.circle` z różnymi parametrami pozwala na tworzenie warstw **create vector graphic** bez ręcznego manipulowania ciągami XML.

## Krok 4: Zapisz SVG do pliku

Na koniec zapisz SVG znajdujące się w pamięci na dysk. To jest moment, w którym wykonywana jest operacja **save SVG file**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Po zakończeniu skryptu znajdziesz `circle.svg` w folderze `output`. Otwarcie pliku w przeglądarce lub edytorze SVG wyświetli czerwone koło z cienkim czarnym obrysem.

### Oczekiwany wynik (surowy SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Jeśli otworzysz plik w przeglądarce, zobaczysz czerwone koło wyśrodkowane na płótnie o wymiarach 100 × 100 pikseli.

## Jak tworzyć SVG z danymi dynamicznymi

Często trzeba generować SVG na podstawie danych w czasie rzeczywistym (np. punkty wykresu, awatary użytkowników). Stosuje się ten sam wzorzec:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Dlaczego to działa*: Funkcja abstrahuje logikę **how to create SVG**, umożliwiając wywołanie jej z dowolnym promieniem lub kolorem wypełnienia. Takie podejście dobrze skaluje się przy przetwarzaniu wsadowym lub endpointach API zwracających obrazy SVG.

## Eksport obrazu SVG do użytku w sieci

Jeśli potrzebujesz osadzić SVG bezpośrednio w HTML lub wysłać go przez HTTP, możesz **export SVG image** jako ciąg znaków:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Kodowanie ciągu jako Base64 pozwala użyć data URI, co eliminuje potrzebę osobnego żądania **save SVG file** w wielu scenariuszach webowych.

## Typowe pułapki i jak ich unikać

| Problem | Dlaczego się pojawia | Rozwiązanie |
|-------|----------------|-----|
| Brak przestrzeni nazw | Niektóre biblioteki nie dodają `xmlns` automatycznie. | Upewnij się, że używasz `svgwrite.Drawing` lub ręcznie ustaw `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Nieprawidłowe nazwy atrybutów | SVG jest wrażliwy na wielkość liter; `"strokeWidth"` nie jest rozpoznawany. | Używaj nazw atrybutów zgodnych ze specyfikacją SVG (`stroke-width`). |
| Nadpisywanie pliku | Ponowne uruchomienie skryptu może nadpisać istniejący plik bez ostrzeżenia. | Sprawdź `os.path.exists(output_path)` przed wywołaniem `saveas`. |
| Duże ciągi wyjściowe | Eksport bardzo dużych SVG może zużywać pamięć. | Strumieniuj wyjście do pliku używając `svg_doc.write(output_path)` zamiast `tostring()`. |

Rozwiązywanie tych przypadków brzegowych zapewnia, że Twoja procedura **create SVG document** jest solidna w środowiskach produkcyjnych.

## Pełny działający przykład

Łącząc wszystko razem, oto samodzielny skrypt, który tworzy czerwone koło, dodaje opcjonalny obrys i zapisuje plik SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Uruchomienie tego skryptu tworzy `output/circle.svg`, który możesz otworzyć w dowolnej nowoczesnej przeglądarce. Plik demonstruje podstawowy **create vector graphic**, który możesz rozbudować o dodatkowe kształty, tekst lub animacje.
