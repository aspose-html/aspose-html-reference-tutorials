# HTML を MHTML に変換する方法（Aspose.HTML for Java）

HTML を MHTML に変換することは、HTML ページとそのすべてのリソース（画像、CSS、スクリプト）を含む単一のポータブルファイルが必要な場合に一般的な要件です。このチュートリアルでは、Aspose.HTML for Java を使用して **HTML を MHTML に変換する方法** を学び、**HTML を MHTML として保存** する方法を確認し、**Java スタイルで HTML ドキュメントをロード** する最適な方法を発見します。ウェブページのアーカイブ、メール用コンテンツの生成、レポートパイプラインの構築など、以下の手順で迅速に実現できます。

## クイック回答
- **主要なライブラリは何ですか？** Aspose.HTML for Java  
- **実装にはどれくらい時間がかかりますか？** 基本的な変換で約10〜15分  
- **ライセンスは必要ですか？** テスト用には一時ライセンスで十分です。本番環境ではフルライセンスが必要です  
- **ファイルをバッチ処理できますか？** はい – ループでコードをラップし、同じオプションを再利用できます  
- **サポートされている出力は？** MHTML（`.mht`）に加えて、PDF、PNG などの他の形式

## HTML から MHTML への変換とは？
HTML から MHTML への変換は、標準的なウェブページを単一の MIME エンコードされたファイルに変換し、HTML マークアップと画像、スタイルシート、スクリプトなどのすべてのリンクされたリソースをまとめます。生成された .mht ファイルは自己完結型で、オフラインでの閲覧、簡単な共有、外部依存なしでメール本文に埋め込むことが可能です。

## なぜ Aspose.HTML for Java を使用するのか？
Aspose.HTML for Java は、外部ブラウザに依存せずに HTML コンテンツを変換できる純粋な Java エンジンを提供し、開発者にレンダリング、リソース処理、出力の忠実度に対する完全な制御を可能にします。バッチ処理をサポートし、大容量ファイルを効率的に処理でき、幅広い出力フォーマットを提供するため、エンタープライズ向けの文書生成やアーカイブ作業に最適です。

- **リソース処理の完全な制御**（コンバータがリンクをたどる深さを決定できます）  
- **外部ブラウザ不要** – 変換は JVM 上だけで実行されます  
- **高忠実度** – 生成された MHTML はブラウザ上の元ページとまったく同じに見えます  
- **スケーラビリティ** – 単一ページでも大規模バッチジョブでも対応可能  
- **12 以上の出力フォーマットに対応**（MHTML、PDF、PNG、JPEG、SVG、EPUB など）で、メモリに全文書を読み込まずに最大 500 MB のファイルを処理できます。

基本が以上ですので、コードに入りましょう。

## パッケージのインポート

Java クラスに必要なインポートを追加します：

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## ステップバイステップガイド

### ステップ 1: HTML ドキュメントのロード

`HTMLDocument` クラスは、さらに処理するためにメモリにロードされた HTML ファイルを表します。  
ここではファイルパスを指定して **Java スタイルで HTML ドキュメントをロード** します。`HTMLDocument` クラスはマークアップを解析し、変換の準備を行います。

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### ステップ 2: MHTML 保存オプションの初期化

`MHTMLSaveOptions` オブジェクトは、エンコーディングやリソース処理を含め、MHTML への変換方法を定義します。  
`MHTMLSaveOptions` を使用すると、変換の動作（例: リソース処理、エンコーディング）を調整できます。

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### ステップ 3: リソース処理ルールの設定

`ResourceHandlingOptions` クラスは、埋め込む外部リソースとクローラの深さを制御します。  
コンバータがリンクされたリソースをたどる深さを設定できます。深さを `1` に設定すると、直接参照されるリソース（画像、CSS）のみが埋め込まれ、出力サイズを抑えることができます。

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### ステップ 4: 出力パスの指定

`outputPath` 文字列は、生成された MHTML ファイルを書き込む場所をライブラリに指示します。  
生成された **MHTML** ファイルの保存先を選択してください。

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### ステップ 5: 変換の実行

`Converter.convertHTML` 静的メソッドは、ソースの `HTMLDocument` を読み取り、`MHTMLSaveOptions` を適用し、出力ファイルを書き込みます。  
この静的 `convertHTML` メソッドが主要な処理を行い、`HTMLDocument` を読み込み、`options` を適用し、MHTML ファイルを `outputMHTML` に書き出します。

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **プロのコツ:** 多数のファイルを変換する場合は、`MHTMLSaveOptions` を一度だけインスタンス化し、ループ内で再利用してパフォーマンスを向上させてください。

## リソース処理の深さは MHTML のサイズにどのように影響しますか？

深さが低い（例: `1`）場合は直接参照されたリソースのみが埋め込まれ、MHTML ファイルは小さくなります。一方、深さが高い（例: `3`）場合は、より深くリンクされた資産も含まれ、ファイルサイズは大きくなりますが、完全性が向上します。ストレージの制約と完全に自己完結した出力の重要性に応じて深さを選択してください。

## HTML を PDF に変換する方法（java html to pdf） – 簡単な注意点

Aspose.HTML for Java は MHTML に限定されません。PDF を生成する必要がある場合は、`MHTMLSaveOptions` を `PdfSaveOptions` に置き換えて同じ `Converter.convertHTML` メソッドを呼び出すだけです。この柔軟性により、余分なライブラリを追加せずに **java html to pdf** 変換を処理できます。

## よくある問題と解決策

| 問題 | 解決策 |
|-------|----------|
| **MHTML ファイルの画像が欠落** | `setMaxHandlingDepth` を十分に高く設定してネストされたリソースを含めるか、`resourceHandlingOptions.getAdditionalResources()` を使用して手動で追加してください。 |
| **サポートされていない CSS 機能** | Aspose.HTML は HTML5/CSS3 標準に従います。古いまたは独自の CSS は無視される可能性があります。スタイルシートを簡素化するか、スタイルを HTML に直接埋め込んでください。 |
| **実行時の LicenseException** | 開発時に一時ライセンスを適用してください: `License license = new License(); license.setLicense("Aspose.HTML.Java.lic");` |
