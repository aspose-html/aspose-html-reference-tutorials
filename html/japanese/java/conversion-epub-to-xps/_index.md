## Aspose.HTML で **load epub in java** の方法

`HtmlDocument` クラスは、Aspose.HTML のコアオブジェクトで、HTML、EPUB、その他のウェブベースのドキュメントをメモリ上で表現します。Maven 依存関係を追加した後、EPUB ファイルパスをコンストラクタに渡して `HtmlDocument` をインスタンス化し、`load()` を呼び出してコンテンツをオブジェクトモデルに取り込みます。

`HtmlLoadOptions` は、暗号化された EPUB ファイル用のパスワードなどのロードパラメータを指定できます。EPUB がパスワードで保護されている場合でも、`HtmlLoadOptions` にパスワードを渡すことでロードできます。ライブラリはコンテナをリアルタイムで復号し、変換のためにコンテンツが正しくレンダリングされることを保証します。パスワードを設定した後、ライブラリはコンテナをリアルタイムで復号し、変換のためにコンテンツが正しくレンダリングされます。
