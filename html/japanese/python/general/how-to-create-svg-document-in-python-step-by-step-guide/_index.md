# PythonでSVGドキュメントを作成する方法 – ステップバイステップガイド

プログラムで **create SVG document** が必要な場合、このチュートリアルで具体的な手順を示します。シンプルなベクターグラフィックを作成し、SVG画像をエクスポートし、SVGファイルをディスクに保存する、完全な実行可能サンプルが得られます。

Webページ、レポート、UIアイコンなど、解像度に依存しないグラフィックが必要な場合、SVGファイルを扱うことは一般的です。以下のセクションでは、環境のセットアップ、SVG要素の構築、カスタム名前空間や動的属性値といったエッジケースの処理方法を学びます。

## 前提条件

* Python 3.8 以上がインストールされていること。
* `svgwrite` パッケージ（または `SVGDocument` に似た API を提供する任意のライブラリ）。以下でインストールします：

```bash
pip install svgwrite
```

* **save SVG file** を行うディレクトリへの書き込み権限があること。

追加のシステム依存は必要ありません。

## ステップ 1: SVGドキュメントの初期化

最初のステップは新しい **SVG document** オブジェクトを作成することです。このオブジェクトはルート `<svg>` 要素を表し、シェイプやグループ、その他の SVG 構造を追加するメソッドを提供します。

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: ドキュメントの初期化によりキャンバスサイズと XML 名前空間が自動的に設定され、**create vector graphic** ワークフローに不可欠です。

## ステップ 2: 赤い円要素の定義

次に、実際のグラフィックコンテンツを追加します。この例では、中心が (50, 50) で半径 40 px の赤い円を描きます。

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: 属性を辞書で管理することでコードがすっきりし、後からプロパティを変更しやすくなります。異なる色やサイズで **export SVG image** する際に便利です。

## ステップ 3: 追加要素の追加（オプション）

さらにシェイプ、テキスト、グループを追加してグラフィックを拡張できます。以下は円の周囲に黒いストロークを追加するオプションの手順です。

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: 異なるパラメータで `svg_doc.circle` を再利用することで、XML文字列を手動で扱うことなく **create vector graphic** レイヤーを作成できます。

## ステップ 4: SVGをファイルに保存

最後に、メモリ上の SVG をディスクに書き込みます。ここで **save SVG file** 操作が実行されます。

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

スクリプトが終了すると、`output` フォルダー内に `circle.svg` が作成されます。ブラウザや SVG エディタでファイルを開くと、細い黒い輪郭の赤い円が表示されます。

### 期待される出力（生の SVG）

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

ブラウザでファイルを表示すると、100 × 100 ピクセルのキャンバスの中央に赤い円が描かれているのが確認できます。

## 動的データで SVG を作成する方法

実行時データ（例: チャートのポイント、ユーザーアバター）に基づいて SVG を生成する必要があることがよくあります。同じパターンが適用できます：

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: この関数は **how to create SVG** ロジックを抽象化し、任意の半径や塗り色で呼び出すことができます。このアプローチはバッチ処理や SVG 画像を返す API エンドポイントに適しています。

## Web 用に SVG 画像をエクスポート

SVG を HTML に直接埋め込んだり HTTP 経由で送信したりする必要がある場合、**export SVG image** を文字列として取得できます：

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

文字列を Base64 エンコードすれば data URI として使用でき、多くの Web シナリオで別途 **save SVG file** のリクエストが不要になります。

## よくある落とし穴と回避方法

| 問題 | 発生理由 | 対策 |
|-------|----------------|-----|
| 名前空間が欠如している | 一部のライブラリは `xmlns` を自動的に追加しません。 | `svgwrite.Drawing` を使用するか、手動で `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"` を設定してください。 |
| 属性名が無効 | SVG は大文字小文字を区別します。`"strokeWidth"` は認識されません。 | SVG 仕様の属性名（`stroke-width`）を使用してください。 |
| ファイルの上書き | スクリプトを再実行すると、警告なしに既存ファイルが上書きされる可能性があります。 | `saveas` を呼び出す前に `os.path.exists(output_path)` を確認してください。 |
| 出力文字列が大きすぎる | 非常に大きな SVG をエクスポートするとメモリを消費します。 | `tostring()` の代わりに `svg_doc.write(output_path)` を使用してファイルにストリーム出力してください。 |

これらのエッジケースに対処することで、**create SVG document** 手順が本番環境でも堅牢になります。

## 完全な動作例

すべてをまとめると、赤い円を作成し、オプションでストロークを追加し、SVG ファイルを保存する自己完結型スクリプトは以下の通りです：

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

このスクリプトを実行すると `output/circle.svg` が作成され、任意の最新ブラウザで開くことができます。このファイルは基本的な **create vector graphic** を示しており、さらにシェイプ、テキスト、アニメーションなどで拡張できます。
