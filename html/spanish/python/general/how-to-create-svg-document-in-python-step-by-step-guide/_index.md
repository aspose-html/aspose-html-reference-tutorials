# Cómo crear un documento SVG en Python – guía paso a paso

Si necesitas **create SVG document** programáticamente, este tutorial te muestra exactamente cómo. Obtendrás un ejemplo completo y ejecutable que crea un gráfico vectorial simple, exporta la **SVG image**, y guarda el **SVG file** en disco.

Trabajar con archivos SVG es común cuando deseas gráficos independientes de la resolución para páginas web, informes o íconos de UI. En las secciones siguientes aprenderás cómo configurar el entorno, construir los elementos SVG y manejar casos límite como espacios de nombres personalizados o valores de atributos dinámicos.

## Requisitos previos

* Python 3.8 o superior instalado.
* El paquete `svgwrite` (o cualquier biblioteca que proporcione una API similar a `SVGDocument`). Instálalo con:

```bash
pip install svgwrite
```

* Permiso de escritura en el directorio donde planeas **save SVG file**.

No se requieren dependencias del sistema adicionales.

## Paso 1: Inicializar el documento SVG

El primer paso es crear un nuevo objeto **SVG document**. Este objeto representa el elemento raíz `<svg>` y proporciona métodos para agregar formas, grupos y otras construcciones SVG.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: Inicializar el documento define el tamaño del lienzo y el espacio de nombres XML automáticamente, lo cual es esencial para cualquier flujo de trabajo **create vector graphic**.

## Paso 2: Definir un elemento de círculo rojo

A continuación, agregas el contenido gráfico real. En este ejemplo dibujamos un círculo rojo centrado en (50, 50) con un radio de 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: Usar un diccionario para los atributos mantiene el código limpio y facilita la modificación de propiedades más adelante—útil cuando **export SVG image** con diferentes colores o tamaños.

## Paso 3: Añadir elementos adicionales (opcional)

Puedes ampliar el gráfico añadiendo más formas, texto o grupos. A continuación se muestra un paso opcional que agrega un trazo negro alrededor del círculo.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: Reutilizar `svg_doc.circle` con diferentes parámetros te permite crear capas **create vector graphic** sin manejar manualmente cadenas XML.

## Paso 4: Guardar el SVG en un archivo

Finalmente, escribe el SVG en memoria en el disco. Este es el momento en que ocurre la operación **save SVG file**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Cuando el script termina, encontrarás `circle.svg` dentro de la carpeta `output`. Abrir el archivo en un navegador o en un editor SVG muestra un círculo rojo con un contorno negro delgado.

### Salida esperada (SVG sin procesar)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Si visualizas el archivo en un navegador, verás el círculo rojo centrado en un lienzo de 100 × 100 píxeles.

## Cómo crear SVG con datos dinámicos

A menudo necesitas generar SVGs basados en datos en tiempo de ejecución (p. ej., puntos de gráfico, avatares de usuario). Se aplica el mismo patrón:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: La función abstrae la lógica de **how to create SVG**, permitiéndote llamarla con cualquier radio o color de relleno. Este enfoque escala bien para procesamiento por lotes o puntos finales de API que devuelven imágenes SVG.

## Exportar imagen SVG para uso web

Si necesitas incrustar el SVG directamente en HTML o enviarlo por HTTP, puedes **export SVG image** como una cadena:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Codificar la cadena como Base64 te permite usar un data URI, lo que elimina la necesidad de una solicitud separada de **save SVG file** en muchos escenarios web.

## Errores comunes y cómo evitarlos

| Problema | Por qué ocurre | Solución |
|----------|----------------|----------|
| Falta de espacio de nombres | Algunas bibliotecas no añaden `xmlns` automáticamente. | Asegúrate de usar `svgwrite.Drawing` o establece manualmente `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Nombres de atributos inválidos | SVG es sensible a mayúsculas y minúsculas; `"strokeWidth"` no se reconoce. | Utiliza los nombres de atributos según la especificación SVG (`stroke-width`). |
| Sobrescribir el archivo | Ejecutar de nuevo el script puede sobrescribir un archivo existente sin advertencia. | Comprueba `os.path.exists(output_path)` antes de llamar a `saveas`. |
| Cadenas de salida grandes | Exportar SVGs muy grandes puede consumir memoria. | Transmite la salida a un archivo usando `svg_doc.write(output_path)` en lugar de `tostring()`. |

Abordar estos casos límite garantiza que tu rutina **create SVG document** sea robusta en entornos de producción.

## Ejemplo completo en funcionamiento

Uniendo todo, aquí tienes un script autónomo que crea un círculo rojo, agrega un trazo opcional y guarda el archivo SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Ejecutar este script crea `output/circle.svg`, que puedes abrir en cualquier navegador moderno. El archivo demuestra un **create vector graphic** básico que puedes ampliar con más formas, texto o animaciones.
