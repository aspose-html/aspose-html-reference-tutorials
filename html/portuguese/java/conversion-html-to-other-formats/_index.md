## Perguntas Frequentes

**Q: Posso usar o Aspose.HTML for Java em uma aplicação comercial?**  
A: Sim. Uma licença comercial válida é necessária para uso em produção; um teste gratuito está disponível para avaliação.

**Q: Quais versões do Java são suportadas?**  
A: O Aspose.HTML for Java suporta Java 8, 11 e versões posteriores.

**Q: A biblioteca lida com CSS e JavaScript externos?**  
A: Absolutamente. O renderizador processa arquivos CSS vinculados e executa JavaScript para garantir que o PDF corresponda ao layout original da página.

**Q: Quão grandes podem ser os arquivos HTML para conversão?**  
A: A biblioteca é otimizada para documentos grandes; no entanto, o consumo de memória cresce com o tamanho da página, portanto, considere fazer streaming de entradas grandes.

**Q: É possível personalizar os metadados do PDF durante a conversão?**  
A: Sim. Você pode definir título, autor, assunto e palavras‑chave via o objeto `PdfSaveOptions` antes de salvar.
