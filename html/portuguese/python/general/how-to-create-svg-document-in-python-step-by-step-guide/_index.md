# Como criar um documento SVG em Python – guia passo a passo

Se você precisa **criar documento SVG** programaticamente, este tutorial mostra exatamente como. Você obterá um exemplo completo e executável que cria um gráfico vetorial simples, exporta a imagem SVG e salva o arquivo SVG no disco.

Trabalhar com arquivos SVG é comum quando você deseja gráficos independentes de resolução para páginas da web, relatórios ou ícones de UI. Nas seções a seguir, você aprenderá como configurar o ambiente, construir os elementos SVG e lidar com casos extremos, como namespaces personalizados ou valores de atributos dinâmicos.

## Pré-requisitos

* Python 3.8 ou mais recente instalado.
* O pacote `svgwrite` (ou qualquer biblioteca que forneça uma API semelhante a `SVGDocument`). Instale‑o com:

```bash
pip install svgwrite
```

* Permissão de gravação no diretório onde você pretende **salvar arquivo SVG**.

Nenhuma dependência de sistema adicional é necessária.

## Etapa 1: Inicializar o documento SVG

O primeiro passo é criar um novo objeto **documento SVG**. Esse objeto representa o elemento raiz `<svg>` e fornece métodos para adicionar formas, grupos e outras construções SVG.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Por que isso importa*: Inicializar o documento define o tamanho da tela e o namespace XML automaticamente, o que é essencial para qualquer fluxo de trabalho de **criar gráfico vetorial**.

## Etapa 2: Definir um elemento de círculo vermelho

Em seguida, você adiciona o conteúdo gráfico real. Neste exemplo, desenhamos um círculo vermelho centrado em (50, 50) com raio de 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Por que isso importa*: Usar um dicionário para atributos mantém o código limpo e facilita a modificação das propriedades posteriormente — útil quando você **exporta imagem SVG** com cores ou tamanhos diferentes.

## Etapa 3: Anexar elementos adicionais (opcional)

Você pode expandir o gráfico adicionando mais formas, texto ou grupos. Abaixo está uma etapa opcional que adiciona um contorno preto ao redor do círculo.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Dica profissional*: Reutilizar `svg_doc.circle` com parâmetros diferentes permite que você **crie camadas de gráfico vetorial** sem manipular manualmente strings XML.

## Etapa 4: Salvar o SVG em um arquivo

Finalmente, escreva o SVG em memória no disco. Este é o momento em que a operação de **salvar arquivo SVG** ocorre.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Quando o script terminar, você encontrará `circle.svg` dentro da pasta `output`. Abrir o arquivo em um navegador ou editor SVG mostra um círculo vermelho com um contorno preto fino.

### Saída esperada (SVG bruto)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Se você visualizar o arquivo em um navegador, verá o círculo vermelho centrado em uma tela de 100 × 100 pixels.

## Como criar SVG com dados dinâmicos

Frequentemente você precisa gerar SVGs com base em dados em tempo de execução (por exemplo, pontos de gráfico, avatares de usuário). O mesmo padrão se aplica:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Por que isso funciona*: A função abstrai a lógica de **como criar SVG**, permitindo que você a chame com qualquer raio ou cor de preenchimento. Essa abordagem escala bem para processamento em lote ou endpoints de API que retornam imagens SVG.

## Exportar imagem SVG para uso na web

Se você precisar incorporar o SVG diretamente em HTML ou enviá‑lo via HTTP, pode **exportar imagem SVG** como uma string:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Codificar a string como Base64 permite usar um data URI, o que elimina a necessidade de uma solicitação separada de **salvar arquivo SVG** em muitos cenários web.

## Armadilhas comuns e como evitá‑las

| Problema | Por que acontece | Solução |
|----------|------------------|---------|
| Namespace ausente | Algumas bibliotecas não adicionam `xmlns` automaticamente. | Certifique‑se de usar `svgwrite.Drawing` ou defina manualmente `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Nomes de atributos inválidos | SVG diferencia maiúsculas de minúsculas; `"strokeWidth"` não é reconhecido. | Use os nomes de atributos da especificação SVG (`stroke-width`). |
| Sobrescrita do arquivo | Reexecutar o script pode sobrescrever um arquivo existente sem aviso. | Verifique `os.path.exists(output_path)` antes de chamar `saveas`. |
| Strings de saída grandes | Exportar SVGs muito grandes pode consumir memória. | Transmita a saída para um arquivo usando `svg_doc.write(output_path)` em vez de `tostring()`. |

Abordar esses casos extremos garante que sua rotina de **criar documento SVG** seja robusta em ambientes de produção.

## Exemplo completo em funcionamento

Juntando tudo, aqui está um script autônomo que cria um círculo vermelho, adiciona um contorno opcional e salva o arquivo SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Executar este script cria `output/circle.svg`, que você pode abrir em qualquer navegador moderno. O arquivo demonstra um **criar gráfico vetorial** básico que você pode estender com mais formas, texto ou animações.
