# Cách Chuyển Đổi HTML sang MHTML với Aspose.HTML cho Java

Việc chuyển đổi HTML sang MHTML là một nhu cầu phổ biến khi bạn cần một tệp duy nhất, di động chứa một trang HTML cùng với tất cả các tài nguyên của nó (hình ảnh, CSS, script). Trong hướng dẫn này, bạn sẽ học **cách chuyển đổi HTML sang MHTML** bằng Aspose.HTML cho Java, xem **cách lưu HTML dưới dạng MHTML**, và khám phá cách **tải tài liệu HTML theo kiểu Java**. Dù bạn đang lưu trữ các trang web, tạo nội dung sẵn sàng gửi email, hay xây dựng một quy trình báo cáo, các bước dưới đây sẽ giúp bạn thực hiện nhanh chóng.

## Câu trả lời nhanh
- **Thư viện chính là gì?** Aspose.HTML cho Java  
- **Thời gian thực hiện khoảng bao lâu?** Khoảng 10‑15 phút cho một chuyển đổi cơ bản  
- **Cần giấy phép không?** Giấy phép tạm thời đủ cho việc thử nghiệm; giấy phép đầy đủ cần thiết cho môi trường sản xuất  
- **Có thể xử lý hàng loạt file không?** Có – chỉ cần bọc mã trong vòng lặp và tái sử dụng cùng một tùy chọn  
- **Định dạng đầu ra được hỗ trợ?** MHTML (`.mht`), cộng thêm các định dạng khác như PDF, PNG, v.v.

## HTML sang MHTML là gì?
HTML sang MHTML là quá trình biến một trang web tiêu chuẩn thành một tệp MIME‑encoded duy nhất, gộp lại mã HTML cùng với tất cả các tài nguyên liên kết như hình ảnh, stylesheet và script. Tệp `.mht` tạo ra là tự chứa, cho phép xem offline, chia sẻ dễ dàng và nhúng vào email mà không cần phụ thuộc vào tài nguyên bên ngoài.

## Tại sao nên dùng Aspose.HTML cho Java?
Aspose.HTML cho Java cung cấp một engine thuần Java chuyển đổi nội dung HTML mà không dựa vào trình duyệt bên ngoài, cho phép nhà phát triển kiểm soát toàn bộ quá trình render, xử lý tài nguyên và độ chính xác của đầu ra. Nó hỗ trợ xử lý hàng loạt, xử lý các tệp lớn hiệu quả, và cung cấp nhiều định dạng đầu ra, làm cho nó trở thành lựa chọn lý tưởng cho các tác vụ tạo tài liệu và lưu trữ doanh nghiệp.

- **Kiểm soát đầy đủ** việc xử lý tài nguyên (bạn quyết định độ sâu mà bộ chuyển đổi sẽ theo các liên kết)  
- **Không cần trình duyệt bên ngoài** – quá trình chuyển đổi chạy hoàn toàn trên JVM  
- **Độ trung thực cao** – MHTML tạo ra trông giống hệt trang gốc trong trình duyệt  
- **Mở rộng** – phù hợp cho cả trang đơn và công việc batch lớn  
- **Hỗ trợ hơn 12 định dạng đầu ra** (bao gồm MHTML, PDF, PNG, JPEG, SVG, EPUB) và có thể xử lý các tệp lên tới 500 MB mà không cần tải toàn bộ tài liệu vào bộ nhớ.

## Nhập khẩu các gói

Thêm các import cần thiết vào lớp Java của bạn:

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## Hướng dẫn từng bước

### Bước 1: Tải tài liệu HTML

Lớp `HTMLDocument` đại diện cho một tệp HTML được tải vào bộ nhớ để xử lý tiếp.  
Ở đây chúng ta **tải tài liệu HTML theo kiểu Java** bằng cách cung cấp đường dẫn tệp. Lớp `HTMLDocument` sẽ phân tích markup và chuẩn bị cho việc chuyển đổi.

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### Bước 2: Khởi tạo tùy chọn lưu MHTML

Đối tượng `MHTMLSaveOptions` xác định cách thực hiện chuyển đổi sang MHTML, bao gồm mã hoá và xử lý tài nguyên.  
Đối tượng này cho phép bạn tinh chỉnh cách chuyển đổi hoạt động (ví dụ: xử lý tài nguyên, mã hoá).

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### Bước 3: Đặt quy tắc xử lý tài nguyên

Lớp `ResourceHandlingOptions` kiểm soát các tài nguyên bên ngoài nào sẽ được nhúng và độ sâu của trình thu thập.  
Bạn có thể kiểm soát độ sâu mà bộ chuyển đổi sẽ theo các liên kết. Đặt độ sâu `1` có nghĩa chỉ nhúng các tài nguyên trực tiếp (hình ảnh, CSS), giúp kích thước đầu ra hợp lý.

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### Bước 4: Xác định đường dẫn đầu ra

Chuỗi `outputPath` cho thư viện biết nơi ghi tệp MHTML kết quả.  
Chọn vị trí lưu tệp **MHTML** cuối cùng.

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### Bước 5: Thực hiện chuyển đổi

Phương thức tĩnh `Converter.convertHTML` đọc `HTMLDocument` nguồn, áp dụng `MHTMLSaveOptions`, và ghi tệp đầu ra.  
Phương thức tĩnh `convertHTML` thực hiện công việc nặng: đọc `HTMLDocument`, áp dụng `options`, và ghi tệp MHTML vào `outputMHTML`.

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **Mẹo chuyên nghiệp:** Nếu bạn cần chuyển đổi nhiều tệp, khởi tạo `MHTMLSaveOptions` một lần và tái sử dụng trong vòng lặp để cải thiện hiệu năng.

## Độ sâu xử lý tài nguyên ảnh hưởng như thế nào đến kích thước MHTML?

Độ sâu thấp hơn (ví dụ `1`) chỉ nhúng các tài nguyên được tham chiếu trực tiếp, tạo ra tệp MHTML nhỏ hơn, trong khi độ sâu cao hơn (ví dụ `3`) bao gồm các tài nguyên liên kết sâu hơn, làm tăng kích thước tệp nhưng cải thiện độ đầy đủ. Hãy chọn độ sâu dựa trên hạn chế lưu trữ và mức độ cần thiết của đầu ra tự chứa.

## Chuyển đổi HTML sang PDF (java html to pdf) – Ghi chú nhanh

Aspose.HTML cho Java không chỉ giới hạn ở MHTML. Nếu bạn cũng cần tạo PDF, chỉ cần thay `MHTMLSaveOptions` bằng `PdfSaveOptions` và gọi cùng một phương thức `Converter.convertHTML`. Tính linh hoạt này cho phép bạn thực hiện các chuyển đổi **java html to pdf** mà không cần thêm thư viện khác.
