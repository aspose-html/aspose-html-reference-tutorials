## Yêu cầu trước

1. **Java Development Kit** – JDK 8 hoặc mới hơn được cài đặt trên máy của bạn.  
2. **Aspose.HTML for Java** – Tải JAR mới nhất từ trang chính thức **[here](https://releases.aspose.com/html/java/)**.  
3. **EPUB source file** – Có một tệp EPUB sẵn sàng (ví dụ, `input.epub`). Bất kỳ EPUB nào tuân thủ tiêu chuẩn đều hoạt động.

Với những mục này đã sẵn sàng, bạn có thể bắt đầu chuyển đổi.

## Nhập gói

Gói `com.aspose.html` cung cấp lớp `Converter` được sử dụng cho việc chuyển đổi EPUB‑to‑PDF.  

```java
import com.aspose.html.saving.PdfSaveOptions;
import com.aspose.html.converters.Converter;
import java.io.FileInputStream;
```

## Tải tệp EPUB

`FileInputStream` mở một tệp dưới dạng luồng byte, mà bộ chuyển đổi sẽ đọc để xử lý nội dung EPUB.  

```java
try (FileInputStream fileInputStream = new FileInputStream("input.epub")) {
```

## Đặt tùy chọn chuyển đổi PDF

`PdfSaveOptions` cấu hình cách PDF được render, cho phép bạn đặt kích thước trang, lề, nhúng phông chữ và các thuộc tính khác.  

```java
PdfSaveOptions options = new PdfSaveOptions();
```

## Chuyển EPUB sang PDF

`Converter.convertEPUB` thực hiện quá trình chuyển đổi thực tế từ luồng đầu vào EPUB sang luồng đầu ra PDF bằng các tùy chọn bạn đã cung cấp.  

```java
Converter.convertEPUB(fileInputStream, options, "output.pdf");
```

Sau khi dòng này chạy, `output.pdf` sẽ xuất hiện trong thư mục dự án của bạn, sẵn sàng để phân phối hoặc xử lý tiếp.
