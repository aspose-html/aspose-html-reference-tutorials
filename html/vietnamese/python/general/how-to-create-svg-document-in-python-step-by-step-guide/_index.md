# Cách tạo tài liệu SVG trong Python – hướng dẫn từng bước

Nếu bạn cần **create SVG document** một cách lập trình, hướng dẫn này sẽ chỉ cho bạn cách thực hiện chính xác. Bạn sẽ nhận được một ví dụ đầy đủ, có thể chạy được, tạo một đồ họa vector đơn giản, xuất ảnh SVG, và lưu tệp SVG vào đĩa.

Làm việc với các tệp SVG là phổ biến khi bạn muốn đồ họa không phụ thuộc vào độ phân giải cho các trang web, báo cáo, hoặc biểu tượng UI. Trong các phần tiếp theo, bạn sẽ học cách thiết lập môi trường, xây dựng các phần tử SVG, và xử lý các trường hợp đặc biệt như không gian tên tùy chỉnh hoặc giá trị thuộc tính động.

## Yêu cầu trước

* Python 3.8 hoặc mới hơn đã được cài đặt.
* Gói `svgwrite` (hoặc bất kỳ thư viện nào cung cấp API giống `SVGDocument`). Cài đặt nó bằng:

```bash
pip install svgwrite
```

* Quyền ghi vào thư mục nơi bạn dự định **save SVG file**.

Không cần phụ thuộc hệ thống bổ sung.

## Bước 1: Khởi tạo tài liệu SVG

Bước đầu tiên là tạo một đối tượng **SVG document** mới. Đối tượng này đại diện cho phần tử gốc `<svg>` và cung cấp các phương thức để thêm hình dạng, nhóm và các cấu trúc SVG khác.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: Khởi tạo tài liệu xác định kích thước canvas và không gian tên XML một cách tự động, điều này thiết yếu cho bất kỳ quy trình **create vector graphic** nào.

## Bước 2: Định nghĩa phần tử vòng tròn màu đỏ

Tiếp theo, bạn thêm nội dung đồ họa thực tế. Trong ví dụ này, chúng ta vẽ một vòng tròn màu đỏ có tâm tại (50, 50) và bán kính 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: Sử dụng từ điển cho các thuộc tính giúp mã sạch sẽ và dễ dàng chỉnh sửa các thuộc tính sau này—hữu ích khi bạn **export SVG image** với các màu sắc hoặc kích thước khác nhau.

## Bước 3: Thêm các phần tử bổ sung (tùy chọn)

Bạn có thể mở rộng đồ họa bằng cách thêm nhiều hình dạng, văn bản hoặc nhóm. Dưới đây là một bước tùy chọn thêm một đường viền đen quanh vòng tròn.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: Tái sử dụng `svg_doc.circle` với các tham số khác nhau cho phép bạn **create vector graphic** các lớp mà không cần xử lý chuỗi XML một cách thủ công.

## Bước 4: Lưu SVG vào tệp

Cuối cùng, ghi SVG trong bộ nhớ ra đĩa. Đây là thời điểm thực hiện thao tác **save SVG file**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Khi script kết thúc, bạn sẽ thấy `circle.svg` trong thư mục `output`. Mở tệp trong trình duyệt hoặc trình chỉnh sửa SVG sẽ hiển thị một vòng tròn màu đỏ với viền đen mỏng.

### Kết quả mong đợi (SVG thô)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Nếu bạn xem tệp trong trình duyệt, bạn sẽ thấy vòng tròn màu đỏ được đặt ở trung tâm của canvas 100 × 100 pixel.

## Cách tạo SVG với dữ liệu động

Thường bạn cần tạo SVG dựa trên dữ liệu thời gian chạy (ví dụ: điểm biểu đồ, avatar người dùng). Mẫu tương tự được áp dụng:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: Hàm trừu tượng hoá logic **how to create SVG**, cho phép bạn gọi nó với bất kỳ bán kính hoặc màu nền nào. Cách tiếp cận này mở rộng tốt cho xử lý hàng loạt hoặc các endpoint API trả về ảnh SVG.

## Xuất ảnh SVG để sử dụng trên web

Nếu bạn cần nhúng SVG trực tiếp vào HTML hoặc gửi qua HTTP, bạn có thể **export SVG image** dưới dạng chuỗi:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Mã hoá chuỗi thành Base64 cho phép bạn sử dụng data URI, điều này loại bỏ nhu cầu một yêu cầu **save SVG file** riêng trong nhiều trường hợp web.

## Những lỗi thường gặp và cách tránh

| Vấn đề | Nguyên nhân | Cách khắc phục |
|-------|----------------|-----|
| Thiếu không gian tên | Một số thư viện không tự động thêm `xmlns`. | Đảm bảo sử dụng `svgwrite.Drawing` hoặc thiết lập thủ công `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Tên thuộc tính không hợp lệ | SVG phân biệt chữ hoa/thường; `"strokeWidth"` không được công nhận. | Sử dụng tên thuộc tính theo chuẩn SVG (`stroke-width`). |
| Ghi đè tệp | Chạy lại script có thể ghi đè lên tệp hiện có mà không có cảnh báo. | Kiểm tra `os.path.exists(output_path)` trước khi gọi `saveas`. |
| Chuỗi đầu ra lớn | Xuất SVG rất lớn có thể tiêu tốn bộ nhớ. | Dòng dữ liệu đầu ra vào tệp bằng `svg_doc.write(output_path)` thay vì `tostring()`. |

Xử lý các trường hợp đặc biệt này đảm bảo quy trình **create SVG document** của bạn mạnh mẽ trong môi trường sản xuất.

## Ví dụ đầy đủ hoạt động

Kết hợp mọi thứ lại, đây là một script tự chứa tạo vòng tròn màu đỏ, thêm một đường viền tùy chọn, và lưu tệp SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Chạy script này sẽ tạo `output/circle.svg`, bạn có thể mở nó trong bất kỳ trình duyệt hiện đại nào. Tệp này minh họa một **create vector graphic** cơ bản mà bạn có thể mở rộng với nhiều hình dạng, văn bản hoặc hoạt ảnh hơn.
