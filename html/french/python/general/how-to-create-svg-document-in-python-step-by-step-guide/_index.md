# Comment créer un document SVG en Python – guide étape par étape

Si vous avez besoin de **create SVG document** de manière programmatique, ce tutoriel vous montre exactement comment. Vous obtiendrez un exemple complet et exécutable qui crée un simple graphique vectoriel, exporte l'**SVG image**, et enregistre le **SVG file** sur le disque.

Travailler avec des fichiers SVG est courant lorsque vous souhaitez des graphiques indépendants de la résolution pour les pages web, les rapports ou les icônes d'interface utilisateur. Dans les sections suivantes, vous apprendrez comment configurer l'environnement, construire les éléments SVG et gérer les cas particuliers tels que les espaces de noms personnalisés ou les valeurs d'attributs dynamiques.

## Prérequis

* Python 3.8 ou une version plus récente installé.
* Le package `svgwrite` (ou toute bibliothèque offrant une API similaire à `SVGDocument`). Installez-le avec :

```bash
pip install svgwrite
```

* Permission d'écriture sur le répertoire où vous prévoyez de **save SVG file**.

Aucune dépendance système supplémentaire n'est requise.

## Étape 1 : Initialiser le document SVG

La première étape consiste à créer un nouvel objet **SVG document**. Cet objet représente l'élément racine `<svg>` et fournit des méthodes pour ajouter des formes, des groupes et d'autres constructions SVG.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Pourquoi c'est important* : L'initialisation du document définit automatiquement la taille du canevas et l'espace de noms XML, ce qui est essentiel pour tout flux de travail **create vector graphic**.

## Étape 2 : Définir un élément cercle rouge

Ensuite, vous ajoutez le contenu graphique réel. Dans cet exemple, nous dessinons un cercle rouge centré en (50, 50) avec un rayon de 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Pourquoi c'est important* : Utiliser un dictionnaire pour les attributs garde le code propre et facilite la modification des propriétés ultérieurement—utile lorsque vous **export SVG image** avec différentes couleurs ou tailles.

## Étape 3 : Ajouter des éléments supplémentaires (optionnel)

Vous pouvez étendre le graphique en ajoutant davantage de formes, de texte ou de groupes. Ci-dessous, une étape optionnelle qui ajoute un contour noir autour du cercle.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Astuce* : Réutiliser `svg_doc.circle` avec différents paramètres vous permet de créer des calques **create vector graphic** sans manipuler manuellement des chaînes XML.

## Étape 4 : Enregistrer le SVG dans un fichier

Enfin, écrivez le SVG en mémoire sur le disque. C'est le moment où l'opération **save SVG file** se produit.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Lorsque le script se termine, vous trouverez `circle.svg` dans le dossier `output`. Ouvrir le fichier dans un navigateur ou un éditeur SVG affiche un cercle rouge avec un fin contour noir.

### Sortie attendue (SVG brut)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Si vous visualisez le fichier dans un navigateur, vous verrez le cercle rouge centré sur un canevas de 100 × 100 pixels.

## Comment créer un SVG avec des données dynamiques

Il arrive souvent que vous deviez générer des SVGs à partir de données d'exécution (par ex., points de graphique, avatars d'utilisateur). Le même modèle s'applique :

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Pourquoi cela fonctionne* : La fonction abstrait la logique **how to create SVG**, vous permettant de l'appeler avec n'importe quel rayon ou couleur de remplissage. Cette approche s'adapte bien au traitement par lots ou aux points de terminaison d'API qui renvoient des images SVG.

## Exporter l'image SVG pour le web

Si vous devez intégrer le SVG directement dans du HTML ou l'envoyer via HTTP, vous pouvez **export SVG image** sous forme de chaîne :

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Encoder la chaîne en Base64 vous permet d'utiliser un data URI, ce qui élimine le besoin d'une requête séparée **save SVG file** dans de nombreux scénarios web.

## Pièges courants et comment les éviter

| Problème | Pourquoi cela se produit | Solution |
|----------|--------------------------|----------|
| Espace de noms manquant | Certaines bibliothèques n’ajoutent pas automatiquement `xmlns`. | Assurez‑vous d’utiliser `svgwrite.Drawing` ou définissez manuellement `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Noms d'attributs invalides | SVG est sensible à la casse ; `"strokeWidth"` n’est pas reconnu. | Utilisez les noms d’attributs de la spécification SVG (`stroke-width`). |
| Écrasement du fichier | Ré‑exécuter le script peut écraser un fichier existant sans avertissement. | Vérifiez `os.path.exists(output_path)` avant d’appeler `saveas`. |
| Chaînes de sortie volumineuses | Exporter des SVG très grands peut consommer de la mémoire. | Diffusez la sortie vers un fichier en utilisant `svg_doc.write(output_path)` au lieu de `tostring()`. |

Gérer ces cas particuliers garantit que votre routine **create SVG document** est robuste en environnement de production.

## Exemple complet fonctionnel

En rassemblant tous les éléments, voici un script autonome qui crée un cercle rouge, ajoute un contour optionnel et enregistre le fichier SVG :

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

L'exécution de ce script crée `output/circle.svg`, que vous pouvez ouvrir dans n'importe quel navigateur moderne. Le fichier montre un **create vector graphic** de base que vous pouvez étendre avec davantage de formes, de texte ou d'animations.
