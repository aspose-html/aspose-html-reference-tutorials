## Как **загрузить EPUB в Java** с Aspose.HTML
Класс `HtmlDocument` — это основной объект Aspose.HTML, представляющий в памяти документ HTML, EPUB или другой веб‑документ. После добавления зависимости Maven создайте экземпляр `HtmlDocument`, передав путь к файлу EPUB в его конструктор, затем вызовите `load()`, чтобы загрузить содержимое в объектную модель.

## Как **конвертировать защищённый EPUB** файлы
`HtmlLoadOptions` позволяет задавать параметры загрузки, такие как пароли для зашифрованных файлов EPUB. Если ваш EPUB защищён паролем, вы всё равно можете загрузить его, указав пароль через `HtmlLoadOptions`. Библиотека будет расшифровывать контейнер «на лету», обеспечивая корректный рендеринг содержимого для конвертации. После установки пароля библиотека расшифровывает контейнер «на лету», обеспечивая корректный рендеринг содержимого для конвертации.

Да — вы можете пакетно конвертировать EPUB, обернув логику конвертации отдельного файла в цикл, который проходит по каталогу файлов EPUB. Такой подход позволяет обрабатывать десятки, а иногда и сотни книг одним запуском из командной строки, что идеально подходит для архивных конвейеров и масштабных издательских процессов.

## Как конвертировать EPUB в XPS?
Загрузите EPUB с помощью `new HtmlDocument("book.epub")`, при необходимости передайте `HtmlLoadOptions` для паролей, затем вызовите `document.save("output.xps", SaveFormat.Xps)`. Aspose.HTML заботится о парсинге EPUB, применении CSS, растеризации векторной графики и встраивании шрифтов, предоставляя готовый к печати XPS‑файл одним вызовом метода.
