# Как создать SVG‑документ в Python – пошаговое руководство

Если вам нужно **создать SVG‑документ** программно, это руководство покажет, как это сделать. Вы получите полностью готовый, исполняемый пример, который создаёт простую векторную графику, экспортирует SVG‑изображение и сохраняет SVG‑файл на диск.

Работа с SVG‑файлами часто требуется, когда нужны графики, независимые от разрешения, для веб‑страниц, отчётов или иконок пользовательского интерфейса. В последующих разделах вы узнаете, как настроить окружение, построить SVG‑элементы и обработать особые случаи, такие как пользовательские пространства имён или динамические значения атрибутов.

## Предварительные требования

Прежде чем начать, убедитесь, что у вас есть:

* Python 3.8 или новее.
* Пакет `svgwrite` (или любая библиотека, предоставляющая API, похожий на `SVGDocument`). Установите его командой:

```bash
pip install svgwrite
```

* Права записи в каталог, куда вы планируете **сохранить SVG‑файл**.

Дополнительные системные зависимости не требуются.

## Шаг 1: Инициализация SVG‑документа

Первый шаг – создать новый объект **SVG‑документ**. Этот объект представляет корневой элемент `<svg>` и предоставляет методы для добавления фигур, групп и других SVG‑конструкций.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Почему это важно*: Инициализация документа задаёт размер холста и XML‑пространство имён автоматически, что необходимо для любого рабочего процесса **создания векторной графики**.

## Шаг 2: Определение красного круга

Далее добавляем фактическое графическое содержимое. В этом примере мы рисуем красный круг, центрированный в точке (50, 50) с радиусом 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Почему это важно*: Использование словаря для атрибутов делает код чистым и упрощает последующее изменение свойств — удобно, когда вы **экспортируете SVG‑изображение** с разными цветами или размерами.

## Шаг 3: Добавление дополнительных элементов (по желанию)

Можно расширить графику, добавив больше фигур, текста или групп. Ниже показан необязательный шаг, который добавляет чёрный контур вокруг круга.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Совет профессионала*: Переиспользование `svg_doc.circle` с разными параметрами позволяет **создавать векторные графики** слоями без ручного формирования XML‑строк.

## Шаг 4: Сохранение SVG в файл

Наконец, записываем SVG, находящийся в памяти, на диск. Здесь происходит операция **сохранения SVG‑файла**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Когда скрипт завершится, вы найдёте `circle.svg` в папке `output`. Открытие файла в браузере или SVG‑редакторе покажет красный круг с тонкой чёрной окантовкой.

### Ожидаемый вывод (сырой SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Если открыть файл в браузере, вы увидите красный круг, центрированный на холсте размером 100 × 100 пикселей.

## Как создавать SVG с динамическими данными

Часто требуется генерировать SVG на основе данных во время выполнения (например, точки графика, аватары пользователей). Применяется тот же шаблон:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Почему это работает*: Функция инкапсулирует логику **как создать SVG**, позволяя вызывать её с любым радиусом или цветом заливки. Такой подход хорошо масштабируется для пакетной обработки или API‑конечных точек, возвращающих SVG‑изображения.

## Экспорт SVG‑изображения для веб‑использования

Если нужно встроить SVG непосредственно в HTML или передать его по HTTP, вы можете **экспортировать SVG‑изображение** в виде строки:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Кодирование строки в Base64 позволяет использовать data URI, что устраняет необходимость отдельного запроса **сохранения SVG‑файла** во многих веб‑сценариях.

## Распространённые подводные камни и как их избежать

| Проблема | Почему возникает | Решение |
|----------|------------------|---------|
| Отсутствует пространство имён | Некоторые библиотеки не добавляют `xmlns` автоматически. | Убедитесь, что используется `svgwrite.Drawing` или вручную задайте `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Неправильные имена атрибутов | SVG чувствителен к регистру; `"strokeWidth"` не распознаётся. | Используйте имена атрибутов из спецификации SVG (`stroke-width`). |
| Перезапись файла | При повторном запуске скрипт может перезаписать существующий файл без предупреждения. | Проверьте `os.path.exists(output_path)` перед вызовом `saveas`. |
| Большие строки вывода | Экспорт очень больших SVG может потреблять много памяти. | Потоково записывайте вывод в файл с помощью `svg_doc.write(output_path)` вместо `tostring()`. |

Учёт этих особенностей делает ваш процесс **создания SVG‑документа** надёжным в продакшн‑среде.

## Полный рабочий пример

Объединив всё вместе, получаем автономный скрипт, который создаёт красный круг, добавляет необязательный контур и сохраняет SVG‑файл:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Запуск этого скрипта создаст `output/circle.svg`, который можно открыть в любом современном браузере. Файл демонстрирует базовую **создаваемую векторную графику**, которую можно расширять добавлением фигур, текста или анимаций.
