# Jak převést HTML na MHTML pomocí Aspose.HTML pro Java

Převod HTML na MHTML je běžná potřeba, když potřebujete jediný, přenosný soubor, který obsahuje HTML stránku spolu se všemi jejími zdroji (obrázky, CSS, skripty). V tomto tutoriálu se naučíte **jak převést HTML na MHTML** pomocí Aspose.HTML pro Java, uvidíte, jak **uložit HTML jako MHTML**, a objevíte nejlepší způsob, jak **načíst HTML dokument ve stylu Java**. Ať už archivujete webové stránky, generujete obsah připravený pro e‑mail, nebo budujete reportingovou pipeline, níže uvedené kroky vás rychle dovedou k cíli.

## Rychlé odpovědi
- **Jaká je hlavní knihovna?** Aspose.HTML for Java  
- **Jak dlouho trvá implementace?** Přibližně 10‑15 minut pro základní převod  
- **Potřebuji licenci?** Dočasná licence stačí pro testování; plná licence je vyžadována pro produkci  
- **Mohu zpracovávat soubory hromadně?** Ano – zabalte kód do smyčky a znovu použijte stejné možnosti  
- **Podporovaný výstup?** MHTML (`.mht`), plus další formáty jako PDF, PNG, atd.

## Co je převod HTML na MHTML?
Převod HTML na MHTML transformuje standardní webovou stránku do jediného MIME‑kódovaného souboru, který spojuje HTML značky s veškerými propojenými zdroji, jako jsou obrázky, styly a skripty. Výsledný soubor .mht je samostatný, umožňuje offline prohlížení, snadné sdílení a vkládání do e‑mailových zpráv bez externích závislostí.

## Proč použít Aspose.HTML pro Java?
Aspose.HTML pro Java poskytuje čistě Java engine, který převádí HTML obsah bez spoléhání se na externí prohlížeče, což vývojářům dává plnou kontrolu nad vykreslováním, zpracováním zdrojů a věrností výstupu. Podporuje hromadné zpracování, efektivně pracuje s velkými soubory a nabízí širokou škálu výstupních formátů, což z něj činí ideální nástroj pro podnikovou generaci dokumentů a archivaci.

- **Plná kontrola** nad zpracováním zdrojů (rozhodujete, jak hluboko má konvertor sledovat odkazy)  
- **Žádné externí prohlížeče** – převod běží kompletně na JVM  
- **Vysoká věrnost** – výsledné MHTML vypadá přesně jako originální stránka v prohlížeči  
- **Škálovatelné** – vhodné pro jednotlivé stránky i velké hromadné úlohy  
- **Podporuje více než 12 výstupních formátů** (včetně MHTML, PDF, PNG, JPEG, SVG, EPUB) a dokáže zpracovat soubory až do 500 MB, aniž by načítal celý dokument do paměti.

2. **Aspose.HTML pro Java** – získejte knihovnu z [Aspose.HTML for Java documentation](https://reference.aspose.com/html/java/).

Nyní, když jsou základy pokryty, pojďme se ponořit do kódu.

## Importovat balíčky

Přidejte požadované importy do své Java třídy:

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## Průvodce krok za krokem

### Krok 1: Načíst HTML dokument

Třída `HTMLDocument` představuje HTML soubor načtený do paměti pro další zpracování.  
Zde **načteme HTML dokument ve stylu Java** zadáním cesty k souboru. Třída `HTMLDocument` parsuje značky a připraví je pro převod.

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### Krok 2: Inicializovat MHTML Save Options

Objekt `MHTMLSaveOptions` definuje, jak má být převod na MHTML proveden, včetně kódování a zpracování zdrojů.  
Objekt `MHTMLSaveOptions` vám umožňuje doladit chování převodu (např. zpracování zdrojů, kódování).

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### Krok 3: Nastavit pravidla zpracování zdrojů

Třída `ResourceHandlingOptions` řídí, které externí zdroje jsou vloženy a jak hluboko crawler jde.  
Můžete řídit, jak hluboko konvertor sleduje propojené zdroje. Nastavení hloubky na `1` znamená, že jsou vloženy jen okamžité zdroje (obrázky, CSS), což udržuje velikost výstupu rozumnou.

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### Krok 4: Specifikovat výstupní cestu

Řetězec `outputPath` určuje knihovně, kam má zapsat výsledný MHTML soubor.  
Vyberte, kam má být výsledný **MHTML** soubor uložen.

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### Krok 5: Provedení převodu

Statická metoda `Converter.convertHTML` načte zdrojový `HTMLDocument`, použije `MHTMLSaveOptions` a zapíše výstupní soubor.  
Statická metoda `convertHTML` provádí těžkou práci: načte `HTMLDocument`, použije `options` a zapíše MHTML soubor do `outputMHTML`.

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **Tip:** Pokud potřebujete převádět mnoho souborů, vytvořte `MHTMLSaveOptions` jednou a znovu jej použijte uvnitř smyčky pro zlepšení výkonu.

## Jak hloubka zpracování zdrojů ovlivňuje velikost MHTML?

Nižší hloubka (např. `1`) vloží jen přímo odkazované zdroje, což vede k menšímu MHTML souboru, zatímco vyšší hloubka (např. `3`) zahrne hlubší propojené assety, zvětší velikost souboru, ale zlepší úplnost. Zvolte hloubku podle svých úložných omezení a důležitosti plně samostatného výstupu.

## Jak převést HTML na PDF (java html to pdf) – rychlá poznámka

Aspose.HTML pro Java není omezen pouze na MHTML. Pokud také potřebujete generovat PDF, jednoduše nahraďte `MHTMLSaveOptions` za `PdfSaveOptions` a zavolejte stejnou metodu `Converter.convertHTML`. Tato flexibilita vám umožní provádět **java html to pdf** převody bez přidávání dalších knihoven.

## Časté problémy a řešení

| Problém | Řešení |
|-------|----------|
| **Chybějící obrázky v MHTML souboru** | Ujistěte se, že `setMaxHandlingDepth` je dostatečně vysoké, aby zahrnovalo vnořené zdroje, nebo je přidejte ručně pomocí `resourceHandlingOptions.getAdditionalResources()` |
| **Není podporována některá CSS** | Aspose.HTML dodržuje standardy HTML5/CSS3; starší nebo proprietární CSS může být ignorováno. Zjednodušte stylopis nebo vložte styly přímo do HTML |
| **LicenseException za běhu** | Použijte dočasnou licenci během vývoje: `License license = new License(); license.setLicense("Aspose.HTML.Java.lic");` |
