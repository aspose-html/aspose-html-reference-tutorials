# Jak vytvořit SVG dokument v Pythonu – krok za krokem průvodce

Pokud potřebujete **create SVG document** programově, tento tutoriál vám přesně ukáže, jak na to. Získáte kompletní, spustitelný příklad, který vytvoří jednoduchou vektorovou grafiku, exportuje SVG obrázek a uloží SVG soubor na disk.

Práce se soubory SVG je běžná, když chcete grafiku nezávislou na rozlišení pro webové stránky, zprávy nebo UI ikony. V následujících sekcích se naučíte, jak nastavit prostředí, vytvořit SVG elementy a řešit okrajové případy, jako jsou vlastní jmenné prostory nebo dynamické hodnoty atributů.

## Požadavky

* Nainstalovaný Python 3.8 nebo novější.
* Balíček `svgwrite` (nebo jakákoli knihovna poskytující API podobné `SVGDocument`). Nainstalujte jej pomocí:

```bash
pip install svgwrite
```

* Oprávnění k zápisu do adresáře, kam plánujete **save SVG file**.

Žádné další systémové závislosti nejsou vyžadovány.

## Krok 1: Inicializace SVG dokumentu

Prvním krokem je vytvořit nový objekt **SVG document**. Tento objekt představuje kořenový element `<svg>` a poskytuje metody pro přidávání tvarů, skupin a dalších SVG konstrukcí.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Proč je to důležité*: Inicializace dokumentu automaticky definuje velikost plátna a XML jmenný prostor, což je nezbytné pro jakýkoli **create vector graphic** workflow.

## Krok 2: Definice červeného kruhu

Dále přidáte skutečný grafický obsah. V tomto příkladu nakreslíme červený kruh se středem v (50, 50) a poloměrem 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Proč je to důležité*: Použití slovníku pro atributy udržuje kód přehledný a usnadňuje pozdější úpravy vlastností – užitečné, když **export SVG image** s různými barvami nebo velikostmi.

## Krok 3: Přidání dalších elementů (volitelné)

Můžete rozšířit grafiku přidáním dalších tvarů, textu nebo skupin. Níže je volitelný krok, který přidá černý tah kolem kruhu.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Tip*: Opakované použití `svg_doc.circle` s různými parametry vám umožní **create vector graphic** vrstvy bez ručního manipulování s XML řetězci.

## Krok 4: Uložení SVG do souboru

Nakonec zapíšete SVG v paměti na disk. Toto je okamžik, kdy se provede operace **save SVG file**.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Po dokončení skriptu najdete `circle.svg` ve složce `output`. Otevření souboru v prohlížeči nebo SVG editoru zobrazí červený kruh s tenkým černým obrysem.

### Očekávaný výstup (raw SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Pokud soubor zobrazíte v prohlížeči, uvidíte červený kruh vycentrovaný na plátně o rozměrech 100 × 100 pixelů.

## Jak vytvořit SVG s dynamickými daty

Často potřebujete generovat SVG na základě dat za běhu (např. body grafu, avatary uživatelů). Používá se stejný vzor:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Proč to funguje*: Funkce abstrahuje logiku **how to create SVG**, což vám umožní volat ji s libovolným poloměrem nebo barvou výplně. Tento přístup se dobře škáluje pro dávkové zpracování nebo API endpointy vracející SVG obrázky.

## Export SVG image pro webové použití

Pokud potřebujete vložit SVG přímo do HTML nebo jej poslat přes HTTP, můžete **export SVG image** jako řetězec:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Kódování řetězce jako Base64 vám umožní použít data URI, což v mnoha webových scénářích eliminuje potřebu samostatného požadavku **save SVG file**.

## Časté úskalí a jak se jim vyhnout

| Problém | Proč k tomu dochází | Oprava |
|-------|----------------|-----|
| Chybějící jmenný prostor | Některé knihovny nepřidávají `xmlns` automaticky. | Zajistěte, aby byl použit `svgwrite.Drawing`, nebo ručně nastavte `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Neplatné názvy atributů | SVG rozlišuje velká a malá písmena; `"strokeWidth"` není rozpoznáno. | Používejte názvy atributů podle SVG specifikace (`stroke-width`). |
| Přepisování souboru | Opětovné spuštění skriptu může přepsat existující soubor bez varování. | Zkontrolujte `os.path.exists(output_path)` před voláním `saveas`. |
| Velké výstupní řetězce | Export velmi velkých SVG může spotřebovat paměť. | Streamujte výstup do souboru pomocí `svg_doc.write(output_path)` místo `tostring()`. |

Řešením těchto okrajových případů zajistíte, že vaše rutina **create SVG document** bude v produkčních prostředích robustní.

## Kompletní funkční příklad

Spojením všech částí získáte samostatný skript, který vytvoří červený kruh, přidá volitelný tah a uloží SVG soubor:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Spuštěním tohoto skriptu se vytvoří `output/circle.svg`, který můžete otevřít v libovolném moderním prohlížeči. Soubor ukazuje základní **create vector graphic**, který můžete rozšířit o další tvary, text nebo animace.
