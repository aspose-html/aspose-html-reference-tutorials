# Python'da SVG belgesi nasıl oluşturulur – adım‑adım rehber

Programlı bir şekilde **SVG belgesi oluşturmanız** gerekiyorsa, bu öğretici tam olarak nasıl yapılacağını gösterir. Basit bir vektör grafiği oluşturan, SVG görüntüsünü dışa aktaran ve SVG dosyasını diske kaydeden eksiksiz, çalıştırılabilir bir örnek elde edeceksiniz.

Web sayfaları, raporlar veya UI simgeleri için çözünürlük‑bağımsız grafikler istediğinizde SVG dosyalarıyla çalışmak yaygındır. Takip eden bölümlerde ortamı nasıl kuracağınızı, SVG öğelerini nasıl oluşturacağınızı ve özel ad alanları ya da dinamik öznitelik değerleri gibi uç durumları nasıl yöneteceğinizi öğreneceksiniz.

## Önkoşullar

Başlamadan önce şunların yüklü olduğundan emin olun:

* Python 3.8 veya daha yeni bir sürüm.
* `svgwrite` paketi (veya `SVGDocument`‑benzeri bir API sağlayan herhangi bir kütüphane). Şu komutla kurun:

```bash
pip install svgwrite
```

* **SVG dosyasını kaydetmek** istediğiniz dizine yazma izni.

Ek sistem bağımlılıkları gerekmez.

## Adım 1: SVG belgesini başlatma

İlk adım, yeni bir **SVG belgesi** nesnesi oluşturmaktır. Bu nesne kök `<svg>` öğesini temsil eder ve şekil, grup ve diğer SVG yapılarını eklemek için yöntemler sunar.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Bu neden önemli*: Belgeyi başlatmak, tuval boyutunu ve XML ad alanını otomatik olarak tanımlar; bu, herhangi bir **create vector graphic** iş akışı için esastır.

## Adım 2: Kırmızı daire öğesini tanımlama

Sonra gerçek grafik içeriğini ekliyorsunuz. Bu örnekte (50, 50) merkezli, 40 px yarıçaplı kırmızı bir daire çiziyoruz.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Bu neden önemli*: Öznitelikler için bir sözlük kullanmak kodu temiz tutar ve özellikleri sonradan değiştirmeyi kolaylaştırır—farklı renkler veya boyutlarla **export SVG image** yaparken faydalıdır.

## Adım 3: Ek öğeler ekleme (isteğe bağlı)

Grafiği daha fazla şekil, metin veya grup ekleyerek genişletebilirsiniz. Aşağıda dairenin etrafına siyah bir kenar ekleyen isteğe bağlı bir adım yer alıyor.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*İpucu*: `svg_doc.circle` öğesini farklı parametrelerle yeniden kullanmak, XML dizgeleriyle manuel uğraşmadan **create vector graphic** katmanları oluşturmanızı sağlar.

## Adım 4: SVG'yi bir dosyaya kaydetme

Son olarak, bellekteki SVG'yi diske yazın. İşte **save SVG file** işleminin gerçekleştiği an.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Betik tamamlandığında `output` klasörünün içinde `circle.svg` dosyasını bulacaksınız. Dosyayı bir tarayıcıda ya da SVG düzenleyicisinde açtığınızda ince bir siyah konturla kırmızı bir daire göreceksiniz.

### Beklenen çıktı (ham SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Dosyayı bir tarayıcıda görüntülerseniz, 100 × 100 piksel tuvalde ortalanmış kırmızı bir daire görürsünüz.

## Dinamik veri ile SVG nasıl oluşturulur

Çoğu zaman çalışma zamanı verilerine (ör. grafik noktaları, kullanıcı avatarları) dayalı SVG'ler üretmeniz gerekir. Aynı desen uygulanır:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Bu neden işe yarar*: Fonksiyon, **how to create SVG** mantığını soyutlar, böylece herhangi bir yarıçap veya dolgu rengiyle çağırabilirsiniz. Bu yaklaşım, toplu işleme veya SVG görüntüleri döndüren API uç noktaları için iyi ölçeklenir.

## Web kullanımı için SVG görüntüsünü dışa aktar

SVG'yi doğrudan HTML'e gömmek ya da HTTP üzerinden göndermek istiyorsanız, **export SVG image** işlemini bir dize olarak yapabilirsiniz:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Dizeyi Base64 olarak kodlamak, bir data URI kullanmanıza olanak tanır; bu da birçok web senaryosunda ayrı bir **save SVG file** isteğine gerek kalmaz.

## Yaygın tuzaklar ve nasıl önlenir

| Sorun | Neden olur | Çözüm |
|-------|------------|-------|
| Eksik ad alanı | Bazı kütüphaneler `xmlns` öğesini otomatik olarak eklemez. | `svgwrite.Drawing` kullanıldığından emin olun veya `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"` ifadesini manuel olarak ayarlayın. |
| Geçersiz öznitelik adları | SVG büyük/küçük harfe duyarlıdır; `"strokeWidth"` tanınmaz. | SVG‑spesifik attribute adlarını (`stroke-width`) kullanın. |
| Dosyanın üzerine yazılması | Betik yeniden çalıştırıldığında mevcut bir dosya uyarı vermeden üzerine yazılabilir. | `saveas` çağırmadan önce `os.path.exists(output_path)` kontrol edin. |
| Büyük çıktı dizgileri | Çok büyük SVG'leri dışa aktarmak bellek tüketebilir. | `tostring()` yerine `svg_doc.write(output_path)` kullanarak çıktıyı bir dosyaya akıtın. |

Bu uç durumları ele almak, **create SVG document** rutininizin üretim ortamlarında sağlam olmasını sağlar.

## Tam çalışan örnek

Her şeyi bir araya getirdiğimizde, kırmızı bir daire oluşturan, isteğe bağlı bir kenar ekleyen ve SVG dosyasını kaydeden bağımsız bir betik elde edersiniz:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Bu betiği çalıştırdığınızda `output/circle.svg` oluşturulur; modern bir tarayıcıda açabilirsiniz. Dosya, daha fazla şekil, metin veya animasyon ekleyebileceğiniz temel bir **create vector graphic** örneği sunar.
