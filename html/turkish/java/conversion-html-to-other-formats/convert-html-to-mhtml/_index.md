# HTML'yi MHTML'ye Aspose.HTML for Java ile Nasıl Dönüştürülür

HTML'yi MHTML'ye dönüştürmek, bir HTML sayfasını ve tüm kaynaklarını (görseller, CSS, betikler) içeren tek, taşınabilir bir dosyaya ihtiyacınız olduğunda yaygın bir gereksinimdir. Bu öğreticide Aspose.HTML for Java kullanarak **HTML'yi MHTML'ye nasıl dönüştüreceğinizi** öğrenecek, **HTML'yi MHTML olarak nasıl kaydedeceğinizi** görecek ve **HTML belgesini Java tarzında nasıl yükleyeceğinizi** keşfedeceksiniz. Web sayfalarını arşivleme, e-posta için hazır içerik oluşturma veya raporlama hattı oluşturma gibi senaryolarda, aşağıdaki adımlar sizi hızlıca hedefe ulaştıracak.

## Hızlı Yanıtlar
- **Ana kütüphane nedir?** Aspose.HTML for Java  
- **Uygulama ne kadar sürer?** Temel bir dönüşüm için yaklaşık 10‑15 dakika  
- **Lisans gerekli mi?** Test için geçici bir lisans yeterlidir; üretim için tam lisans gereklidir  
- **Dosyaları toplu işleyebilir miyim?** Evet – kodu bir döngü içinde sarın ve aynı seçenekleri yeniden kullanın  
- **Desteklenen çıktı?** MHTML (`.mht`), ayrıca PDF, PNG gibi diğer formatlar

## HTML'den MHTML'ye Dönüşüm Nedir?
HTML'den MHTML'ye dönüşüm, standart bir web sayfasını, HTML işaretlemesini ve görseller, stil sayfaları ve betikler gibi tüm bağlı kaynakları bir araya getiren tek bir MIME‑kodlu dosyaya dönüştürür. Oluşan .mht dosyası kendi içinde bağımsızdır, çevrim dışı görüntüleme, kolay paylaşım ve dış bağımlılıklar olmadan e-posta mesajlarına gömme imkanı sağlar.

## Neden Aspose.HTML for Java Kullanmalısınız?
Aspose.HTML for Java, harici tarayıcılara bağımlı olmadan HTML içeriğini dönüştüren saf‑Java bir motor sağlar; bu da geliştiricilere renderlama, kaynak yönetimi ve çıktı doğruluğu üzerinde tam kontrol verir. Toplu işleme destekler, büyük dosyaları verimli bir şekilde işler ve geniş bir çıktı formatı yelpazesi sunar; bu da onu kurumsal düzeyde belge oluşturma ve arşivleme görevleri için ideal kılar.

- **Tam kontrol** kaynak yönetimi üzerinde (dönüştürücünün bağlantıları ne kadar derine izleyeceğini siz belirlersiniz)  
- **Harici tarayıcı yok** – dönüşüm tamamen JVM üzerinde çalışır  
- **Yüksek doğruluk** – ortaya çıkan MHTML, tarayıcıda orijinal sayfa gibi görünür  
- **Ölçeklenebilir** – tek sayfalar veya büyük toplu işler için uygundur  
- **12+ çıktı formatını destekler** (MHTML, PDF, PNG, JPEG, SVG, EPUB dahil) ve belgenin tamamını belleğe yüklemeden 500 MB'a kadar dosyaları işleyebilir.

Temel bilgiler ele alındığına göre, kodlara dalalım.

## Paketleri İçe Aktarın

Gerekli içe aktarmaları Java sınıfınıza ekleyin:

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## Adım‑Adım Kılavuz

### Adım 1: HTML Belgesini Yükleyin

`HTMLDocument` sınıfı, daha sonraki işleme için belleğe yüklenen bir HTML dosyasını temsil eder.  
Burada dosya yolunu sağlayarak **HTML belgesini Java tarzında** yüklüyoruz. `HTMLDocument` sınıfı işaretlemeyi ayrıştırır ve dönüşüm için hazırlar.

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### Adım 2: MHTML Kaydetme Seçeneklerini Başlatın

`MHTMLSaveOptions` nesnesi, MHTML'ye dönüşümün nasıl yapılacağını, kodlamayı ve kaynak yönetimini tanımlar.  
`MHTMLSaveOptions` nesnesi, dönüşümün davranışını (ör. kaynak yönetimi, kodlama) ayarlamanıza olanak tanır.

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### Adım 3: Kaynak Yönetimi Kurallarını Ayarlayın

`ResourceHandlingOptions` sınıfı, hangi dış kaynakların gömüleceğini ve tarayıcının ne kadar derine gideceğini kontrol eder.  
Dönüştürücünün bağlı kaynakları ne kadar derine izleyeceğini kontrol edebilirsiniz. `1` derinlik ayarı, yalnızca doğrudan kaynakların (görseller, CSS) gömülmesi anlamına gelir ve çıktı boyutunun makul kalmasını sağlar.

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### Adım 4: Çıktı Yolunu Belirtin

`outputPath` dizesi, kütüphaneye oluşturulan MHTML dosyasının nereye yazılacağını söyler.  
Oluşturulan **MHTML** dosyasının nereye kaydedileceğini seçin.

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### Adım 5: Dönüşümü Gerçekleştirin

`Converter.convertHTML` statik metodu, kaynak `HTMLDocument`'i okur, `MHTMLSaveOptions`'ı uygular ve çıktı dosyasını yazar.  
Statik `convertHTML` metodu işi halleder: `HTMLDocument`'i okur, `options`'ı uygular ve MHTML dosyasını `outputMHTML`'ye yazar.

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **Pro tip:** Birçok dosyayı dönüştürmeniz gerekiyorsa, `MHTMLSaveOptions`'ı bir kez örnekleyin ve performansı artırmak için bir döngü içinde yeniden kullanın.

## Kaynak yönetimi derinliği MHTML boyutunu nasıl etkiler?
Daha düşük bir derinlik (ör. `1`) yalnızca doğrudan referans verilen kaynakları gömer ve daha küçük bir MHTML dosyası üretir; daha yüksek bir derinlik (ör. `3`) daha derin bağlı varlıkları ekler, dosya boyutunu artırır ancak bütünlüğü iyileştirir. Derinliği, depolama kısıtlamalarınıza ve tamamen kendi içinde barındırılmış çıktının önemine göre seçin.

## HTML'yi PDF'ye (java html to pdf) Nasıl Dönüştürülür – Kısa Bir Not
Aspose.HTML for Java sadece MHTML ile sınırlı değildir. PDF'ler de oluşturmanız gerekiyorsa, `MHTMLSaveOptions` yerine `PdfSaveOptions` kullanın ve aynı `Converter.convertHTML` metodunu çağırın. Bu esneklik, ek kütüphaneler eklemeden **java html to pdf** dönüşümlerini yönetmenizi sağlar.
