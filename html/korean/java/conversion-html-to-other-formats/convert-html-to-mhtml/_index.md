# HTML을 MHTML로 변환하는 방법 (Aspose.HTML for Java 사용)

HTML을 MHTML로 변환하는 것은 HTML 페이지와 모든 리소스(이미지, CSS, 스크립트)를 하나의 휴대용 파일에 담아야 할 때 흔히 요구되는 작업입니다. 이 튜토리얼에서는 Aspose.HTML for Java를 사용하여 **HTML을 MHTML로 변환하는 방법**을 배우고, **HTML을 MHTML로 저장하는 방법**을 확인하며, **Java 스타일로 HTML 문서를 로드하는 최선의 방법**을 알아봅니다. 웹 페이지를 보관하거나, 이메일용 콘텐츠를 생성하거나, 보고 파이프라인을 구축할 때도 아래 단계들을 따라 하면 빠르게 목표를 달성할 수 있습니다.

## 빠른 답변
- **주요 라이브러리는 무엇인가요?** Aspose.HTML for Java  
- **구현에 얼마나 걸리나요?** 기본 변환의 경우 약 10‑15분  
- **라이선스가 필요합니까?** 테스트용으로는 임시 라이선스로 충분하며, 프로덕션에서는 정식 라이선스가 필요합니다  
- **파일을 배치 처리할 수 있나요?** 예 – 코드를 루프에 감싸고 동일한 옵션을 재사용하면 됩니다  
- **지원되는 출력 형식?** MHTML(`.mht`) 외에도 PDF, PNG 등 다양한 형식  

## HTML을 MHTML로 변환이란?
HTML을 MHTML로 변환하면 표준 웹 페이지를 단일 MIME 인코딩 파일로 바꾸어 HTML 마크업과 이미지, 스타일시트, 스크립트와 같은 모든 연결된 리소스를 하나에 묶습니다. 생성된 .mht 파일은 자체 포함형이므로 오프라인으로 볼 수 있고, 쉽게 공유하거나 외부 종속성 없이 이메일에 삽입할 수 있습니다.

## 왜 Aspose.HTML for Java를 사용하나요?
Aspose.HTML for Java는 외부 브라우저에 의존하지 않고 HTML 콘텐츠를 변환하는 순수 Java 엔진을 제공하여 개발자가 렌더링, 리소스 처리 및 출력 정확성을 완전히 제어할 수 있게 합니다. 배치 처리 지원, 대용량 파일 효율적 처리, 다양한 출력 형식 제공으로 엔터프라이즈 수준의 문서 생성 및 보관 작업에 이상적입니다.

- **전체 제어** 리소스 처리에 대해 (변환기가 링크를 얼마나 깊게 따라갈지 직접 결정)  
- **외부 브라우저 없음** – 변환이 JVM에서 완전히 실행됩니다  
- **높은 충실도** – 결과 MHTML은 브라우저에서 본 원본 페이지와 정확히 동일하게 보입니다  
- **확장성** – 단일 페이지든 대규모 배치 작업이든 적합합니다  
- **12개 이상의 출력 형식 지원** (MHTML, PDF, PNG, JPEG, SVG, EPUB 등 포함) 및 전체 문서를 메모리에 로드하지 않고도 최대 500 MB 파일을 처리할 수 있습니다.

기본 사항을 살펴보았으니, 이제 코드로 들어가 보겠습니다.

## 패키지 가져오기

Java 클래스에 필요한 import를 추가하세요:

```java
import com.aspose.html.HTMLDocument;
import com.aspose.html.saving.MHTMLSaveOptions;
import com.aspose.html.converters.Converter;
import com.aspose.html.saving.MHTMLResourceHandlingOptions;
```

## 단계별 가이드

### 단계 1: HTML 문서 로드

`HTMLDocument` 클래스는 추가 처리를 위해 메모리로 로드된 HTML 파일을 나타냅니다.  
여기서는 파일 경로를 제공하여 **Java 스타일로 HTML 문서를 로드**합니다. `HTMLDocument` 클래스는 마크업을 파싱하고 변환을 위해 준비합니다.

```java
HTMLDocument htmlDocument = new HTMLDocument("path_to_your_html_file.html");
```

### 단계 2: MHTML 저장 옵션 초기화

`MHTMLSaveOptions` 객체는 인코딩 및 리소스 처리 등을 포함해 MHTML 변환 방식을 정의합니다.  
`MHTMLSaveOptions` 객체를 사용하면 변환 동작(예: 리소스 처리, 인코딩)을 세부 조정할 수 있습니다.

```java
MHTMLSaveOptions options = new MHTMLSaveOptions();
```

### 단계 3: 리소스 처리 규칙 설정

`ResourceHandlingOptions` 클래스는 어떤 외부 리소스를 포함할지와 크롤러가 얼마나 깊게 탐색할지를 제어합니다.  
변환기가 링크된 리소스를 어느 정도까지 따라갈지 제어할 수 있습니다. 깊이를 `1`로 설정하면 즉시 참조되는 리소스(이미지, CSS)만 포함되어 출력 파일 크기가 적절하게 유지됩니다.

```java
MHTMLResourceHandlingOptions resourceHandlingOptions = options.getResourceHandlingOptions();
resourceHandlingOptions.setMaxHandlingDepth(1);
```

### 단계 4: 출력 경로 지정

`outputPath` 문자열은 라이브러리에게 결과 MHTML 파일을 어디에 쓸지 알려줍니다.  
결과 **MHTML** 파일을 저장할 위치를 선택하세요.

```java
String outputMHTML = "path_to_output_mhtml_file.mht";
```

### 단계 5: 변환 수행

`Converter.convertHTML` 정적 메서드는 소스 `HTMLDocument`를 읽고 `MHTMLSaveOptions`를 적용한 뒤 출력 파일을 작성합니다.  
정적 `convertHTML` 메서드는 핵심 작업을 수행합니다: `HTMLDocument`를 읽고 `options`를 적용한 뒤 MHTML 파일을 `outputMHTML`에 기록합니다.

```java
Converter.convertHTML(htmlDocument, options, outputMHTML);
```

> **프로 팁:** 많은 파일을 변환해야 할 경우 `MHTMLSaveOptions`를 한 번 인스턴스화하고 루프 내에서 재사용하면 성능이 향상됩니다.

## 리소스 처리 깊이가 MHTML 크기에 미치는 영향은?

깊이가 낮으면(예: `1`) 직접 참조된 리소스만 포함되어 MHTML 파일이 작아지고, 깊이가 높으면(예: `3`) 더 깊은 링크된 자산까지 포함되어 파일 크기가 증가하지만 완전성이 향상됩니다. 저장 공간 제약과 완전한 자체 포함 출력의 중요도에 따라 깊이를 선택하세요.

## HTML을 PDF로 변환하는 방법 (java html to pdf) – 간단히

Aspose.HTML for Java는 MHTML에만 국한되지 않습니다. PDF를 생성해야 할 경우 `MHTMLSaveOptions`를 `PdfSaveOptions`로 교체하고 동일한 `Converter.convertHTML` 메서드를 호출하면 됩니다. 이 유연성을 통해 **java html to pdf** 변환을 추가 라이브러리 없이 처리할 수 있습니다.

## 일반적인 문제와 해결책

| 문제 | 해결책 |
|-------|----------|
| **MHTML 파일에서 이미지 누락** | 중첩된 리소스를 포함하도록 `setMaxHandlingDepth` 값을 충분히 높게 설정하거나, `resourceHandlingOptions.getAdditionalResources()`를 통해 수동으로 추가하세요. |
| **지원되지 않는 CSS 기능** | Aspose.HTML는 HTML5/CSS3 표준을 따르며, 오래되거나 독점적인 CSS는 무시될 수 있습니다. 스타일시트를 단순화하거나 스타일을 HTML에 직접 삽입하세요. |
| **런타임 시 LicenseException** | 개발 중에 임시 라이선스를 적용하세요: `License license = new License(); license.setLicense("Aspose.HTML.Java.lic");` |
