# Python에서 SVG 문서 만들기 – 단계별 가이드

프로그램matically **create SVG document**가 필요하다면, 이 튜토리얼이 정확히 어떻게 하는지 보여줍니다. 간단한 벡터 그래픽을 만들고, SVG 이미지를 내보내며, SVG 파일을 디스크에 저장하는 완전한 실행 가능한 예제를 제공합니다.

웹 페이지, 보고서, UI 아이콘 등에 해상도에 독립적인 그래픽이 필요할 때 SVG 파일을 다루는 것이 일반적입니다. 다음 섹션에서는 환경 설정, SVG 요소 구축, 사용자 정의 네임스페이스나 동적 속성 값과 같은 엣지 케이스 처리 방법을 배웁니다.

## 사전 요구 사항

* Python 3.8 이상 설치되어 있어야 합니다.
* `svgwrite` 패키지(`SVGDocument`와 유사한 API를 제공하는 라이브러리라도 가능). 다음 명령으로 설치합니다:

```bash
pip install svgwrite
```

* **save SVG file** 을 저장하려는 디렉터리에 대한 쓰기 권한이 있어야 합니다.

추가 시스템 종속성은 필요하지 않습니다.

## Step 1: **SVG document** 초기화

첫 번째 단계는 새로운 **SVG document** 객체를 만드는 것입니다. 이 객체는 루트 `<svg>` 요소를 나타내며, 도형, 그룹 및 기타 SVG 구성 요소를 추가하는 메서드를 제공합니다.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Why this matters*: 문서를 초기화하면 캔버스 크기와 XML 네임스페이스가 자동으로 정의되어, 모든 **create vector graphic** 워크플로우에 필수적입니다.

## Step 2: 빨간 원 요소 정의

다음으로 실제 그래픽 내용을 추가합니다. 이 예제에서는 (50, 50)을 중심으로 반지름 40 px인 빨간 원을 그립니다.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Why this matters*: 속성을 딕셔너리로 사용하면 코드가 깔끔해지고 나중에 속성을 쉽게 수정할 수 있어, 다양한 색상이나 크기로 **export SVG image** 할 때 유용합니다.

## Step 3: 추가 요소 추가 (선택 사항)

더 많은 도형, 텍스트 또는 그룹을 추가하여 그래픽을 확장할 수 있습니다. 아래는 원 주위에 검은색 스트로크를 추가하는 선택적 단계입니다.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro tip*: 다른 매개변수로 `svg_doc.circle`을 재사용하면 XML 문자열을 직접 다루지 않고도 **create vector graphic** 레이어를 만들 수 있습니다.

## Step 4: SVG를 파일에 저장

마지막으로 메모리 상의 SVG를 디스크에 씁니다. 바로 여기서 **save SVG file** 작업이 수행됩니다.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

스크립트가 완료되면 `output` 폴더 안에 `circle.svg` 파일이 생성됩니다. 브라우저나 SVG 편집기에서 파일을 열면 얇은 검은 윤곽선이 있는 빨간 원이 표시됩니다.

### 예상 출력 (raw SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

브라우저에서 파일을 보면 100 × 100 픽셀 캔버스 중앙에 빨간 원이 표시됩니다.

## 동적 데이터로 SVG 만들기

런타임 데이터(예: 차트 포인트, 사용자 아바타)를 기반으로 SVG를 생성해야 할 경우가 많습니다. 동일한 패턴을 적용합니다:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Why this works*: 이 함수는 **how to create SVG** 로직을 추상화하여, 반지름이나 채우기 색상에 관계없이 호출할 수 있게 합니다. 이 접근 방식은 배치 처리나 SVG 이미지를 반환하는 API 엔드포인트에 잘 확장됩니다.

## 웹 사용을 위한 SVG 이미지 내보내기

SVG를 HTML에 직접 삽입하거나 HTTP를 통해 전송해야 할 경우, **export SVG image** 를 문자열로 내보낼 수 있습니다:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

문자열을 Base64로 인코딩하면 데이터 URI를 사용할 수 있어, 많은 웹 시나리오에서 별도의 **save SVG file** 요청이 필요 없게 됩니다.

## 흔히 발생하는 문제와 회피 방법

| Issue | Why it happens | Fix |
|-------|----------------|-----|
| 네임스페이스 누락 | 일부 라이브러리는 `xmlns`를 자동으로 추가하지 않습니다. | `svgwrite.Drawing`을 사용하거나 `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"` 를 수동으로 설정하십시오. |
| 잘못된 속성 이름 | SVG는 대소문자를 구분합니다; `"strokeWidth"`는 인식되지 않습니다. | SVG 사양 속성 이름(`stroke-width`)을 사용하십시오. |
| 파일 덮어쓰기 | 스크립트를 다시 실행하면 경고 없이 기존 파일을 덮어쓸 수 있습니다. | `saveas` 호출 전에 `os.path.exists(output_path)` 를 확인하십시오. |
| 큰 출력 문자열 | 매우 큰 SVG를 내보내면 메모리를 많이 사용할 수 있습니다. | `tostring()` 대신 `svg_doc.write(output_path)` 로 파일에 스트리밍하십시오. |

이러한 엣지 케이스를 해결하면 **create SVG document** 루틴이 프로덕션 환경에서도 견고해집니다.

## 전체 작업 예제

모든 것을 종합하면, 빨간 원을 만들고 선택적 스트로크를 추가하며 SVG 파일을 저장하는 독립 실행형 스크립트가 다음과 같습니다:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

이 스크립트를 실행하면 `output/circle.svg` 가 생성되며, 최신 브라우저에서 열 수 있습니다. 이 파일은 더 많은 도형, 텍스트 또는 애니메이션으로 확장할 수 있는 기본 **create vector graphic** 를 보여줍니다.
