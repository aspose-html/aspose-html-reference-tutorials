# Wie man ein SVG-Dokument in Python erstellt – Schritt‑für‑Schritt‑Anleitung

Wenn Sie ein **create SVG document** programmgesteuert benötigen, zeigt Ihnen dieses Tutorial genau, wie es geht. Sie erhalten ein vollständiges, ausführbares Beispiel, das eine einfache Vektorgrafik erstellt, das SVG‑Bild exportiert und die SVG‑Datei auf die Festplatte speichert.

Die Arbeit mit SVG-Dateien ist üblich, wenn Sie auflösungsunabhängige Grafiken für Webseiten, Berichte oder UI‑Icons benötigen. In den folgenden Abschnitten lernen Sie, wie Sie die Umgebung einrichten, die SVG‑Elemente erstellen und Sonderfälle wie benutzerdefinierte Namespaces oder dynamische Attributwerte behandeln.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

* Python 3.8 oder neuer installiert.
* Das `svgwrite`‑Paket (oder jede Bibliothek, die eine `SVGDocument`‑ähnliche API bereitstellt). Installieren Sie es mit:

```bash
pip install svgwrite
```

* Schreibberechtigung für das Verzeichnis, in dem Sie das **save SVG file** speichern möchten.

Keine zusätzlichen Systemabhängigkeiten sind erforderlich.

## Schritt 1: SVG-Dokument initialisieren

Der erste Schritt besteht darin, ein neues **SVG document**‑Objekt zu erstellen. Dieses Objekt repräsentiert das Wurzelelement `<svg>` und bietet Methoden zum Hinzufügen von Formen, Gruppen und anderen SVG‑Konstrukten.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Warum das wichtig ist*: Das Initialisieren des Dokuments legt die Canvas‑Größe und den XML‑Namespace automatisch fest, was für jeden **create vector graphic**‑Workflow unerlässlich ist.

## Schritt 2: Rotes Kreiselement definieren

Als Nächstes fügen Sie den eigentlichen Grafikinhalt hinzu. In diesem Beispiel zeichnen wir einen roten Kreis, zentriert bei (50, 50) mit einem Radius von 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Warum das wichtig ist*: Die Verwendung eines Dictionaries für Attribute hält den Code sauber und erleichtert das spätere Ändern von Eigenschaften – nützlich, wenn Sie **export SVG image** mit unterschiedlichen Farben oder Größen durchführen.

## Schritt 3: Zusätzliche Elemente anhängen (optional)

Sie können die Grafik erweitern, indem Sie weitere Formen, Text oder Gruppen hinzufügen. Nachfolgend ein optionaler Schritt, der einen schwarzen Strich um den Kreis legt.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Pro‑Tipp*: Das Wiederverwenden von `svg_doc.circle` mit unterschiedlichen Parametern ermöglicht es Ihnen, **create vector graphic**‑Ebenen zu erzeugen, ohne XML‑Strings manuell zu bearbeiten.

## Schritt 4: SVG in einer Datei speichern

Abschließend schreiben Sie das im Speicher befindliche SVG auf die Festplatte. Dies ist der Moment, in dem die **save SVG file**‑Operation ausgeführt wird.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Wenn das Skript beendet ist, finden Sie `circle.svg` im Ordner `output`. Öffnen Sie die Datei in einem Browser oder einem SVG‑Editor, sehen Sie einen roten Kreis mit einer dünnen schwarzen Kontur.

### Erwartete Ausgabe (rohes SVG)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Wenn Sie die Datei in einem Browser ansehen, sehen Sie den roten Kreis zentriert auf einer 100 × 100‑Pixel‑Canvas.

## Wie man SVG mit dynamischen Daten erstellt

Oft müssen Sie SVGs basierend auf Laufzeitdaten (z. B. Diagrammpunkte, Benutzer‑Avatare) erzeugen. Das gleiche Muster gilt:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Warum das funktioniert*: Die Funktion abstrahiert die **how to create SVG**‑Logik, sodass Sie sie mit beliebigem Radius oder Füllfarbe aufrufen können. Dieser Ansatz skaliert gut für Batch‑Verarbeitung oder API‑Endpunkte, die SVG‑Bilder zurückgeben.

## SVG‑Bild für Web‑Verwendung exportieren

Wenn Sie das SVG direkt in HTML einbetten oder über HTTP senden müssen, können Sie **export SVG image** als Zeichenkette ausgeben:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Das Codieren der Zeichenkette als Base64 ermöglicht die Verwendung eines data‑URI, wodurch in vielen Web‑Szenarien ein separater **save SVG file**‑Aufruf entfällt.

## Häufige Fallstricke und wie man sie vermeidet

| Issue | Why it happens | Fix |
|-------|----------------|-----|
| Fehlender Namespace | Einige Bibliotheken fügen `xmlns` nicht automatisch hinzu. | Stellen Sie sicher, dass `svgwrite.Drawing` verwendet wird, oder setzen Sie manuell `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Ungültige Attributnamen | SVG ist case‑sensitive; `"strokeWidth"` wird nicht erkannt. | Verwenden Sie die SVG‑Spezifikations‑Attributnamen (`stroke-width`). |
| Überschreiben der Datei | Das erneute Ausführen des Skripts kann eine vorhandene Datei ohne Warnung überschreiben. | Prüfen Sie `os.path.exists(output_path)` bevor Sie `saveas` aufrufen. |
| Große Ausgabestrings | Das Exportieren sehr großer SVGs kann viel Speicher verbrauchen. | Streamen Sie die Ausgabe in eine Datei mit `svg_doc.write(output_path)` anstatt `tostring()` zu verwenden. |

Die Behandlung dieser Sonderfälle stellt sicher, dass Ihre **create SVG document**‑Routine in Produktionsumgebungen robust ist.

## Vollständiges funktionierendes Beispiel

Wenn wir alles zusammenführen, hier ein eigenständiges Skript, das einen roten Kreis erstellt, optional einen Strich hinzufügt und die SVG‑Datei speichert:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Das Ausführen dieses Skripts erzeugt `output/circle.svg`, das Sie in jedem modernen Browser öffnen können. Die Datei demonstriert eine grundlegende **create vector graphic**, die Sie mit weiteren Formen, Text oder Animationen erweitern können.
