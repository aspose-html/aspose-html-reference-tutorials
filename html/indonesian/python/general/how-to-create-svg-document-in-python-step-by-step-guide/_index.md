# Cara membuat SVG document di Python – panduan langkah demi langkah

Jika Anda perlu **create SVG document** secara programatis, tutorial ini menunjukkan secara tepat caranya. Anda akan mendapatkan contoh lengkap yang dapat dijalankan yang membuat grafik vektor sederhana, mengekspor gambar SVG, dan menyimpan file SVG ke disk.

Bekerja dengan file SVG umum ketika Anda menginginkan grafik yang tidak tergantung resolusi untuk halaman web, laporan, atau ikon UI. Pada bagian-bagian berikut Anda akan belajar cara menyiapkan lingkungan, membangun elemen SVG, dan menangani kasus tepi seperti namespace khusus atau nilai atribut dinamis.

## Prasyarat

* Python 3.8 atau lebih baru terinstal.
* Paket `svgwrite` (atau perpustakaan apa pun yang menyediakan API mirip `SVGDocument`). Instal dengan:

```bash
pip install svgwrite
```

* Izin menulis ke direktori tempat Anda berencana **save SVG file**.

Tidak ada dependensi sistem tambahan yang diperlukan.

## Langkah 1: Inisialisasi dokumen SVG

Langkah pertama adalah membuat objek **SVG document** baru. Objek ini mewakili elemen root `<svg>` dan menyediakan metode untuk menambahkan bentuk, grup, dan konstruksi SVG lainnya.

```python
import svgwrite

# Create a new SVG document with a 100×100 viewport
svg_doc = svgwrite.Drawing(filename="circle.svg", size=("100px", "100px"))
```

*Mengapa ini penting*: Menginisialisasi dokumen mendefinisikan ukuran kanvas dan namespace XML secara otomatis, yang penting untuk alur kerja **create vector graphic** apa pun.

## Langkah 2: Definisikan elemen lingkaran merah

Selanjutnya, Anda menambahkan konten grafis sebenarnya. Pada contoh ini kami menggambar lingkaran merah berpusat di (50, 50) dengan radius 40 px.

```python
# Define circle attributes
circle_attrs = {
    "cx": "50",   # x‑coordinate of the centre
    "cy": "50",   # y‑coordinate of the centre
    "r": "40",    # radius
    "fill": "red"
}

# Create the circle element and add it to the document
svg_doc.add(svg_doc.circle(**circle_attrs))
```

*Mengapa ini penting*: Menggunakan kamus untuk atribut menjaga kode tetap bersih dan memudahkan modifikasi properti nanti—berguna ketika Anda **export SVG image** dengan warna atau ukuran yang berbeda.

## Langkah 3: Tambahkan elemen tambahan (opsional)

Anda dapat memperluas grafik dengan menambahkan lebih banyak bentuk, teks, atau grup. Di bawah ini adalah langkah opsional yang menambahkan garis tepi hitam di sekitar lingkaran.

```python
# Add a black stroke to the same circle using a style attribute
svg_doc.add(
    svg_doc.circle(
        center=("50px", "50px"),
        r="40px",
        fill="none",
        stroke="black",
        stroke_width="2"
    )
)
```

*Tips pro*: Menggunakan kembali `svg_doc.circle` dengan parameter berbeda memungkinkan Anda membuat lapisan **create vector graphic** tanpa harus menangani string XML secara manual.

## Langkah 4: Simpan SVG ke file

Akhirnya, tulis SVG yang berada di memori ke disk. Ini adalah saat operasi **save SVG file** terjadi.

```python
# Save the document to the specified path
output_path = "output/circle.svg"
svg_doc.saveas(output_path)
print(f"SVG document saved to {output_path}")
```

Setelah skrip selesai, Anda akan menemukan `circle.svg` di dalam folder `output`. Membuka file tersebut di browser atau editor SVG menampilkan lingkaran merah dengan outline hitam tipis.

### Output yang diharapkan (SVG mentah)

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<svg height="100px" version="1.1" width="100px" xmlns="http://www.w3.org/2000/svg">
  <circle cx="50" cy="50" r="40" fill="red"/>
  <circle cx="50px" cy="50px" r="40px" fill="none" stroke="black" stroke-width="2"/>
</svg>
```

Jika Anda melihat file tersebut di browser, Anda akan melihat lingkaran merah berpusat pada kanvas 100 × 100 pixel.

## Cara membuat SVG dengan data dinamis

Sering kali Anda perlu menghasilkan SVG berdasarkan data runtime (mis., titik grafik, avatar pengguna). Pola yang sama berlaku:

```python
def draw_circle(radius, color, filename):
    dwg = svgwrite.Drawing(filename=filename, size=("200px", "200px"))
    dwg.add(dwg.circle(center=("100", "100"), r=str(radius), fill=color))
    dwg.save()
    
# Example usage
draw_circle(radius=80, color="steelblue", filename="dynamic.svg")
```

*Mengapa ini berhasil*: Fungsi tersebut mengabstraksi logika **how to create SVG**, memungkinkan Anda memanggilnya dengan radius atau warna isi apa pun. Pendekatan ini skalabel untuk pemrosesan batch atau endpoint API yang mengembalikan gambar SVG.

## Ekspor gambar SVG untuk penggunaan web

Jika Anda perlu menyematkan SVG langsung ke HTML atau mengirimnya melalui HTTP, Anda dapat **export SVG image** sebagai string:

```python
svg_string = svg_doc.tostring()
# You can now embed svg_string in a <img src="data:image/svg+xml;base64,..."> tag
```

Mengenkripsi string sebagai Base64 memungkinkan Anda menggunakan data URI, yang menghilangkan kebutuhan akan permintaan **save SVG file** terpisah dalam banyak skenario web.

## Kesalahan umum dan cara menghindarinya

| Masalah | Mengapa terjadi | Perbaikan |
|-------|----------------|-----|
| Namespace hilang | Beberapa perpustakaan tidak menambahkan `xmlns` secara otomatis. | Pastikan `svgwrite.Drawing` digunakan atau atur secara manual `svg_doc.attribs['xmlns'] = "http://www.w3.org/2000/svg"`. |
| Nama atribut tidak valid | SVG sensitif huruf besar/kecil; `"strokeWidth"` tidak dikenali. | Gunakan nama atribut sesuai spesifikasi SVG (`stroke-width`). |
| Menimpa file | Menjalankan ulang skrip dapat menimpa file yang ada tanpa peringatan. | Periksa `os.path.exists(output_path)` sebelum memanggil `saveas`. |
| String output besar | Mengekspor SVG yang sangat besar dapat mengonsumsi memori. | Alirkan output ke file menggunakan `svg_doc.write(output_path)` alih-alih `tostring()`. |

Menangani kasus tepi ini memastikan rutinitas **create SVG document** Anda kuat dalam lingkungan produksi.

## Contoh lengkap yang berfungsi

Menggabungkan semuanya, berikut skrip mandiri yang membuat lingkaran merah, menambahkan stroke opsional, dan menyimpan file SVG:

```python
import os
import svgwrite

def create_svg_circle(output_dir: str, filename: str = "circle.svg"):
    """Create an SVG document containing a red circle and save it."""
    # Ensure the output directory exists
    os.makedirs(output_dir, exist_ok=True)
    output_path = os.path.join(output_dir, filename)

    # Initialize the SVG document (100×100 viewport)
    dwg = svgwrite.Drawing(filename=output_path, size=("100px", "100px"))

    # Red circle
    dwg.add(dwg.circle(center=("50", "50"), r="40", fill="red"))

    # Optional black stroke
    dwg.add(
        dwg.circle(
            center=("50px", "50px"),
            r="40px",
            fill="none",
            stroke="black",
            stroke_width="2"
        )
    )

    # Save the file
    dwg.save()
    print(f"SVG document saved to {output_path}")

# Example usage
if __name__ == "__main__":
    create_svg_circle(output_dir="output")
```

Menjalankan skrip ini membuat `output/circle.svg`, yang dapat Anda buka di browser modern mana pun. File tersebut menunjukkan **create vector graphic** dasar yang dapat Anda kembangkan dengan lebih banyak bentuk, teks, atau animasi.
